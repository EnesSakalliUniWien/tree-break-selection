# Node contexts, eigenvalue magnitude and native statistical tests

Confirmed scope: trace node absent; children absent; node present with original
parent absent; node present with original parent and children absent, across
subtree/subspace alternatives. Connect these states to prior results, eigenvalue
magnitudes, native tests, distance fit and inherited versus rebuilt geometry.

## Definitions and constraints

Node identity is its exact labeled descendant leaf set, using the established
clade representation. Linkage IDs do not identify a node across trees. Retain
the presence of each original child, both absent and at least one absent;
case 2 means both absent and can overlap cases 1 or 4. Report its present-node
subset separately. Root parent is not applicable. Direct adjacency is recorded
separately from whether the parent clade exists anywhere in the alternative.
The four cases are not an exhaustive disjoint classification.

Structural absence, existing but unvisited, unavailable/invalid gate, evaluated
non-rejection, and final traversal boundary remain separate. Never substitute
p=1 for a missing node or count a finite raw p as an active calibrated decision.
Preserve production sources, defaults, prior reports and the dirty checkout.
No install, commit, push or service is part of this analysis.

## Paired native replay

Reuse exactly the first four declared seeds of each of the four prior spectral
regimes: crossed, tied-population crossed, compatible and common-mean null.
There are 16 reused n=64,p=6 matrices. Labels are evaluation-only. On each matrix
fit the two native symmetric/average and Markov/Ward reference trees and a
truth-free covariance shortlist: six whole individual sample eigenblocks,
the shortest leading whole-block prefix of rank at least two, and full raw
coordinates. This gives ten fits per matrix and 160 fits total. Do not choose
a view from its recovery or p-values.

All topologies receive native all-pair NNLS fitting against the same original
mean-squared standardized Euclidean target, then the same native edge/sibling
policies and traversal. Retain source-space distances and their spectra as
construction evidence, separate from the common branch-fitting target. Compare
every reference internal clade against each covariance alternative; preserve
repeated candidate comparisons as dependent observations, not new datasets.

Capture the actual edge-half spectral basis as well as the all-leaf sibling
context, raw/local spectra, incoming held-out memberships, raw statistics,
branch factors, empirical inflation, annotations and traversal decisions.
Record matching hypotheses and changes of immediate parent and child partition
before interpreting numeric statistic differences. Same clade has the same raw
sample covariance; native covariance/projections may depend on the tree context.

## Magnitudes and earlier evidence

Reanalyse all 80 previous datasets and their 5,120 saved alternative outcomes
without new clustering fits: raw covariance trace shares, factor coverage,
oracle recovery and common-target residuals. Keep raw covariance eigenvalues,
diffusion max(lambda,0)^6 distance coefficients, and native null-whitened PCA
eigenvalues in separate units. Conditional and fixed-context Wolfram/kernel
controls check which magnitude changes enter the statistic directly.

The existing 25-test candidate/native-replay baseline passed. Use verified
Python 3.12.11, NumPy 2.3.4, SciPy 1.16.3, pandas 2.3.3 and pytest 8.4.2, with
one BLAS thread. Exact structural witnesses and conditional algebra do not
