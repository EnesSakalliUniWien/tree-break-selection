# Structural context of a labeled subtree across topology alternatives

The diagnostic identifies a node by its exact sorted descendant leaf set.
Linkage node numbers and child order are irrelevant. It validates a binary
tree with unique integer labels and requires the two trees to share the same
leaf universe. Every reference internal node, including the root, gets one
row. Leaf singletons are present in both trees.

| Case | Predicate |
| --- | --- |
| 1 | The reference node's clade is absent in the alternative. |
| 2 | Both original direct-child clades are absent anywhere in the alternative. |
| 3 | The node remains and its original parent clade is absent. |
| 4 | The node remains and its original parent and both original child clades are absent. |

These predicates overlap. Case 4 is in cases 2 and 3. Case 1 can overlap case
2, and the root can have case 2. The root never has a missing parent case.
Case 2 is defined using **both** children. The row also reports each
child's presence, whether at least one child is missing, and whether the
tested node itself remains. Presence does not imply preserved adjacency.
The original parent can remain a higher ancestor while a new direct parent
intervenes. A retained child can similarly occur lower down. If the node
and both original children remain, their disjoint child sets exhaust that
node, so both are direct children in a binary hierarchy.

## Minimal six-leaf witness for case 4

Use reference `((((0,1),(2,3)),4),5)` and alternative
`((((0,2),(1,3)),5),4)`. The node `0123` remains. Its parent changes from
`01234` to `01235`, and its children change from `01|23` to `02|13`.
The old parent and both old child clades disappear. The two sibling cuts
inside `0123` cross, so no single binary tree contains both.

Six leaves are necessary for this case. To disappear, each original child
must contain at least two leaves because singletons are always present.
The original parent needs one or more outside leaves and cannot be the root,
since the root's full leaf set is preserved. This adds at least two leaves
outside the four-leaf focal node.

This topology change can be generated by Ward from two distinct whole raw
covariance eigendirections. Assign the six rows coordinates
`x = (0, 1, 10, 11, 30, 100)` and
`y = (0, 10, 1, 11, 1000, −12751/224)`.
The centered cross-product is exactly zero. The sample variances are
approximately 1454.267 and 169646.755, so the eigendirections are distinct.
One-dimensional Ward on x gives the reference tree and Ward on y gives the
alternative. Each view first pairs its close focal leaves. It then attaches
the nearer outside leaf to the four-leaf group. The weaker eigenvalue still
exposes its own cut and parent context. The magnitude difference is partly
due to the two outside coordinates and provides no calibration for either
split.

The same fixture separates inherited directions from a rebuilt covariance.
On the four focal rows, the two inherited axes have sample covariance
`[[101,20],[20,101]]/3`. Rebuilding on those rows gives rotated eigendirections
and eigenvalues `121/3` and `81/3`. Rebuilding a diffusion graph can likewise
change weights or degrees. Comparing such outputs requires declaring
whether one restricts inherited scores, constructs a new graph, or only
changes the linkage while holding distances fixed.

## Implications for comparing statistical records

- If the node is absent, there is no alternative native sibling record for
  that leaf set. Mark it unavailable, even if either original child or the
  original parent remains.
- If the node is present but the original children are absent, an
  alternative sibling record compares different child sets. A numerical
  difference in scores or p-values compares two different contrasts.
- If the node and original children remain but the original parent is
  absent, the same labeled sibling contrast can be identified. The
  child-versus-parent edge contrast has changed. Even the sibling score
  can differ when fitted branch times, normalization, projection or
  empirical reference change. Hold those quantities fixed explicitly to
  isolate a specific mechanism.
- If the original parent and children are all absent, the focal data rows
  remain available, but both the original sibling and edge contrasts have
  changed. A counterfactual score on the fixed old partition would be a
  different diagnostic from a native score for the new topology.

This distinction extends the prior spectral finding that one hierarchy
can omit a crossing factor, while null datasets can still generate many
candidate topologies. These topology predicates, eigenvalue magnitudes and
distance comparisons do not yield a selected p-value. A Gaussian conditional
test must specify its score, target leaf set, and replayed selection event.
Changing the candidate topology can change that event even when the focal
leaf set is identical.

Deterministic tests check all four cases, overlap, root applicability,
child-order invariance, retained clades with changed adjacency, the
Ward eigendirection witness, and invalid input contracts.
