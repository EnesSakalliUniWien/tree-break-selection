# Paths through missing nodes and disappearing neighborhoods

Confirmed scope: both ancestor–descendant and cross-branch paths between
surviving nodes, and disappearing neighboring parents, children and siblings,
related to the native statistics. Exact clade identity and fixed leaf universe
are inherited from the preceding study.

Reuse all 160 saved native fits from the 16-matrix context panel. Compare the
same two reference trees against each of eight covariance alternatives on every
matrix, giving 256 tree pairs. Enumerate every unordered pair of shared nodes,
including leaf singletons. Report internal/internal, internal/leaf and leaf/leaf
endpoints separately. Ancestor paths point toward the descendant. The original
data and native fits remain unchanged; there are no new independent datasets.

Record missing intermediate clades, surviving intermediates moved off the new
path, inserted intermediates and changed lowest common ancestors. The path's
neighborhood consists of the parents, children and siblings of its vertices,
excluding vertices on the path. Keep role membership, global absence, and
survival outside the alternative neighborhood distinct.

Relate these structural changes to fitted path length, the existing edge
statistics and gate states, endpoint sibling records, and actual traversal.
Root-to-node eligibility remains distinct from the path between two nodes.
Trace full-data mean contrasts and the actual edge-half mean increments
separately; neither a sum of Wald scores nor p-values is introduced as a test.

Use saved masks to reconstruct native edge-half contrasts, verify their row
identities, and check that fixed full-data endpoint contrasts agree across
topologies. Exact Wolfram and deterministic fixtures check path telescoping,
increment covariance and nonadditivity of standardized squares. Existing
context/replay baseline: 22 tests passed. Python 3.12.11 and the existing
NumPy/SciPy/pytest environment are used; no installation or production edit.
