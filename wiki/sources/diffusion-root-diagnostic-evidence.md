# Diffusion Root Diagnostic Evidence

## Summary

Three Sol agents implemented native point replay, exact-real operator and
selection-cell enclosures, and outward chi probability bounds. Parent integration
adds a root-only diagnostic and reproducible output tables. The work establishes
local selection certificates and exposes a native floating-point discrepancy;
it does not provide a production selected-root calibration repair.
The subsequent self-distance correction and tighter bounds are documented in
[[diffusion-self-distance-repair-evidence]]; the numerical discrepancy below is
the historical pre-correction finding.

## Key Points

- Original dyadic observations and rational root weights define the exact
  Gaussian conditional path. Rounded replay offsets are excluded from proofs.
- Kernel certificates refit/enclose neighbor selection, NNKDE, all BGH candidates,
  intrinsic dimension, bandwidths, median epsilon and the normalized operator.
- Rational spectral residual bounds and linkage comparisons certify positive-width
  selected/nonselected/selected windows in the scalar reentry fixture.
- Missing regions and the unbounded tail retain unknown probability mass.
  A root decision requires certified observed-event membership and sufficient
  conditional probability bounds. Unresolved roots retain one cluster.
- The native first 80-row matrix contains 29 tiny positive self distances that
  enter median epsilon. The radial reconstruction has 28. The exact-real
  constructor has zero self distances; a final interval certificate excludes
  the native history at its exact observed radius, beginning at merge step 5.
- Wolfram checked probability-ratio monotonicity, not the selection region or
  code correctness. The spectral derivation cites the primary Davis–Kahan reference.

## Evidence

The three raw notes specify equations, arithmetic contracts, native source
relationships, observed numerical discrepancies, reproduction commands and
limitations. Tests cover actual reentry, signed/outward arithmetic, exact
observed-radius bounds, spectral grouping, arithmetic failures, conditional
probability and conservative root gating. The 80-row test separates an
exact-real formula consistency check from literal native disagreement.
