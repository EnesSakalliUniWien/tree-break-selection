# Diffusion Attribution Evidence

## Summary

Three Sol subagents executed and independently reviewed 50 fixed-diffusion-tree
Gaussian pairs, with Wolfram checking the reference-law calculations.

## Key Points

- Full-feature known-identity root tests reject 50/50 selected matrices versus
  0/50 independent matrices assigned to identical groups.
- Production covariance gives 8/50 independent rejections, chiefly the dense
  pooled regime whose finite-sample reference differs from chi-square.
- Restoring the native projection leaves all raw root statistics unchanged
  because every root spans 24 features, but changes empirical inflation through
  nonroot records.
- Root predictions, eligible gate tests and final fragmentation are explicitly
  distinguished. No production calibration repair was integrated.

## Evidence

The primary report specifies seeds, fixed roles/bases, covariance regimes,
reproduction commands, numerical outcomes and limitations. The Wolfram capture
preserves evaluator code and outputs. Compact summaries link the 200 baseline
and 800 restoration root records and 63,200 compressed node records.
