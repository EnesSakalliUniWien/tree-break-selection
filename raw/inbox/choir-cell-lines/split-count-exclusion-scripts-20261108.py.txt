# ===== protocol.md =====
# Protocol: counting all possible splits, with exclusions from subspaces and equidistant cells (frozen 2026-11-08)

## Question (user-confirmed, both readings tested as the user asked)

Count all possible splits of a subtree's cells, then exclude possibilities based on the numbers of different
subspaces and equidistant relationships. "Exclude" is tested in both readings: ruling splits out as real
separations, and shrinking the count of possible splits.

## Per tested split (subtree v with children A and B, n cells)

- p_split = chi2.sf(T, df), production sibling statistic, no inflation factor.
- Invariant directions: eigenvectors of v's covariance in the test PCs above its noise band (rule of
  `split_count_correction_20261108`; n <= p + 1 gives k = 0). Separable: a flat cut in those k directions puts A
  and B on different sides (linear program); k = 0 is not separable.
- Equidistant cells: margin |m| < 0.1 in the test metric (PCs whitened by the pooled within-children covariance;
  measure of `subspace_distance_ties_20261108`); f = their number, tie share = f / n.
- Counts: M_all = 2^(n-1) - 1; M_inv(n', k) = sum_{i=0}^{k} binom(n'-1, i) (Cover's flat-cut count, capped at
  2^(n'-1) - 1).

## Arms (production code end to end; only each tested split's p-value changes)

| Arm | p-value |
| --- | --- |
| today | production (replay) |
| count_all | min(1, M_all p_split) |
| rule_out | count_all, and p = 1 unless the split is separable in its invariant directions and its tie share <= 0.05 |
| shrink | equidistant cells left out of the count (n' = n - f); if separable: min(1, 2 M_inv(n', k) p_split), else min(1, 2 (2^(n'-1) - 1) p_split) |
| both | shrink, and p = 1 unless separable with tie share <= 0.05 |

The 0.05 tie share and the 0.1 margin are conventions fixed here before any result of these arms. Validity:
count_all is a union bound; the exclusions use the observed split, so their error control is not guaranteed by
construction and is measured.

## Data, endpoints, decision rule

The 900 no-group and 35 real-group datasets of 2026-11-08, both trees, production alphas.
E1 tested no-group splits with p <= 0.01 by size bin (2-9, 10-39, 40-159, 160-400); E2 false partitions of 300;
E3 mean ARI on real groups; E4 share of tested splits excluded by each criterion (not separable / tie share).

- Fixes large splits: Markov/Ward, sd 0.25 and 0.42, tested splits >= 40 cells pass at <= 2%.
- Fixes small splits (added for this comparison): Markov/Ward, sd 0.25 and 0.42, tested splits of 10-39 cells
  pass at <= 2%.
- Keeps real groups: default tree, mean ARI on every signal model within 0.02 of today's.

# ===== deviations.md =====
# Deviations from protocol.md

- None at launch. Pilot (`run.py check`, `low` 0 and `signal_balanced` 0): replay 40/40, cell counts 40/40.

# ===== run.py =====
"""Run protocol.md: split-count p-values with exclusions, swapped into production fits."""

import importlib.util
import json
import sys
from dataclasses import replace
from multiprocessing import Pool
from pathlib import Path
from time import perf_counter

HERE = Path(__file__).resolve().parent


def _load(name, folder):
    spec = importlib.util.spec_from_file_location(name, HERE.parent / folder / "run.py")
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    return module


counting = _load("split_count_run", "split_count_correction_20261108")  # puts depth/validate/repo on sys.path
distances = _load("subspace_ties_run", "subspace_distance_ties_20261108")

import numpy as np  # noqa: E402
from scipy.spatial.distance import pdist  # noqa: E402
from scipy.stats import chi2  # noqa: E402
from sklearn.metrics import adjusted_rand_score  # noqa: E402
from threadpoolctl import threadpool_limits  # noqa: E402

import depth  # noqa: E402
from compare import fit  # noqa: E402
from validate import MODELS as VALIDATION_MODELS  # noqa: E402
from validate import prepare  # noqa: E402

import tree_break_selection.hierarchy_analysis.statistics.sibling_divergence.inflated_projected_wald_annotation.pipeline as pipeline  # noqa: E402,E501
from tree_break_selection.hierarchy_analysis.statistics.projection.spectral.tree_helpers import (  # noqa: E402
    precompute_descendants,
)

ARMS = ("today", "count_all", "rule_out", "shrink", "both")
MAX_TIE_SHARE, TIE_MARGIN = 0.05, 0.1
TREES = {"symmetric_average": 1, "markov_ward": 2}
NULLS = ("low", "matched_median", "high")
SIGNALS = ("signal_balanced", "signal_imbalanced", "signal_singleton", "signal_density_variation")
STATE = {"arm": "today", "splits": [], "checks": {}, "data": None, "cache": {}}
ORIGINAL = counting.ORIGINAL


def count(name, ok):
    n, k = STATE["checks"].get(name, (0, 0))
    STATE["checks"][name] = (n + 1, k + bool(ok))


def log_count(n, k, sep):
    """log of the number of possible splits of n cells; flat cuts in k invariant directions when separable."""
    if n < 2:
        return 0.0
    return counting.log_hyperplane_splits(n, k) if sep else counting.log_all_splits(n)


def adjusted(stat, df, log_m):
    return float(np.exp(min(0.0, log_m + chi2.logsf(stat, df))))


def swapped(records, *, model, **kwargs):
    ids, summaries, labels, decisions, inadmissible = ORIGINAL(records, model=model, **kwargs)
    arm, cache = STATE["arm"], STATE["cache"]
    tree = sys._getframe(1).f_locals["tree"]
    by_parent = {r.parent: r for r in records}
    if "rows" not in cache:
        cache["rows"] = precompute_descendants(tree, {label: i for i, label in enumerate(STATE["data"].index)})
        cache["matrix"] = STATE["data"].to_numpy(dtype=np.float64)
    rows, matrix = cache["rows"], cache["matrix"]
    out = ([], [], [], [], list(inadmissible))
    for pid, summary, label, decision in zip(ids, summaries, labels, decisions, strict=True):
        record = by_parent[pid]
        if decision is None:
            for column, value in zip(out[:4], (pid, summary, label, decision), strict=True):
                column.append(value)
            continue
        key = ("split", str(pid))
        if key not in cache:
            left, right = sorted(rows[record.left]), sorted(rows[record.right])
            points = matrix[left + right]
            own_a = np.r_[np.ones(len(left), bool), np.zeros(len(right), bool)]
            n = len(points)
            count("n_matches_record", n == int(record.n_parent))
            k, basis = counting.invariant_directions(points)
            sep = bool(k >= 1 and counting.separable(points @ basis.T, own_a))
            m, _ = distances.margins(distances.whiten(points, own_a), own_a)
            ties = int(np.sum(np.abs(m) < TIE_MARGIN))
            cache[key] = (n, int(min(len(left), len(right))), k, sep, ties)
        n, n_small, k, sep, ties = cache[key]
        stat, df = float(record.stat), float(record.degrees_of_freedom)
        real = sep and ties / n <= MAX_TIE_SHARE
        if arm == "today":
            p, c = decision.p_value, decision.c_hat
            count("replay", np.isclose(float(chi2.sf(stat / c, df)), p, rtol=1e-9, atol=1e-300))
        else:
            c = 1.0
            if arm in ("count_all", "rule_out"):
                p = adjusted(stat, df, counting.log_all_splits(n))
            else:
                p = adjusted(stat, df, log_count(n - ties, k, sep) + np.log(2.0))
            if arm in ("rule_out", "both") and not real:
                p = 1.0
        STATE["splits"].append({"node": str(pid), "n_parent": n, "n_small": n_small, "stat": stat, "df": df, "k": k,
                                "separable": sep, "tie_share": ties / n, "real": real, "p": p,
                                "c_today": float(decision.c_hat)})
        out[0].append(pid)
        out[1].append((stat / c, df, p))
        out[2].append(f"{label}:{arm}")
        out[3].append(replace(decision, c_hat=float(c), p_value=p))
    return out


pipeline.compute_inflation_adjusted_sibling_tests = swapped


def task(job):
    model, replicate = job
    counts, truth = depth.generate(model, replicate)
    datasets, splits = [], []
    STATE["checks"] = {}
    with threadpool_limits(limits=1):
        prepared = prepare(counts)
        STATE["data"] = prepared[0]
        for tree_name, index in TREES.items():
            dist = pdist(prepared[index])
            STATE["cache"] = {}
            for arm in ARMS:
                STATE.update(arm=arm, splits=[])
                start = perf_counter()
                result = fit(prepared[0], dist, tree_name)
                key = {"model": model, "replicate": replicate, "tree": tree_name, "arm": arm}
                bh = result.extra["annotations"]["Sibling_BH_Different"].astype(bool)
                splits.extend({**key, **row, "bh_different": bool(bh[row["node"]])} for row in STATE["splits"])
                datasets.append({**key, "status": result.status.value, "found_clusters": result.found_clusters,
                                 "ari": float(adjusted_rand_score(np.asarray(truth), result.labels)),
                                 "sec": perf_counter() - start})
    return datasets, splits, {"model": model, "replicate": replicate, **STATE["checks"]}


def jobs():
    signal = [(m, r) for m in SIGNALS for r in range(VALIDATION_MODELS[m]["replicates"])]
    return signal + [(m, r) for m in NULLS for r in range(300)]


def main(workers):
    paths = {name: HERE / f"{name}.jsonl" for name in ("datasets", "splits", "checks")}
    done = set()
    if paths["checks"].exists():
        done = {(r["model"], r["replicate"]) for r in map(json.loads, paths["checks"].read_text().splitlines())}
    todo = [j for j in jobs() if j not in done]
    files = {name: path.open("a", buffering=1) for name, path in paths.items()}
    with Pool(workers) as pool:
        for i, (datasets, splits, checks) in enumerate(pool.imap_unordered(task, todo), 1):
            files["splits"].write("".join(json.dumps(r) + "\n" for r in splits))
            files["datasets"].write("".join(json.dumps(r) + "\n" for r in datasets))
            files["checks"].write(json.dumps(checks) + "\n")
            if i % 25 == 0:
                print(f"{i}/{len(todo)}", flush=True)


if __name__ == "__main__":
    if sys.argv[1] == "check":
        for job in (("low", 0), ("signal_balanced", 0)):
            t = perf_counter()
            datasets, splits, checks = task(job)
            print(job, f"{perf_counter() - t:.1f}s", checks)
            for d in datasets:
                print(d["tree"], d["arm"], d["found_clusters"], round(d["ari"], 3), round(d["sec"], 1))
            for s in splits:
                if s["arm"] == "both" and s["n_parent"] >= 100:
                    print({k: (round(v, 3) if isinstance(v, float) else v) for k, v in s.items()
                           if k in ("tree", "n_parent", "k", "separable", "tie_share", "real", "p")})
    else:
        main(int(sys.argv[1]))

"""Summarize run.py output into the protocol endpoints (protocol.md)."""

import json
from pathlib import Path

import numpy as np
import pandas as pd

HERE = Path(__file__).resolve().parent
NULLS = ["low", "matched_median", "high"]
BINS, LABELS = [1, 9, 39, 159, 400], ["2-9", "10-39", "40-159", "160-400"]
ARMS = ["today", "count_all", "rule_out", "shrink", "both"]


def load(name):
    return pd.DataFrame(map(json.loads, (HERE / f"{name}.jsonl").read_text().splitlines()))


def main():
    checks = load("checks")
    for col in [c for c in checks.columns if c not in ("model", "replicate")]:
        pairs = checks[col].dropna()
        print(f"check {col}: {sum(p[1] for p in pairs)}/{sum(p[0] for p in pairs)}")
    ds, sp = load("datasets"), load("splits")
    for frame in (ds, sp):
        frame["arm"] = pd.Categorical(frame.arm, ARMS)
    sp["passed"] = sp.p <= 0.01
    sp["bin"] = pd.cut(sp.n_parent, BINS, labels=LABELS)
    null = sp[sp.model.isin(NULLS)]

    e1 = null.groupby(["tree", "model", "bin", "arm"], observed=True).agg(
        tested=("passed", "size"), pass_share=("passed", "mean"))
    big = null[null.n_parent >= 40].groupby(["tree", "model", "arm"], observed=True).agg(
        tested=("passed", "size"), pass_share=("passed", "mean"))
    nds = ds[ds.model.isin(NULLS)]
    e2 = nds.groupby(["tree", "model", "arm"], observed=True).agg(
        false_partitions=("found_clusters", lambda x: int((x > 1).sum())), median_clusters=("found_clusters", "median"))
    sds = ds[~ds.model.isin(NULLS)]
    e3 = sds.groupby(["tree", "model", "arm"], observed=True).agg(
        datasets=("ari", "size"), mean_ari=("ari", "mean"), median_clusters=("found_clusters", "median"))
    today = sp[sp.arm == "today"].copy()
    today["kind"] = np.where(today.model.isin(NULLS), "no-group", "group data")
    e4 = today.groupby(["kind", "tree", "bin"], observed=True).agg(
        tested=("real", "size"), separable=("separable", "mean"), tie_share_le_005=("tie_share", lambda x: (x <= 0.05).mean()),
        kept_as_real=("real", "mean"))
    for name, table in [("e1_pass_large", big), ("e1_pass_by_size", e1), ("e2_false_partitions", e2),
                        ("e3_signal", e3), ("e4_exclusion", e4)]:
        table.round(4).to_csv(HERE / f"{name}.csv")
        print(name)
        print(table.round(3).to_string(), "\n")

    small = null[null.n_parent.between(10, 39)].groupby(["tree", "model", "arm"], observed=True).passed.mean()
    small.round(4).to_csv(HERE / "e1_pass_small.csv")
    print("pass 10-39\n", small.round(3).to_string(), "\n")
    rule = big.pass_share.xs("markov_ward", level="tree")
    ari = e3.mean_ari.xs("symmetric_average", level="tree").unstack("arm")
    sm = small.xs("markov_ward", level="tree")
    print("Decision rule:", {a: {"fixes_large_splits": bool(all(rule.loc[(m, a)] <= 0.02 for m in ("low", "matched_median"))),
                                "fixes_small_splits": bool(all(sm.loc[(m, a)] <= 0.02 for m in ("low", "matched_median"))),
                                "keeps_real_groups": bool(((ari[a] - ari["today"]).abs() <= 0.02).all())} for a in ARMS})


if __name__ == "__main__":
    main()
