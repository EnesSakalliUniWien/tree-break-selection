# ===== protocol.md =====
# Protocol: splits, leaves, eigenvectors, eigenvalues, geometric multiplicity and separations that do not fit the topology (frozen 2026-11-08)

## Question (user-confirmed)

Analyse, per subtree, the number of splits, the given number of leaves, the number of eigenvectors, the
eigenvalues and the geometrical multiplicity, including that not all separations fit into a topology, which
leads to alternative clusters.

## Per-subtree quantities (feature space = the 30 PCs the tests use)

- n = leaves; number of two-group splits of the leaf set 2^(n-1) - 1 (reported as n - 1 bits); rooted binary
  topologies (2n - 3)!! (log10).
- Eigenvalues of the subtree's cell covariance (no whitening). Noise level = median eigenvalue / median of the
  Marchenko-Pastur law with ratio p/n; noise edge = level * (1 + sqrt(p/n))^2. Number of eigenvectors above the
  edge = k (invariant directions); the bulk below it (p - k directions) is the fuzzy part.
- Geometric multiplicity of the eigenvalues above the edge: consecutive eigenvalues are put in one group while
  a likelihood-ratio test of equality for the block does not reject at 0.01:
  stat = (n - 1) * [m * log(mean of block) - sum(log l_i)], reference chi2 with (m - 1)(m + 2)/2 df (derived
  here as the sphericity test of an m-dimensional block; attribution to Anderson 1963 / Lawley 1956 is not
  verified). Calibration of this rule is checked by simulation (E2) before it is read.
- Subtrees analysed: simulated data, every node with n >= 60; real data, nodes with n >= 500 whose smaller
  child has >= 50 cells (splits that are not peels).

## Separations that do not fit the topology

A two-group separation of a subtree's cells fits the rooted topology below the subtree when one of its sides
is a clade (a node's leaf set) below it. With true labels: groups present = labels with >= 5 cells (simulated)
or >= 20 cells (real) in the subtree.

- Simulated data (g <= 5 groups): every group bipartition (2^(g-1) - 1) of the subtree's labelled cells;
  strength = n_S n_R / n * d' W^-1 d, d = mean difference, W = pooled within-group covariance of the subtree;
  fits = some clade below the subtree holds >= 95% of side S (or of its complement) with >= 95% purity.
  An alternative cluster = a bipartition that does not fit. Reported: share of bipartitions that fit, and the
  strength of the strongest non-fitting bipartition relative to the strongest fitting one, by the
  multiplicity pattern of the subtree's top eigenvalues.
- Real data (190 cell lines, too many to enumerate): per analysed node, lines present and lines cut by the
  node's split (each child holds >= 10% of the line's cells in the node), by k and multiplicity pattern.

## Data and trees

- Simulated: 50 replicates of each no-group model (`low`, `matched_median`, `high`) and all 35 real-group
  datasets of 2026-11-08; frozen preparation (`validate.prepare`); default tree = average linkage on the
  symmetric diffusion coordinates, Markov/Ward = Ward linkage on the Markov coordinates (scipy, same inputs
  as production; production's canonical sample order is not applied, so ties may break differently).
- Real: the CHOIR cell-line data (48,879 cells, 190 lines), the saved trees of 2026-11-06
  (`choir_cell_lines_tbs_merged_20261106/linkage.npy` default, `choir_tbs_recovery_comparison_20261103_174622/
  markov_ward/linkage.npy`), the 30 PCs in `choir_cell_lines_tbs_merged_20261106/pca.npy`; leaf i = cell i
  in `cell_metadata.csv` order (as the 2026-11-06 comparison read them).

## Endpoints (descriptive; no decision rule)

- E1 k and multiplicity pattern by model, tree and subtree role (root; nodes with >= 2 true groups; nodes
  with one group).
- E2 calibration of the multiplicity rule: Gaussian samples with p = 30, n in {100, 400, 1000}, top
  eigenvalue patterns (20,20,20), (20), (30,20,10) on a unit bulk, 500 replicates: share of runs whose grouping
  equals the true pattern.
- E3 simulated alternative separations as above.
- E4 real-data lines cut per analysed node by k and multiplicity pattern; share of lines kept whole.

"""protocol.md: per-subtree spectrum, geometric multiplicity and separations that do not fit the topology.

usage: run.py calib | sim WORKERS | real
"""

import itertools
import json
import sys
from multiprocessing import Pool
from pathlib import Path

HERE = Path(__file__).resolve().parent
sys.path.insert(0, str(HERE.parent / "depth_confound_20261107"))
sys.path.insert(1, str(HERE.parents[2]))

import numpy as np  # noqa: E402
import pandas as pd  # noqa: E402
from scipy.cluster.hierarchy import linkage  # noqa: E402
from scipy.spatial.distance import pdist  # noqa: E402
from scipy.special import gammaln  # noqa: E402
from scipy.stats import chi2  # noqa: E402
from threadpoolctl import threadpool_limits  # noqa: E402

ALPHA = 0.01


def mp_median(ratio):
    """Median of the unit-scale Marchenko-Pastur law with ratio p/n < 1 (numerical)."""
    lo, hi = (1 - np.sqrt(ratio)) ** 2, (1 + np.sqrt(ratio)) ** 2
    grid = np.linspace(lo, hi, 20001)
    dens = np.sqrt(np.maximum((hi - grid) * (grid - lo), 0.0)) / (2 * np.pi * ratio * grid)
    cdf = np.cumsum(dens)
    return float(grid[np.searchsorted(cdf / cdf[-1], 0.5)])


def multiplicities(values, n):
    """Greedy groups of consecutive eigenvalues whose equality the block likelihood-ratio test keeps."""
    groups, start = [], 0
    while start < len(values):
        end = start + 1
        while end < len(values):
            block = values[start:end + 1]
            m = len(block)
            stat = (n - 1) * (m * np.log(block.mean()) - np.log(block).sum())
            if chi2.sf(stat, (m - 1) * (m + 2) / 2) < ALPHA:
                break
            end += 1
        groups.append(end - start)
        start = end
    return groups


def spectrum(points):
    """Eigenvalues (descending), noise edge, k above it and their multiplicity groups."""
    n, p = points.shape
    values = np.sort(np.linalg.eigvalsh(np.cov(points.T)))[::-1]
    ratio = p / n
    level = np.median(values) / mp_median(ratio)
    edge = level * (1 + np.sqrt(ratio)) ** 2
    k = int(np.sum(values > edge))
    return {"n": n, "eig": values, "noise_level": float(level), "edge": float(edge), "k": k,
            "multiplicity": multiplicities(values[:k], n)}


def log10_topologies(n):
    """log10 of (2n - 3)!!, the rooted binary topologies of n labelled leaves."""
    return float((gammaln(2 * n - 1) - gammaln(n) - (n - 1) * np.log(2)) / np.log(10)) if n >= 2 else 0.0


def children_and_counts(z, codes, n_labels):
    """Child arrays and per-label leaf counts for every node of a scipy linkage (leaves 0..n-1)."""
    n = len(codes)
    left, right = z[:, 0].astype(int), z[:, 1].astype(int)
    counts = np.zeros((2 * n - 1, n_labels), dtype=np.int32)
    counts[np.arange(n), codes] = 1
    for i in range(n - 1):
        counts[n + i] = counts[left[i]] + counts[right[i]]
    return left, right, counts


def descendants(node, n, left, right):
    """All nodes below `node` (inclusive) and its leaves."""
    stack, nodes = [node], []
    while stack:
        u = stack.pop()
        nodes.append(u)
        if u >= n:
            stack += [left[u - n], right[u - n]]
    nodes = np.array(nodes)
    return nodes, nodes[nodes < n]


def bipartitions(points, labels, groups, clade_counts, clade_sizes):
    """Every bipartition of the groups: strength and whether a clade below holds one side."""
    keep = np.isin(labels, groups)
    x, y = points[keep], labels[keep]
    centered = np.vstack([x[y == g] - x[y == g].mean(0) for g in groups])
    within = centered.T @ centered / (len(x) - len(groups))
    w_inv = np.linalg.pinv(within)
    rows = []
    for size in range(1, len(groups) // 2 + 1):
        for side in itertools.combinations(groups, size):
            if 2 * size == len(groups) and groups[0] not in side:
                continue  # each balanced bipartition once
            in_s = np.isin(y, side)
            d = x[in_s].mean(0) - x[~in_s].mean(0)
            strength = in_s.sum() * (~in_s).sum() / len(y) * float(d @ w_inv @ d)
            fits = False
            for s_groups in (list(side), [g for g in groups if g not in side]):
                total = clade_counts[:, s_groups].sum(1)
                n_side = int(np.isin(y, s_groups).sum())
                fits |= bool(np.any((total >= 0.95 * n_side) & (total >= 0.95 * clade_sizes)))
            rows.append({"side": "+".join(map(str, side)), "size": size, "strength": strength, "fits": fits})
    return rows


def calibrate():
    rng = np.random.default_rng(np.random.SeedSequence([20261108, 2]))
    rows = []
    for pattern in ((20, 20, 20), (20,), (30, 20, 10)):
        for n in (100, 400, 1000):
            truth = [len(list(g)) for _, g in itertools.groupby(pattern)]
            hits = 0
            for _ in range(500):
                scale = np.sqrt(np.r_[pattern, np.ones(30 - len(pattern))])
                s = spectrum(rng.standard_normal((n, 30)) * scale)
                hits += s["k"] == len(pattern) and s["multiplicity"] == truth
            rows.append({"pattern": str(pattern), "n": n, "true_grouping": str(truth), "share_exact": hits / 500})
    out = pd.DataFrame(rows)
    out.to_csv(HERE / "e2_calibration.csv", index=False)
    print(out.to_string(index=False))


def analyse_tree(points, z, labels, groups_min, min_n, real=False):
    """Rows for the subtree table (E1) and the bipartition table (E3) of one tree."""
    codes, uniq = pd.factorize(labels)
    n = len(codes)
    left, right, counts = children_and_counts(z, codes, len(uniq))
    sizes = counts.sum(1)
    nodes, bips = [], []
    for i in range(n - 1):
        v = n + i
        small = int(min(sizes[left[i]], sizes[right[i]]))
        if sizes[v] < min_n or (real and small < 50):
            continue
        below, leaves = descendants(v, n, left, right)
        s = spectrum(points[leaves])
        present = np.flatnonzero(counts[v] >= groups_min)
        row = {"node": int(v), "is_root": v == 2 * n - 2, "n": int(sizes[v]), "n_small": small,
               "split_bits": int(sizes[v] - 1), "log10_topologies": log10_topologies(int(sizes[v])),
               "k": s["k"], "multiplicity": "+".join(map(str, s["multiplicity"])),
               "top_multiplicity": s["multiplicity"][0] if s["multiplicity"] else 0,
               "eig_top6": np.round(s["eig"][:6], 3).tolist(), "noise_level": s["noise_level"], "edge": s["edge"],
               "groups_present": int(len(present))}
        if real:
            lc, rc = counts[left[i]][present], counts[right[i]][present]
            row["lines_cut"] = int(np.sum(np.minimum(lc, rc) >= 0.10 * (lc + rc)))
        nodes.append(row)
        if not real and 2 <= len(present) <= 5:
            clades = below[below != v]
            for b in bipartitions(points[leaves], codes[leaves], list(present), counts[clades], sizes[clades]):
                bips.append({"node": int(v), "n": int(sizes[v]), "g": int(len(present)), "k": s["k"],
                             "multiplicity": row["multiplicity"], **b})
    return nodes, bips


def sim_task(job):
    import depth  # noqa: PLC0415  (frozen generator; also puts validate on sys.path)
    from validate import prepare  # noqa: PLC0415

    model, replicate = job
    counts, truth = depth.generate(model, replicate)
    with threadpool_limits(limits=1):
        data, symmetric, markov = prepare(counts)
        points = data.to_numpy(dtype=np.float64)
        labels = np.asarray(truth).astype(str)
        out_nodes, out_bips = [], []
        for name, coords, method in (("symmetric_average", symmetric, "average"), ("markov_ward", markov, "ward")):
            z = linkage(pdist(np.asarray(coords)), method=method)
            nodes, bips = analyse_tree(points, z, labels, groups_min=5, min_n=60)
            key = {"model": model, "replicate": replicate, "tree": name}
            out_nodes += [{**key, **r} for r in nodes]
            out_bips += [{**key, **r} for r in bips]
    return out_nodes, out_bips


def simulate(workers):
    import depth  # noqa: PLC0415
    from validate import MODELS  # noqa: PLC0415

    jobs = [(m, r) for m in ("signal_balanced", "signal_imbalanced", "signal_singleton", "signal_density_variation")
            for r in range(MODELS[m]["replicates"])] + [(m, r) for m in ("low", "matched_median", "high") for r in range(50)]
    with Pool(workers) as pool, (HERE / "sim_nodes.jsonl").open("w") as fn, (HERE / "sim_bipartitions.jsonl").open("w") as fb:
        for i, (nodes, bips) in enumerate(pool.imap_unordered(sim_task, jobs), 1):
            fn.write("".join(json.dumps(r, default=float) + "\n" for r in nodes))
            fb.write("".join(json.dumps(r, default=float) + "\n" for r in bips))
            if i % 25 == 0:
                print(f"{i}/{len(jobs)}", flush=True)


def real():
    base = HERE.parent
    meta = pd.read_csv(base / "choir_cell_lines_tbs_merged_20261106/cell_metadata.csv", index_col=0, dtype=str)
    points = np.load(base / "choir_cell_lines_tbs_merged_20261106/pca.npy").astype(np.float64)
    assert points.shape == (len(meta), 30)
    trees = {"symmetric_average": base / "choir_cell_lines_tbs_merged_20261106/linkage.npy",
             "markov_ward": base / "choir_tbs_recovery_comparison_20261103_174622/markov_ward/linkage.npy"}
    with threadpool_limits(limits=4), (HERE / "real_nodes.jsonl").open("w") as f:
        for name, path in trees.items():
            z = np.load(path)
            assert z.shape == (len(meta) - 1, 4) and int(z[-1, 3]) == len(meta)
            nodes, _ = analyse_tree(points, z, meta.Cell_line.to_numpy(), groups_min=20, min_n=500, real=True)
            f.write("".join(json.dumps({"tree": name, **r}, default=float) + "\n" for r in nodes))
            print(name, len(nodes), "nodes", flush=True)


if __name__ == "__main__":
    {"calib": calibrate, "real": real}.get(sys.argv[1], lambda: simulate(int(sys.argv[2])))()

# ===== summarize.py =====
"""Summaries for protocol.md endpoints E1, E3, E4 (E2 is written by run.py calib)."""

import json
from pathlib import Path

import numpy as np
import pandas as pd

HERE = Path(__file__).resolve().parent
pd.set_option("display.width", 220)


def load(name):
    return pd.DataFrame(map(json.loads, (HERE / f"{name}.jsonl").read_text().splitlines()))


def top(series, n=3):
    counts = series.replace("", "none").value_counts(normalize=True).head(n)
    return "; ".join(f"{k} {v:.0%}" for k, v in counts.items())


def main():
    nodes, bips, real = load("sim_nodes"), load("sim_bipartitions"), load("real_nodes")
    nodes["role"] = np.where(nodes.is_root, "root", np.where(nodes.groups_present >= 2, "several groups", "one group"))
    e1 = nodes.groupby(["model", "tree", "role"]).agg(
        nodes=("k", "size"), median_n=("n", "median"), share_k0=("k", lambda x: (x == 0).mean()),
        median_k=("k", "median"), multiplicity=("multiplicity", top))
    print("E1\n", e1.round(3).to_string(), "\n")

    per_node = bips.groupby(["model", "replicate", "tree", "node"]).apply(lambda b: pd.Series({
        "g": b.g.iloc[0], "k": b.k.iloc[0], "multiplicity": b.multiplicity.iloc[0] or "none",
        "bipartitions": len(b), "fit": int(b.fits.sum()),
        "ratio_best_nonfit": (b.strength[~b.fits].max() / b.strength[b.fits].max()) if (~b.fits).any() and b.fits.any() else np.nan,
    }), include_groups=False).reset_index()
    e3 = per_node.groupby(["model", "tree", "g", "multiplicity"]).agg(
        nodes=("fit", "size"), bipartitions=("bipartitions", "first"), median_fit=("fit", "median"),
        median_ratio_best_nonfit=("ratio_best_nonfit", "median"),
        share_nonfit_within_10pct=("ratio_best_nonfit", lambda x: (x >= 0.9).mean()))
    print("E3\n", e3.round(3).to_string(), "\n")
    balanced = bips[(bips.model == "signal_balanced") & (bips.g == 4)]
    e3b = balanced.groupby(["tree", "size"]).agg(bipartitions=("fits", "size"), share_fit=("fits", "mean"),
                                                 median_strength=("strength", "median"))
    print("E3 balanced roots by side size\n", e3b.round(3).to_string(), "\n")

    real["cut_any"] = real.lines_cut > 0
    e4 = real.groupby(["tree", "top_multiplicity"]).agg(
        nodes=("n", "size"), median_n=("n", "median"), median_k=("k", "median"), median_lines=("groups_present", "median"),
        median_lines_cut=("lines_cut", "median"), share_nodes_cutting=("cut_any", "mean"))
    print("E4\n", e4.round(3).to_string(), "\n")
    roots = real[real.n == real.n.max()][["tree", "n", "n_small", "k", "multiplicity", "eig_top6", "groups_present", "lines_cut"]]
    print("E4 roots\n", roots.to_string(index=False))
    for name, table in [("e1_subtrees", e1), ("e3_alternatives", e3), ("e3_balanced", e3b), ("e4_real", e4)]:
        table.round(4).to_csv(HERE / f"{name}.csv")
    per_node.to_csv(HERE / "e3_per_node.csv", index=False)


if __name__ == "__main__":
    main()
