# ===== protocol.md =====
# # Protocol: variant A with both findings of the check fixed (frozen 2026-11-12, before the runs)
#
# ## The two findings (wiki page `k-split-direction-draft`, capture `variant-a-check-20261112.md`)
#
# 1. A feature that is constant in the basis half makes the within covariance singular; the draft raised
#    `LinAlgError`, which stopped the fit.
# 2. The halves alternated in the order of the rows, so the result depended on that order: on the CHOIR cells 196
#    to 225 clusters and ARI 0.8043 to 0.8397 over five orders.
#
# ## Looked up before this protocol
#
# - N. Meinshausen, L. Meier, P. Buehlmann, "p-Values for High-Dimensional Regression", Journal of the American
#   Statistical Association 104(488), 1671-1681, 2009, https://doi.org/10.1198/jasa.2009.tm08647 (record), text
#   read at https://arxiv.org/abs/0811.2177 page 5: a single random split gives a "p-value lottery"; over B
#   splits the paper defines Q(gamma) = min{1, the gamma-quantile of the p-values divided by gamma}, a p-value for
#   any fixed gamma; for gamma = 0.5 it is twice the median of the p-values.
# - V. Vovk, R. Wang, "Combining p-values via averaging", https://arxiv.org/abs/1212.4966 (abstract): twice the
#   arithmetic mean of p-values is valid without any assumption on their dependence.
#
# ## The fixed draft (`draft_rule_v2.py`, analysis folder only)
#
# For a node and the tree's split into left and right, with R = 20:
#
# 1. For r = 1 to R: divide each side at random into a test part (half of the side, rounded up) and a basis part,
#    with a random number generator seeded by (cells of the node, cells of the left side, r).
# 2. Direction from the basis part as in variant A, but with the pseudo-inverse of the pooled within covariance,
#    so a feature that is constant in the basis part gets no weight instead of an error.
# 3. p_r from `rho` of the tree's split of the test part along the direction against the reference at (test
#    cells, 1). If the direction is zero or not finite, or the test cells do not vary along it, p_r = 1.
# 4. The node's p-value is min(1, 2 x median of p_1 ... p_R). The reported `rho` is the median of the R values.
# 5. p = 1 with fewer than 15 test cells or a side with fewer than 2 cells, as before.
#
# The division of the cells no longer uses the order of the rows; with the same cells in another order the random
# parts differ, but the node's p-value is a median over 20 divisions instead of one division.
#
# ## Runs
#
# - E0 constructed inputs of the check: a constant feature; equal basis means. Expected: no error.
# - E1 benchmark (`run_benchmark.py`): the 14 cases, both registered methods, and the one-population grid of 80
#   runs, as for variant A.
# - E2 level (`run_level.py`): one Gaussian population, (256, 30) and (496, 30), identity and the unequal
#   variances of the CHOIR root with the fixed rotation, 50 seeds, the 4 cells of operator and linkage (800 fits):
#   fits with more than 1 cluster and tested calls with p <= 0.01. Variant A on the same 800 fits (recorded in
#   `results/analyses/k_split_direction_level_20261112`): 6 fits with more than 1 cluster.
# - E3 CHOIR cells (`run_choir.py`): the data order and 4 random orders of the rows (seeds 1, 2, 3, 777).
#
# ## Predictions, stated before the runs
#
# - G0 no error on the constructed inputs.
# - G1 the benchmark gives the found clusters of variant A in all 28 rows; both null cases and all 80 runs of the
#   one-population grid give 1 cluster.
# - G2 level: at most 6 of the 800 fits have more than 1 cluster.
# - G3 CHOIR: over the five orders the found clusters differ by at most 10 (variant A: 196 to 225) and the ARI by
#   at most 0.01 (variant A: 0.8043 to 0.8397).
# - G4 CHOIR: the ARI is at least 0.80 in every order.
# Each is reported as held or not held.
#
# ## Limits known before the runs
#
# Twice the median needs p_r <= 0.005 in more than half of the divisions, so splits of moderate strength are
# refused more often than with one division. The remaining dependence on the order is measured, not removed
# exactly. One real dataset and tree; one seed per benchmark case.
#
# ## Amendment (2026-11-12, after E1 and E3 of the fixed draft, before any run of the third version)
#
# Result that prompts it: with 20 divisions and twice the median, the CHOIR fit no longer depends on the order of
# the rows (133 to 135 clusters, ARI 0.5371 to 0.5374 over five orders), but the ARI falls from about 0.82 to 0.54.
# Measured cause: 151 calls sit at the smallest possible p-value, 0.001 = 2 x 0.0005, and Benjamini-Hochberg does
# not accept 54 of them; of the 54 splits that variant A accepted and the fixed draft does not, 46 have p = 0.001.
# The table has 1,999 draws per cell, so no p-value can be below 0.0005, and doubling it is too much for the BH
# step. The independent check also found the table's 99% points at k = 1 off by this Monte Carlo error.
#
# Third version (`draft_rule_v3.py`): the fixed draft unchanged except for the null. For k = 1 the best flat cut
# is the best cut of the sorted values, so its null can be simulated exactly and cheaply: 99,999 Gaussian
# datasets per n of the table's grid (15 to 800), stored in the analysis folder (`null_k1.npz`,
# `build_null_k1.py`, seed 20261112). p_r = (1 + number of null values >= `rho`) / 100,000 at the largest grid n
# not above the number of test cells. The smallest possible node p-value is then 0.00002.
#
# Runs: E1 (benchmark and one-population grid), E2 (level, 800 fits) and E3 (CHOIR, five orders) again with the
# third version; outputs carry the suffix `_v3`.
#
# Predictions for the third version, stated before its runs:
# - H1 benchmark: found clusters of variant A in all 28 rows; null cases and the one-population grid at 1 cluster.
# - H2 level: at most 6 of the 800 fits have more than 1 cluster.
# - H3 CHOIR: over the five orders the found clusters differ by at most 10 and the ARI by at most 0.01.
# - H4 CHOIR: the ARI is at least 0.80 in every order.


# ===== draft_rule_v2.py =====
"""protocol.md: variant A with 20 random divisions per node, twice the median p-value, and no error for a singular covariance."""
import numpy as np

from tree_break_selection.hierarchy_analysis.statistics.sibling_divergence import (
    best_flat_cut_reference as mod,
)

DIVISIONS = 20
CALLS = []
_original_leaf_rows = mod._leaf_rows


def _direction(points, in_first):
    """Pseudo-inverse of the pooled within covariance times the difference of the two means."""
    a, b = points[in_first], points[~in_first]
    difference = a.mean(axis=0) - b.mean(axis=0)
    if len(points) <= points.shape[1] + 2:
        return difference
    if min(len(a), len(b)) >= 2:
        within = (np.cov(a.T) * (len(a) - 1) + np.cov(b.T) * (len(b) - 1)) / (len(points) - 2)
    else:
        within = np.cov(points.T)
    return np.linalg.pinv(np.atleast_2d(within), hermitian=True) @ difference


def _one_division(points, in_left, left, right, rng):
    """(rho, p) of one random division of each side into a test part and a basis part."""
    left, right = rng.permutation(left), rng.permutation(right)
    cut_left, cut_right = (len(left) + 1) // 2, (len(right) + 1) // 2
    test = np.concatenate([left[:cut_left], right[:cut_right]])
    basis = np.concatenate([left[cut_left:], right[cut_right:]])
    w = _direction(points[basis], in_left[basis])
    projected = points[test] @ w
    if not np.isfinite(w).all() or not w.any() or np.ptp(projected) <= 1e-12 * max(1.0, float(np.abs(projected).max())):
        return float("nan"), 1.0
    try:
        rho = mod.split_rho(projected[:, None], in_left[test])
    except np.linalg.LinAlgError:
        return float("nan"), 1.0
    return rho, mod.reference_p_value(rho, len(test), 1)[0]


def draft(points, in_left):
    points = np.asarray(points, dtype=np.float64)
    in_left = np.asarray(in_left, dtype=bool)
    left, right = np.flatnonzero(in_left), np.flatnonzero(~in_left)
    n_test = (len(left) + 1) // 2 + (len(right) + 1) // 2
    record = dict(n=len(points), left=len(left), reason="too_few_cells", k=0, rho=None, p=1.0)
    if n_test < 15 or len(left) < 2 or len(right) < 2:
        CALLS.append(record)
        return mod.BestFlatCutReference(1.0, "too_few_cells", 0, float("nan"), 0)
    results = [_one_division(points, in_left, left, right, np.random.default_rng((len(points), len(left), r))) for r in range(DIVISIONS)]
    p_values = np.array([p for _, p in results])
    rhos = np.array([rho for rho, _ in results])
    p_value = float(min(1.0, 2.0 * np.median(p_values)))
    rho = float(np.nanmedian(rhos)) if np.isfinite(rhos).any() else float("nan")
    record.update(reason="tested", k=1, rho=rho if np.isfinite(rho) else None, p=p_value, n_test=n_test,
                  p_min=float(p_values.min()), p_max=float(p_values.max()))
    CALLS.append(record)
    return mod.BestFlatCutReference(p_value, "tested", 1, rho, int(mod.reference_p_value(0.0, n_test, 1)[1]))


def install(order_seed=None):
    """Replace the reference by the fixed draft; cells of a side arrive in data order, or in a seeded random order of the rows."""
    if order_seed is None:
        mod._leaf_rows = lambda tree, node, row_of_label: sorted(_original_leaf_rows(tree, node, row_of_label))
    else:
        key = np.random.default_rng(order_seed).permutation(1_000_000)
        mod._leaf_rows = lambda tree, node, row_of_label: sorted(_original_leaf_rows(tree, node, row_of_label), key=lambda row: key[row])
    mod.best_flat_cut_reference = draft


# ===== build_null_k1.py =====
"""protocol.md amendment: exact null of the best cut of one direction for one Gaussian population, per grid n."""
from pathlib import Path

import numpy as np

HERE = Path(__file__).resolve().parent
N_GRID = np.array([15, 20, 30, 40, 50, 75, 100, 150, 200, 300, 400, 800])
DRAWS = 99_999
rng = np.random.default_rng(20261112)
null = np.empty((len(N_GRID), DRAWS))
for i, n in enumerate(N_GRID):
    left = np.arange(1, n)
    for start in range(0, DRAWS, 5000):
        x = np.sort(rng.normal(size=(min(5000, DRAWS - start), n)), axis=1)
        prefix = np.cumsum(x, axis=1)[:, :-1]
        total = x.sum(axis=1, keepdims=True)
        between = (prefix / left - (total - prefix) / (n - left)) ** 2 * left * (n - left) / n
        r2 = between.max(axis=1) / ((x - x.mean(axis=1, keepdims=True)) ** 2).sum(axis=1)
        null[i, start:start + len(x)] = (n - 2) / n * r2 / (1 - r2)
    null[i].sort()
    print(f"n = {n}: 99% point {np.quantile(null[i], 0.99):.3f}, 99.9% point {np.quantile(null[i], 0.999):.3f}", flush=True)
np.savez_compressed(HERE / "null_k1.npz", n_grid=N_GRID, null=null)

"""protocol.md amendment: the fixed draft with an exact null of 99,999 draws for one direction instead of the table."""
from pathlib import Path

    best_flat_cut_reference as mod,
)

DIVISIONS = 20
CALLS = []

_NULL = np.load(Path(__file__).with_name("null_k1.npz"))
_N_GRID, _NULL_VALUES = _NULL["n_grid"], _NULL["null"]


def _p_value(rho, n_test):
    """Monte Carlo p-value of rho against the exact null of the best cut of one direction; grid n rounded down."""
    values = _NULL_VALUES[int(np.searchsorted(_N_GRID, n_test, side="right")) - 1]
    count = len(values) - int(np.searchsorted(values, rho, side="left"))
    return (1 + count) / (len(values) + 1)


def _direction(points, in_first):
    """Pseudo-inverse of the pooled within covariance times the difference of the two means."""
    a, b = points[in_first], points[~in_first]

    else:

Q = ortho_group.rvs(30, random_state=0)

def make_blobs(**kwargs):
    x, y = original_make_blobs(**kwargs)[:2]
    return (x * np.sqrt(V)) @ Q.T if covariance == "unequal" else x, y

(registered,) = [c for c in get_test_cases_by_suite("continuous") if c["name"] == "gauss_null_large_continuous"]
fits = []
for seed in range(1, 51):
    case = {**registered, "n_samples": cells, "n_features": 30, "seed": seed}
    for operator in ("symmetric", "markov"):
        for linkage in ("average", "ward"):
            draft_rule_v3.CALLS.clear()
            params = {**METHOD_SPECS["tbs_family_diffusion"].param_grid[0], "diffusion_coordinate_operator": operator,
                      "tree_linkage_method": linkage, "sibling_best_flat_cut_reference": True}
            res = benchmark_cluster_algorithm(test_cases=[case], methods=["tbs_family_diffusion"], method_params={"tbs_family_diffusion": [params]},
                                              verbose=False, plot_umap=False, include_cover_pages=False, include_validation_page=False,
                                              allow_method_errors=False)
            fits.append(dict(cells=cells, covariance=covariance, seed=seed, cell=f"{operator}/{linkage}", found=int(res["found_clusters"].iloc[0]),
                             calls=[dict(c) for c in draft_rule_v3.CALLS]))

      f"{sum(p <= 0.01 for p in tested)} of {len(tested)}; smallest p {min(tested)}", flush=True)
