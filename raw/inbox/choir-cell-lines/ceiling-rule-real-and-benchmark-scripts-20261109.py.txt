# ===== protocol.md =====
# Protocol: the ceiling-3 rule on the CHOIR cell lines and the continuous benchmark (frozen 2026-11-09)

User choice: test the ceiling-3 rule of `gaussian_cut_rule_20261108` on the real cell lines and the continuous
benchmark. Descriptive; no production change.

## Rule

For each tested sibling split: k invariant directions of its subtree (production `invariant_directions`),
rho = pi (1 - pi) D^2 along them, and

    p = min{1, sum_{i<=k} binom(n-1, i) P(chi2_k(3 n) >= n rho)},  p = 1 when k = 0

(`cut_rule.cut_bound_p` with `unimodal_bound`, unchanged). The p-value goes to the usual sibling BH step.

## How it runs

Both parts use the production opt-in path `sibling_split_count_rule_out=True`. Arm `rule_out` runs it as is;
arm `ceiling3` swaps `pipeline.apply_split_count_rule_out` for a function that returns the ceiling-3 p-value on
the same `leaf_data`, the same leaf rows (`_leaf_rows`) and the same statistic.

1. Real: `split_count_exclusion_real_20261108/run.py` setup (48,879 cells, 30 PCs, the saved diffusion
   coordinates of `choir_cell_lines_tbs_lbfgsb_20261106`, registry parameters, edge alpha 1e-3, sibling alpha
   1e-2), both registered methods, arms `rule_out` and `ceiling3`. Replay check: `rule_out` should give the
   2026-11-08 harness result, 69 and 664 clusters.
2. Benchmark: `rule_out_continuous_benchmark_20261108/run.py` setup (9 continuous cases, both methods, registered
   cell and the same cell with the opt-in, default alphas). Replay check: today and `rule_out` rows equal the
   2026-11-08 `results.csv` in found clusters and ARI. Then the opt-in cell again with arm `ceiling3`.

## Endpoints

- Real, per method and arm: found clusters, ARI and NMI against the cell lines, lines recovered at 90/90, ARI
  against published CHOIR_1, clusters at least 90% pure, clusters under 20 cells, median clusters per line;
  per tested split: size, share, k, rho, p, kept (p <= 0.01 before BH) and BH acceptance, by size bin.
- Benchmark, per case and method: found clusters and ARI for today, `rule_out` and `ceiling3`.

## Expected before running

- Benchmark: a subtree of n <= p + 1 cells has no invariant directions under either rule, so `ceiling3` keeps
  the losses of `rule_out` on gauss_clear_medium (60 cells, 40 features), gauss_moderate_3c (45, 30) and
  gauss_dense_signal_highd (40, 20,000).
- Real: at 48,879 cells the ceiling-3 rule allows about 4% overlap for balanced splits where separability
  allows none, so it should keep more of the large splits than `rule_out`. Whether that raises or lowers
  agreement with the cell lines is not predicted. These data have no known no-group parts, so false splits can
  only be read from lines split into several clusters.

# ===== deviations.md =====
# Deviations from protocol.md

- First run (2026-11-09 00:14): the ceiling3 arm used the method label `ceiling3`, which the sibling FDR step
  rejects ("Unsupported sibling test method label"), so all 18 ceiling3 benchmark runs ended with status error
  and the real-data run was stopped before its first arm finished. The label was changed to
  `split_count_rule_out:ceiling3` (the prefix the FDR step accepts for the opt-in rule-out); the rule is
  unchanged. Both parts were rerun from the start.
- Added after the endpoints: `breakdown.py` counts, per method and arm, the lines that miss 90/90 because they
  are split across clusters, merged with other lines, or both (`breakdown.txt`).
- Expectation "ceiling3 keeps more of the large splits than rule_out" held for Markov/Ward (1000+ cells: 40.8%
  vs 34.0%) and failed for the default tree (10.2% vs 18.4%).

"""protocol.md: production rule-out vs the ceiling-3 rule on the CHOIR cell lines and the continuous suite.

usage: run.py real METHOD | run.py benchmark
"""

import json
import os
import sys
from dataclasses import replace
from pathlib import Path
from time import perf_counter

HERE = Path(__file__).resolve().parent
sys.path.insert(0, str(HERE.parents[2]))
sys.path.insert(0, str(HERE.parent / "gaussian_cut_rule_20261108"))

import numpy as np  # noqa: E402
import pandas as pd  # noqa: E402
from cut_rule import cut_bound_p, unimodal_bound  # noqa: E402

import tree_break_selection.hierarchy_analysis.statistics.sibling_divergence.inflated_projected_wald_annotation.pipeline as pipeline  # noqa: E402,E501
from tree_break_selection.hierarchy_analysis.statistics.sibling_divergence.split_count_rule_out import (  # noqa: E402
    _leaf_rows,
    invariant_directions,
)

ORIGINAL = pipeline.apply_split_count_rule_out
STATE = {"arm": "rule_out", "splits": []}


def swapped(tree, leaf_data, records, tested_parent_ids, summaries, method_labels, decisions):
    """rule_out: production as is. ceiling3: p from the at-the-mode ceiling 3, same rows and statistic."""
    by_parent = {record.parent: record for record in records}
    shape = list(leaf_data.shape)
    if STATE["arm"] == "rule_out":
        out = ORIGINAL(tree, leaf_data, records, tested_parent_ids, summaries, method_labels, decisions)
        for parent, label, decision in zip(tested_parent_ids, out[1], out[2], strict=True):
            if decision is not None:
                STATE["splits"].append({"shape": shape, "node": str(parent), "n_parent": int(by_parent[parent].n_parent),
                                        "reason": label.split(":")[-1], "p": float(decision.p_value)})
        return out
    row_of_label = {label: row for row, label in enumerate(leaf_data.index)}
    matrix = leaf_data.to_numpy(dtype=np.float64)
    new = ([], [], [])
    for parent, summary, label, decision in zip(tested_parent_ids, summaries, method_labels, decisions, strict=True):
        if decision is None:
            for column, value in zip(new, (summary, label, decision), strict=True):
                column.append(value)
            continue
        record = by_parent[parent]
        left, right = _leaf_rows(tree, record.left, row_of_label), _leaf_rows(tree, record.right, row_of_label)
        points = matrix[left + right]
        in_left = np.r_[np.ones(len(left), bool), np.zeros(len(right), bool)]
        directions = invariant_directions(points)
        p, rho = cut_bound_p(points @ directions.T, in_left, unimodal_bound)
        assert np.isfinite(p), (parent, rho)  # a NaN tail would silently read as p = 1
        statistic = float(record.stat) / float(record.reference_scale)
        STATE["splits"].append({"shape": shape, "node": str(parent), "n_parent": len(points),
                                "n_small": int(min(len(left), len(right))), "k": len(directions),
                                "pi": float(in_left.mean()), "rho": rho, "p": p})
        new[0].append((statistic, float(record.degrees_of_freedom), p))
        new[1].append("split_count_rule_out:ceiling3")  # the FDR step accepts this prefix
        new[2].append(replace(decision, c_hat=1.0, p_value=p))
    return new


pipeline.apply_split_count_rule_out = swapped


def recovered_lines(truth, labels):
    table = pd.crosstab(truth, labels)
    recall = table.max(axis=1) / table.sum(axis=1)
    purity = table.max(axis=0) / table.sum(axis=0)
    return int(((recall >= 0.9) & (purity[table.idxmax(axis=1)].to_numpy() >= 0.9)).sum())


def real(method):
    from scipy.spatial.distance import pdist
    from sklearn.metrics import adjusted_rand_score, normalized_mutual_info_score
    from threadpoolctl import threadpool_limits

    from benchmarks.shared.runners.dispatch import _tbs_branch_length_optimization_kwargs
    from benchmarks.shared.runners.method_registry import METHOD_SPECS
    from benchmarks.shared.runners.tbs_runner import run_tbs_on_distance
    from tree_break_selection.tree.feature_space import continuous_feature_space_from_columns

    source = HERE.parent / "choir_cell_lines_tbs_lbfgsb_20261106"
    metadata = pd.read_csv(source / "cell_metadata.csv", index_col=0, dtype=str)
    data = pd.DataFrame(np.load(source / "pca.npy"), index=metadata.index, columns=[f"PC{i + 1}" for i in range(30)])
    truth = metadata.Cell_line.to_numpy()
    params = dict(METHOD_SPECS[method].param_grid[0])
    out = HERE / method
    out.mkdir(exist_ok=True)
    distance_path = out / "diffusion_distance.npy"
    distances = np.lib.format.open_memmap(distance_path, mode="w+", dtype=np.float64,
                                          shape=(len(data) * (len(data) - 1) // 2,))
    pdist(np.load(source / method / "coordinates.npy"), metric="euclidean", out=distances)
    distances.flush()
    with threadpool_limits(limits=4), (out / "results.jsonl").open("w") as f:
        for arm in ("rule_out", "ceiling3"):
            STATE.update(arm=arm, splits=[])
            start = perf_counter()
            result = run_tbs_on_distance(
                data, distances, 0.01, edge_alpha=0.001, tree_linkage_method=params["tree_linkage_method"],
                feature_space=continuous_feature_space_from_columns(tuple(data.columns)), branch_length_data_df=data,
                edge_branch_length_variance_policy=params["edge_branch_length_variance_policy"],
                adaptive_projection_dimension_energy_fraction=0.90, sibling_split_count_rule_out=True,
                **_tbs_branch_length_optimization_kwargs(params),
                extra={"feature_family_diffusion_fallback_reason": None})
            labels = np.asarray(result.labels, dtype=int)
            bh = result.extra["annotations"]["Sibling_BH_Different"].astype(bool)
            splits = [{**s, "bh_different": bool(bh[s["node"]])} for s in STATE["splits"]]
            row = {"method": method, "arm": arm, "status": result.status.value, "found_clusters": result.found_clusters,
                   "ari_cell_line": adjusted_rand_score(truth, labels), "nmi_cell_line": normalized_mutual_info_score(truth, labels),
                   "recovered_lines_90_90": recovered_lines(truth, labels),
                   "ari_published_CHOIR_1": adjusted_rand_score(metadata.CHOIR_1, labels),
                   "sec": perf_counter() - start, "splits": splits}
            f.write(json.dumps(row, default=float) + "\n")
            pd.DataFrame({"cell": metadata.index, "Cell_line": truth, "cluster": labels}).to_csv(
                out / f"assignments_{arm}.csv.gz", index=False)
            print(json.dumps({k: v for k, v in row.items() if k != "splits"}, default=float), flush=True)
    distances._mmap.close()
    distance_path.unlink()


def benchmark():
    from benchmarks.shared.benchmark_runs.runtime import apply_single_thread_runtime_defaults
    from benchmarks.shared.cases import get_test_cases_by_suite
    from benchmarks.shared.pipeline import benchmark_cluster_algorithm
    from benchmarks.shared.runners.method_registry import METHOD_SPECS

    methods = ["tbs_family_diffusion", "tbs_family_diffusion_markov_ward"]
    apply_single_thread_runtime_defaults()
    opt_in = {m: {**METHOD_SPECS[m].param_grid[0], "sibling_split_count_rule_out": True} for m in methods}
    frames, splits = [], []
    for arm, params in (("rule_out", {m: [dict(METHOD_SPECS[m].param_grid[0]), opt_in[m]] for m in methods}),
                        ("ceiling3", {m: [opt_in[m]] for m in methods})):
        STATE.update(arm=arm, splits=[])
        results = benchmark_cluster_algorithm(test_cases=get_test_cases_by_suite("continuous"), methods=methods,
                                              method_params=params, verbose=False, plot_umap=False,
                                              include_cover_pages=False, include_validation_page=False,
                                              allow_method_errors=True)
        results["arm"] = np.where(results.params.str.contains("sibling_split_count_rule_out=True"), arm, "today")
        frames.append(results)
        splits += [{"arm": arm, **s} for s in STATE["splits"]]
    pd.concat(frames).to_csv(HERE / "benchmark_results.csv", index=False)
    (HERE / "benchmark_splits.jsonl").write_text("".join(json.dumps(s, default=float) + "\n" for s in splits))


if __name__ == "__main__":
    if sys.argv[1] == "real":
        real(sys.argv[2])
        os._exit(0)  # shortcut: interpreter teardown stalled after earlier full-data runs (run_lbfgsb.py)
    benchmark()

# ===== summarize.py =====
"""Summaries for protocol.md: replay checks, real-data metrics and split facts, benchmark table."""
import json
import sys
from pathlib import Path

import numpy as np
import pandas as pd

HERE = Path(__file__).resolve().parent
OLD_REAL = HERE.parent / "split_count_exclusion_real_20261108"
OLD_BENCH = HERE.parent / "rule_out_continuous_benchmark_20261108" / "results.csv"
METHODS = {"tbs_family_diffusion": "default", "tbs_family_diffusion_markov_ward": "markov_ward"}
pd.set_option("display.width", 220)
BINS, NAMES = [1, 31, 159, 999, 50000], ["<=31", "32-159", "160-999", "1000+"]


def real():
    rows, splits = [], []
    old = pd.read_csv(OLD_REAL / "metrics.csv")
    for method, short in METHODS.items():
        path = HERE / method / "results.jsonl"
        if not path.exists():
            continue
        for r in map(json.loads, path.read_text().splitlines()):
            a = pd.read_csv(HERE / method / f"assignments_{r['arm']}.csv.gz")
            t = pd.crosstab(a.Cell_line, a.cluster)
            purity = t.max(axis=0) / t.sum(axis=0)
            rows.append({"method": short, "arm": r["arm"], "clusters": r["found_clusters"], "ari": r["ari_cell_line"],
                         "nmi": r["nmi_cell_line"], "lines_90_90": r["recovered_lines_90_90"],
                         "ari_choir1": r["ari_published_CHOIR_1"], "clusters_ge90_pure": int((purity >= 0.9).sum()),
                         "clusters_lt20_cells": int((t.sum(axis=0) < 20).sum()),
                         "largest_cluster": int(t.sum(axis=0).max()),
                         "median_clusters_per_line": float((t >= 0.05 * t.sum(axis=1).to_numpy()[:, None]).sum(axis=1).median()),
                         "sec": round(r["sec"])})
            splits += [{"method": short, "arm": r["arm"], **s} for s in r["splits"]]
    m = pd.DataFrame(rows)
    print("REAL: earlier runs (2026-11-08 harness)\n", old.round(3).to_string(index=False), "\n")
    print("REAL: this run\n", m.round(3).to_string(index=False), "\n")
    for _, r in m[m.arm == "rule_out"].iterrows():
        o = old[(old.method == r.method) & (old.arm == "rule_out")].iloc[0]
        print(f"replay {r.method}: clusters {r.clusters} vs {o.clusters}, ARI {r.ari:.4f} vs {o.ari:.4f}")
    s = pd.DataFrame(splits)
    s["bin"] = pd.cut(s.n_parent, BINS, labels=NAMES)
    s["kept"] = s.p <= 0.01
    print("\nREAL: tested splits by size (kept = p <= 0.01 before BH; accepted = BH)")
    print(s.groupby(["method", "arm", "bin"], observed=True).agg(
        tested=("p", "size"), kept=("kept", "mean"), accepted=("bh_different", "mean")).round(3).to_string())
    c = s[s.arm == "ceiling3"]
    has_k = c[c.k > 0]
    print("\nREAL ceiling3: splits with k >= 1, rho and k by size")
    print(has_k.groupby(["method", "bin"], observed=True).agg(
        n=("rho", "size"), k_median=("k", "median"), rho_median=("rho", "median"),
        rho_q10=("rho", lambda x: x.quantile(0.1)), rho_q90=("rho", lambda x: x.quantile(0.9)),
        above_3=("rho", lambda x: (x > 3).mean())).round(3).to_string())
    both = s.pivot_table(index=["method", "node"], columns="arm", values="kept", aggfunc="first").dropna()
    print("\nREAL: same split tested in both arms, kept by rule_out x ceiling3")
    for method, g in both.groupby(level=0):
        print(method, pd.crosstab(g.rule_out, g.ceiling3).to_dict())
    m.round(4).to_csv(HERE / "real_metrics.csv", index=False)


def benchmark():
    b = pd.read_csv(HERE / "benchmark_results.csv")
    old = pd.read_csv(OLD_BENCH)
    old["arm"] = np.where(old.params.str.contains("sibling_split_count_rule_out=True"), "rule_out", "today")
    key = ["case_id", "method", "arm"]
    replay = b[b.arm != "ceiling3"].merge(old[key + ["found_clusters", "ari"]], on=key, suffixes=("", "_old"))
    same = (replay.found_clusters == replay.found_clusters_old) & np.isclose(replay.ari, replay.ari_old)
    print(f"BENCHMARK replay: {int(same.sum())}/{len(replay)} rows with the same clusters and ARI")
    print(replay.loc[~same, key + ["found_clusters", "found_clusters_old", "ari", "ari_old"]].to_string(index=False))
    b["cell"] = b.found_clusters.astype(str) + ", " + b.ari.map("{:.3f}".format)
    b["m"] = b.method.map(METHODS)
    table = b.pivot_table(index=["case_id", "true_clusters", "samples", "features"], columns=["m", "arm"],
                          values="cell", aggfunc="first")
    print("\nBENCHMARK: found clusters, ARI\n", table.to_string())
    print("\nmean ARI\n", b.groupby(["m", "arm"]).ari.mean().round(3).to_string())
    print("exact cluster count\n", b.assign(exact=b.found_clusters == b.true_clusters)
          .groupby(["m", "arm"]).exact.sum().to_string())
    s = pd.read_json(HERE / "benchmark_splits.jsonl", lines=True)
    c = s[s.arm == "ceiling3"].copy()
    c["case"] = c["shape"].map(tuple)
    print("\nBENCHMARK ceiling3 splits per data shape (cells, features)")
    print(c.groupby("case").agg(tested=("p", "size"), with_k=("k", lambda x: (x > 0).sum()),
                                kept=("p", lambda x: (x <= 0.01).sum()), rho_max=("rho", "max")).to_string())


if __name__ == "__main__":
    {"real": real, "benchmark": benchmark}[sys.argv[1]]()

# ===== breakdown.py =====
"""Added after the endpoints (deviations.md): why lines miss 90/90 - split across clusters, merged with others, or both."""
from pathlib import Path

import pandas as pd

HERE = Path(__file__).resolve().parent
for method in ("tbs_family_diffusion", "tbs_family_diffusion_markov_ward"):
    for arm in ("rule_out", "ceiling3"):
        a = pd.read_csv(HERE / method / f"assignments_{arm}.csv.gz")
        t = pd.crosstab(a.Cell_line, a.cluster)
        main = t.idxmax(axis=1)
        split = t.max(axis=1) / t.sum(axis=1) < 0.9  # under 90% of the line in its main cluster
        merged = (t.max(axis=0) / t.sum(axis=0))[main].to_numpy() < 0.9  # main cluster under 90% this line
        print(method, arm, {"lines": len(t), "recovered": int((~split & ~merged).sum()),
                            "split_only": int((split & ~merged).sum()), "merged_only": int((~split & merged).sum()),
                            "both": int((split & merged).sum())})

# ===== merge_protocol.md =====
# Protocol: which cell lines ceiling 3 merges (frozen 2026-11-09, before running merges.py)

User choice: check which cell lines ceiling 3 merges and whether they are the small ones. Markov/Ward
assignments of `run.py real` (arms rule_out and ceiling3); no new fits.

1. Per line and arm: status recovered / split only / merged only / both (as `breakdown.py`).
2. Lines merged under ceiling3 (merged only or both): size against all 190 line sizes (median, rank
   percentile), status under rule_out, cancer type.
3. Each ceiling3 cluster holding two or more lines with >= 5% of its cells: composition. For its two largest
   lines, the true-label split on the 30 PCs: n, share pi, k invariant directions, rho, p under ceiling 3 and
   under the Gaussian ceiling (`cut_rule.cut_bound_p`), and whether rule_out and the published CHOIR_1 put the
   two lines in different clusters.

Expected: if the merges come from the constant ceiling asking small groups for a larger gap, the merged lines
are smaller than typical and their true-label splits have small pi and rho below 3 but above g(pi).

    invariant_directions,

def status(a):
    t = pd.crosstab(a.Cell_line, a.cluster)
    split = t.max(axis=1) / t.sum(axis=1) < 0.9
    merged = pd.Series((t.max(axis=0) / t.sum(axis=0))[t.idxmax(axis=1)].to_numpy() < 0.9, index=t.index)
    return pd.Series(np.select([split & merged, split, merged], ["both", "split", "merged"], "recovered"), index=t.index)


meta = pd.read_csv(SOURCE / "cell_metadata.csv", index_col=0, dtype=str)
pca = np.load(SOURCE / "pca.npy")
row = {c: i for i, c in enumerate(meta.index)}
arms = {arm: pd.read_csv(METHOD / f"assignments_{arm}.csv.gz") for arm in ("rule_out", "ceiling3")}
sizes = meta.Cell_line.value_counts()
lines = pd.DataFrame({"size": sizes, "size_pct": sizes.rank(pct=True).round(2),
                      "cancer": meta.groupby("Cell_line").Cancer_type.first()})
for arm, a in arms.items():
    lines[arm] = status(a)
print("status counts\n", pd.crosstab(lines.rule_out, lines.ceiling3), "\n")
print("line size by ceiling3 status\n", lines.groupby("ceiling3")["size"].describe().round(0).to_string(), "\n")
merged = lines[lines.ceiling3.isin(["merged", "both"])].sort_values("size")
print("lines merged under ceiling3\n", merged.to_string(), "\n")

c3 = arms["ceiling3"].set_index("cell")
ro = arms["rule_out"].set_index("cell").cluster
rows = []
for cluster, cells in c3.groupby("cluster"):
    share = cells.Cell_line.value_counts(normalize=True)
    big = share[share >= 0.05]
    if len(big) < 2:
        continue
    a_line, b_line = big.index[:2]
    pick = cells[cells.Cell_line.isin([a_line, b_line])]
    points = pca[[row[c] for c in pick.index]]
    in_a = (pick.Cell_line == a_line).to_numpy()
    directions = invariant_directions(points)
    p3, rho = cut_bound_p(points @ directions.T, in_a, unimodal_bound)
    pg, _ = cut_bound_p(points @ directions.T, in_a, gaussian_bound)
    pi = float(min(in_a.mean(), 1 - in_a.mean()))

    def apart(labels):
        main = labels.loc[pick.index].groupby(pick.Cell_line.to_numpy()).agg(lambda x: x.value_counts().idxmax())
        return bool(main[a_line] != main[b_line])

    rows.append({"cluster": cluster, "cells": len(cells), "lines_ge5pct": len(big),
                 "pair": f"{a_line} + {b_line}", "n": len(pick), "pi": round(pi, 3), "k": len(directions),
                 "rho": rho, "g_pi": gaussian_bound(pi), "p_ceiling3": p3, "p_gaussian": pg,
                 "apart_rule_out": apart(ro), "apart_choir1": apart(meta.CHOIR_1)})
m = pd.DataFrame(rows).sort_values("rho")
print("ceiling3 clusters with >= 2 lines at >= 5%: true-label split of the two largest lines\n",
      m.round(3).to_string(index=False))
lines.to_csv(HERE / "merge_lines.csv")
m.to_csv(HERE / "merge_pairs.csv", index=False)

# ===== trace_protocol.md =====
# Protocol: why the Markov/Ward tree hides the line boundary (2026-11-09)

User choice: find why the tree does not offer the line boundary for the 27 merged pairs whose true-label split
passes ceiling 3 (`merge_pairs.csv`: k >= 1, p_ceiling3 <= 0.01).

1. `trace_fit.py`: refit Markov/Ward with ceiling3 exactly as `run.py real` and keep the tree, annotations and
   split records. Replay: the same 1,838 tested splits and BH decisions as the earlier ceiling3 run (the
   cluster labels were not printed because `os._exit` dropped buffered output; checked on the splits).
   Result: 120 BH acceptances in both; p-values equal to the last digits (59 differ by float rounding only).
2. `trace.py`, per pair, inside its ceiling3 cluster:
   - cluster node: the smallest tree node holding all the cluster's cells; why traversal stopped there (child
     edge flags, sibling skipped, sibling p, BH decision, k and rho of its split);
   - boundary node: the smallest node holding all cells of both lines in the cluster; its depth below the
     cluster node; how its two children divide the two lines (share of each line in its majority child);
   - best tree node per line (F1 against the line's cells in the cluster).
3. Classify each pair: (a) boundary is the cluster node's own split, stopped by the sibling rule or an edge
   gate; (b) boundary deeper, the cluster node's split cuts elsewhere and was not accepted, so traversal never
   reached the boundary; (c) no node separates the lines (best F1 < 0.9 for either line).

Descriptive; no production change.

"""trace_protocol.md step 2-3: where the line boundary sits in the tree for the 27 merged pairs, and why it is not reached."""
import json
import pickle
from pathlib import Path

import networkx as nx
import numpy as np
import pandas as pd

HERE = Path(__file__).resolve().parent
pd.set_option("display.width", 250)
tree = pickle.load((HERE / "trace" / "tree.pkl").open("rb"))
ann = pd.read_csv(HERE / "trace" / "annotations.csv", index_col=0, low_memory=False)
splits = {s["node"]: s for s in map(json.loads, (HERE / "trace" / "splits.jsonl").read_text().splitlines())}
assign = pd.read_csv(HERE / "tbs_family_diffusion_markov_ward" / "assignments_ceiling3.csv.gz").set_index("cell")
pairs = pd.read_csv(HERE / "merge_pairs.csv")
pairs = pairs[(pairs.k > 0) & (pairs.p_ceiling3 <= 0.01)].reset_index(drop=True)
assert len(pairs) == 27, len(pairs)

order = list(nx.topological_sort(tree))[::-1]  # children before parents
leaf_cell = {n: tree.nodes[n]["label"] for n in tree if tree.out_degree(n) == 0}
total = {}
for n in order:
    total[n] = 1 if n in leaf_cell else sum(total[c] for c in tree.successors(n))


def counts(cells):
    """Number of the given cells below each node."""
    member = set(cells)
    out = {}
    for n in order:
        out[n] = int(leaf_cell[n] in member) if n in leaf_cell else sum(out[c] for c in tree.successors(n))
    return out


def smallest_holding(cnt, size):
    return min((n for n, v in cnt.items() if v == size), key=total.get)


def depth_between(top, node):
    return nx.shortest_path_length(tree, top, node)


def node_facts(n):
    kids = list(tree.successors(n))
    a = ann.loc[n]
    s = splits.get(n, {})
    return {"children": [total[c] for c in kids], "edge_sig": [bool(ann.loc[c, "Child_Parent_Divergence_Significant"]) for c in kids],
            "skipped": bool(a.Sibling_Divergence_Skipped), "bh_different": bool(a.Sibling_BH_Different),
            "k": s.get("k"), "rho": s.get("rho"), "p": s.get("p")}


rows = []
for _, pr in pairs.iterrows():
    line_a, line_b = pr.pair.split(" + ")
    cells = assign[assign.cluster == pr.cluster]
    c_all = counts(cells.index)
    top = smallest_holding(c_all, len(cells))
    ca, cb = counts(cells.index[cells.Cell_line == line_a]), counts(cells.index[cells.Cell_line == line_b])
    na, nb = ca[top], cb[top]
    both = {n: ca[n] + cb[n] for n in order}
    boundary = smallest_holding(both, na + nb)
    kids = list(tree.successors(boundary))
    a_major = max(ca[k] for k in kids) / na
    b_major = max(cb[k] for k in kids) / nb
    same_child = int(np.argmax([ca[k] for k in kids])) == int(np.argmax([cb[k] for k in kids]))
    f1 = lambda c, n_line: max(2 * c[n] / (total[n] + n_line) for n in nx.descendants(tree, top) | {top})  # noqa: E731
    top_f, bnd_f = node_facts(top), node_facts(boundary)
    rows.append({"pair": pr.pair[:44], "cluster_cells": len(cells), "cluster_node_cells": total[top],
                 "top_children": top_f["children"], "top_edge_sig": top_f["edge_sig"], "top_skipped": top_f["skipped"],
                 "top_k": top_f["k"], "top_rho": top_f["rho"], "top_p": top_f["p"], "top_bh": top_f["bh_different"],
                 "boundary_depth": depth_between(top, boundary), "boundary_cells": total[boundary],
                 "a_in_major_child": round(a_major, 2), "b_in_major_child": round(b_major, 2), "lines_same_child": same_child,
                 "boundary_k": bnd_f["k"], "boundary_rho": bnd_f["rho"], "boundary_p": bnd_f["p"],
                 "true_rho": pr.rho, "best_f1_a": round(f1(ca, na), 2), "best_f1_b": round(f1(cb, nb), 2)})
t = pd.DataFrame(rows)


def kind(r):
    if min(r.best_f1_a, r.best_f1_b) < 0.9:
        return "c_no_node_separates"
    return "a_boundary_is_top_split" if r.boundary_depth == 0 else "b_boundary_deeper"


t["kind"] = t.apply(kind, axis=1)
t["top_stop"] = np.where(~t.top_edge_sig.map(any), "edge_gate", np.where(t.top_skipped, "sibling_skipped",
                         np.where(t.top_p.fillna(1) > 0.01, "ceiling3_p", "bh")))
print(t.drop(columns=["pair"]).assign(pair=t.pair).round(3).to_string(index=False), "\n")
print(pd.crosstab(t.kind, t.top_stop), "\n")
print("top split rho (median by kind)\n", t.groupby("kind")[["top_rho", "true_rho", "boundary_rho"]].median().round(2))
t.to_csv(HERE / "trace_pairs.csv", index=False)

# rho a split of this size, share and dimension needs for p <= 0.01 under ceiling 3 (bisection on cut_rule's tail)
import sys  # noqa: E402

sys.path.insert(0, str(HERE.parent / "gaussian_cut_rule_20261108"))
from cut_rule import log_flat_cuts  # noqa: E402
from scipy.optimize import brentq  # noqa: E402
from scipy.stats import ncx2  # noqa: E402


def needed_rho(n, k, bound=3.0):
    return brentq(lambda r: log_flat_cuts(n, k) + ncx2.logsf(n * r, k, n * bound) - np.log(0.01), bound, 100.0)


t["top_needed_rho"] = [needed_rho(r.cluster_node_cells, int(r.top_k)) if r.top_k == r.top_k else np.nan for r in t.itertuples()]
t["clean_boundary"] = (~t.lines_same_child) & (t.a_in_major_child >= 0.85) & (t.b_in_major_child >= 0.85) & (t.boundary_depth == 0)
print(t[["pair", "cluster_node_cells", "top_k", "top_rho", "top_needed_rho", "true_rho", "a_in_major_child",
         "b_in_major_child", "clean_boundary", "top_stop"]].round(2).to_string(index=False))
print("\nclean boundary at the top split:", int(t.clean_boundary.sum()), "| needed rho median",
      round(t.top_needed_rho.median(), 2), "range", round(t.top_needed_rho.min(), 2), "-", round(t.top_needed_rho.max(), 2))
t.to_csv(HERE / "trace_pairs.csv", index=False)
