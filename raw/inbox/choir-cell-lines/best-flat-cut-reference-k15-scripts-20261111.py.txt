# ===== protocol.md =====
# # Protocol: the Gaussian best-flat-cut reference extended to 11 to 15 invariant directions (frozen 2026-11-11, before any run)
#
# Reason: on the 48,879 CHOIR cells every split with 1,000 cells or more has 11 to 15 invariant directions and the
# opt-in `sibling_best_flat_cut_reference` returns p = 1 for them (`too_many_invariant_directions`, 190 splits on
# the Markov/Ward tree). The opt-in stays opt-in; no default changes.
#
# ## Part 1: production change
#
# - `scripts/build_best_flat_cut_reference.py`: `K_GRID` becomes 1 to 15. A new option `--k-min` computes only the
#   cells with k at or above it and takes the others from the existing table (same n grid, B and seed required),
#   so the cells for k up to 10 stay exactly as they are. The search is unchanged (grid of 3,000 directions for
#   k above 6, re-sorts from the top 50, single-point moves), B = 1,999, seed `[20261110, 81, n, k, block]`.
# - For k above 10 the cells with n below 50 are not built: at n = 15 the whitening fails for k = 15 and `rho` is
#   3,000 to 1e10 for k = 11 and 13 (timing run). They are stored as NaN and the module fails closed there with
#   reason `too_few_cells`. Nodes with 11 or more invariant directions in 30 features have more than 31 cells
#   anyway.
# - `best_flat_cut_reference.py`: `MAX_DIRECTIONS` becomes 15; the docstring states what is and is not known for k
#   above 10 (below). Tests 82, 83 and integration 66 and the statistics README follow.
# - Check: the cells for k up to 10 are bit-identical to the table before the change; two of them are recomputed
#   from their seeds and equal the stored values; the new cells are finite, rise with k and fall with n.
#
# ## What is known for k above 10 (recorded earlier, wiki page gaussian-best-flat-cut-reference)
#
# The search does not reliably find the best flat cut for k of 15 and 20: its 99% points are lower bounds. The
# stored null is therefore the null of the searched value. It is exact for a statistic that is itself the
# searched value. For an arbitrary split (the tree's split) the argument "any split's `rho` is at most the best
# flat cut's `rho`" still holds for the true best flat cut, but not for the searched value, so the p-value for k
# above 10 is not guaranteed conservative. Part 2 measures this.
#
# ## Part 2: validity study under one Gaussian population (no production file)
#
# For k = 11, 13, 15 and n = 200 and 800, with the 99% point of the searched null from the builder's own cells:
#
# 1. Fresh datasets: the searched value's rejection rate at the 99% point (about 1% expected).
# 2. The split of a Ward tree built on the same data (root split): its `rho` against the 99% point. This is the
#    use in the pipeline. Expected far below 1%.
# 3. Stronger searches than the table's (more directions; single-point moves started from the Ward split and
#    from the table's result): how often and by how much they exceed the searched value, and how often they exceed
#    the 99% point. This is the size of the gap. Expected above 1% at k = 15; how much is not predicted.
# 4. k chosen by `invariant_directions` in 30 features with 11 to 15 strong directions (n = 400 and 2,000): the
#    rejection rate of the Ward root split and of the searched value through the whole function
#    `best_flat_cut_reference`.
#
# At least 1,000 datasets per cell for the rates, exact binomial intervals, seeds stated, counts reported.
#
# ## Part 3: the real data again (harness of `spr_refit_20261111`)
#
# The unchanged Markov/Ward tree and the tree after the sprs (`tree_spr.npz`) through the harness with the
# extended reference. Endpoints as in `spr_refit_20261111` (clusters, ARI, NMI, lines recovered, split only,
# merged only, both, largest cluster, tested, kept, accepted), plus the reasons and verdicts of the splits with
# 11 to 15 invariant directions.
#
# ## Expected before running
#
# - 99% points at n = 800 near the run-time values of the divisive trial (399 datasets): 2.533, 2.562, 2.600,
#   2.659, 2.682 for k = 11 to 15.
# - Real data: ceiling 3 accepted 77 of the 190 large splits. With the extension a comparable part should pass, the
#   largest cluster (7,678 cells, 40 lines) should break up and the ARI should rise well above 0.30; the exact value
#   is not predicted. Splits at the lowest possible p that BH refuses will remain.
# - n above 800 is rounded down to 800, which is strict.
#
# ## Limits known before running
#
# The reference for k above 10 is measured, not guaranteed; one Gaussian population only; k is chosen from the
# same data; the real-data part is one dataset and one tree; the p-value floor 1/2,000 and its interaction with
# BH are unchanged; no benchmark panel is run in this protocol.

# ===== part2_deviations.md =====
# # Part 2 deviations from protocol.md
#
# 1. Step 3 ("single-point moves started from the Ward split and from the table's result"): moves started from
#    the table's result are already part of the table's search (`best_flat_cut_rho` ends with `swap`), so they
#    add nothing. Instead, three stronger searches were run: (a) the table's search with 30,000 directions
#    (`grid(k, 30000, stream=1)`, top 50, re-sorts and moves); (b) re-sorts and moves started from the Ward root
#    split; (c) the same from 20 random half-splits. Step 3 used the first 600 (n = 200) and 300 (n = 800)
#    datasets of step 1, so the searched value there is the step-1 value of the same dataset.
# 2. Step 4, "the searched value through the whole function `best_flat_cut_reference`": while Part 1 was being
#    changed the stored table could not be relied on, so the whole function was not called. The same quantity
#    was computed directly: `d = invariant_directions(points)`, `rho = split_rho(points @ d.T, in_left)`, compared
#    with the 20th largest of this study's own null cell at (n rounded down to 400 or 800, k = len(d)). The
#    searched value in the chosen directions (`best_flat_cut_rho(points @ d.T)`) was run on the first 200
#    datasets per cell only (about 1.5 s each at n = 2,000), not 1,000; its rate is secondary to the tree split.
# 3. Step 4 data: one Gaussian population in 30 features, variance 25 on the first k coordinates and 1 on the
#    other 30 - k. Datasets whose chosen k has no null cell in this study would be left untested and counted;
#    see `not_tested_k_outside_cells` in part2_results.json. Outcome: none; k was the intended value in all
#    6,000 datasets.
# 4. The null cells were computed by importing `block_job` from `scripts/build_best_flat_cut_reference.py`
#    while Part 1 was editing that file; the source of every imported function was hashed at start
#    (`source_hashes` in part2_results.json) and workers were forked from that one import. After the run the
#    nine null cells were compared, read-only, with the extended table Part 1 had written: the top 200 values
#    agree in all nine cells (float32).
# 5. Step 3 sizes were not reduced: 600 datasets at n = 200 and 300 at n = 800 (wall time 2,000 s in total).

    print(f"   {name}: {'equal' if ok else 'DIFFERENT'}")

print("      n " + "".join(f"{k:>8}" for k in k_grid[9:]))

# ===== part2_validity.py =====
"""Part 2 of protocol.md: is the searched null of the best flat cut safe for a tree split at k = 11 to 15?

Run (repository root):

    OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 uv run --no-sync --offline python \\
        results/analyses/best_flat_cut_reference_k15_20261111/part2_validity.py

Phases (each is written to part2_results.json when done; a rerun skips finished phases):
  null    step 0: the builder's own null cells (block_job, B = 1,999, seed [20261110, 81, n, k, block]).
  fresh   steps 1 to 3 on fresh N(0, I_k) datasets, seed [20261111, 1, n, k, i]; step 3 on the first N3[n].
  chosen  step 4: 30 features, k strong directions of variance 25, the rest 1; seed [20261111, 4, n, k, i].
Rejection at 0.01 means p = (1 + #{null >= rho}) / 2000 <= 0.01, i.e. rho above the 20th largest null value.
"""

from __future__ import annotations

import hashlib
import inspect
import json
import math
import multiprocessing as mp
import sys
import time
from pathlib import Path

import numpy as np
from scipy.cluster.hierarchy import linkage, to_tree
from scipy.stats import binomtest

ROOT = Path(__file__).resolve().parents[3]
sys.path.insert(0, str(ROOT / "scripts"))
import build_best_flat_cut_reference as builder  # noqa: E402

from tree_break_selection.hierarchy_analysis.statistics.sibling_divergence import (  # noqa: E402
    best_flat_cut_reference as module,
)
from tree_break_selection.hierarchy_analysis.statistics.sibling_divergence.split_count_rule_out import (  # noqa: E402
    invariant_directions,
)

OUT = Path(__file__).with_name("part2_results.json")
SEED = 20261111
WORKERS = 5
B = 1999
RANK = 20  # the 99% point is the 20th largest of B = 1,999
K_CELLS = (11, 13, 15)
N_NULL = (200, 400, 800)
N_FRESH = (200, 800)
N1 = 1000  # steps 1 and 2
N3 = {200: 600, 800: 300}  # step 3, first datasets of step 1
N_CHOSEN = (400, 2000)
N4 = 1000
N4_SEARCH = 200  # searched value through the k chosen from the data, first datasets only
STRONG_VAR, P = 25.0, 30
DIRS_STRONG, STREAM_STRONG, RANDOM_STARTS = 30000, 1, 20


def log(msg):
    print(f"[{time.strftime('%H:%M:%S')}] {msg}", flush=True)


def ward_root(x):
    root = to_tree(linkage(x, "ward"))
    mask = np.zeros(len(x), bool)
    mask[root.get_left().pre_order()] = True
    return mask


def climb(y, mask):
    """Re-sorts and single-point moves from a start mask (the builder's resort and swap)."""
    s = mask.sum()
    r2 = float((y[mask].sum(0) ** 2).sum() / (s * (len(y) - s)))
    r2, mask = builder.resort(y, mask, r2)
    r2, _ = builder.swap(y, mask, r2)
    return r2


def fresh_job(job):
    n, k, i, strong = job
    rng = np.random.default_rng([SEED, 1, n, k, i])
    x = rng.standard_normal((n, k))
    mask = ward_root(x)
    out = {"searched": builder.best_flat_cut_rho(x), "tree": module.split_rho(x, mask)}
    if strong:
        y = module.whiten(x)
        out["dirs30k"] = builder.search(
            x, builder.grid(k, DIRS_STRONG, stream=STREAM_STRONG), top=50, local_swap=True
        )
        out["from_ward"] = module.to_rho(climb(y, mask), n)
        starts = []
        for _ in range(RANDOM_STARTS):
            m = np.zeros(n, bool)
            m[rng.permutation(n)[: n // 2]] = True
            starts.append(climb(y, m))
        out["random20"] = module.to_rho(max(starts), n)
    return out


def chosen_job(job):
    n, k, i, with_search = job
    rng = np.random.default_rng([SEED, 4, n, k, i])
    sd = np.r_[np.full(k, math.sqrt(STRONG_VAR)), np.ones(P - k)]
    x = rng.standard_normal((n, P)) * sd
    d = invariant_directions(x)
    mask = ward_root(x)  # the tree is built in all 30 features
    out = {"k": len(d), "tree": float("nan"), "searched": float("nan")}
    if len(d):
        z = x @ d.T
        out["tree"] = module.split_rho(z, mask)
        if with_search:
            out["searched"] = builder.best_flat_cut_rho(z)
    return out


def ci(count, total):
    lo, hi = binomtest(count, total).proportion_ci(0.95, method="exact")
    return {"count": int(count), "n": int(total), "rate": count / total, "ci95": [lo, hi]}


def phase_null(pool):
    blocks = [(b, min(100, B - b * 100)) for b in range(math.ceil(B / 100))]
    jobs = [(n, k, b, size) for n in N_NULL for k in K_CELLS for b, size in blocks]
    samples = {}
    for done, (n, k, _b, rho) in enumerate(pool.imap(builder.block_job, jobs), 1):
        samples.setdefault(f"{n},{k}", []).extend(rho)
        if done % 20 == 0:
            log(f"null {done}/{len(jobs)} blocks")
    cells = {}
    for key, values in samples.items():
        v = np.sort(values)
        assert len(v) == B
        cells[key] = {"q99": float(v[-RANK]), "upper200": v[-200:].tolist()}
        log(f"null cell n,k={key}: 99% point (20th largest of {B}) = {v[-RANK]:.4f}")
    return cells


def phase_fresh(pool, cells):
    res = {}
    for n in N_FRESH:
        for k in K_CELLS:
            q = cells[f"{n},{k}"]["q99"]
            jobs = [(n, k, i, i < N3[n]) for i in range(N1)]
            rows = list(pool.imap(fresh_job, jobs, chunksize=4))
            searched = np.array([r["searched"] for r in rows])
            tree = np.array([r["tree"] for r in rows])
            ratio = tree / q
            cell = {
                "q99": q,
                "step1_searched_reject": ci(int((searched > q).sum()), N1),
                "step2_tree_reject": ci(int((tree > q).sum()), N1),
                "step2_ratio_tree_over_q99": {
                    "median": float(np.median(ratio)),
                    "p99": float(np.quantile(ratio, 0.99)),
                    "max": float(ratio.max()),
                },
                "step2_tree_over_searched_count": int((tree > searched * (1 + 1e-9)).sum()),
            }
            strong = rows[: N3[n]]
            base = np.array([r["searched"] for r in strong])
            best = base.copy()
            step3 = {"datasets": N3[n]}
            for name in ("dirs30k", "from_ward", "random20"):
                v = np.array([r[name] for r in strong])
                gain = v / base - 1
                beats = gain > 1e-9
                step3[name] = {
                    "beats_table_search": ci(int(beats.sum()), len(v)),
                    "gain_median_when_beats": float(np.median(gain[beats])) if beats.any() else 0.0,
                    "gain_max": float(gain.max()),
                    "reject": ci(int((v > q).sum()), len(v)),
                }
                best = np.maximum(best, v)
            gain = best / base - 1
            step3["best_of_all"] = {
                "beats_table_search": ci(int((gain > 1e-9).sum()), len(best)),
                "gain_median_when_beats": float(np.median(gain[gain > 1e-9])) if (gain > 1e-9).any() else 0.0,
                "gain_max": float(gain.max()),
                "reject": ci(int((best > q).sum()), len(best)),
                "searched_reject_same_datasets": ci(int((base > q).sum()), len(base)),
            }
            cell["step3"] = step3
            res[f"{n},{k}"] = cell
            log(f"fresh n={n} k={k}: {json.dumps(cell)}")
    return res


def phase_chosen(pool, cells):
    res = {}
    for n in N_CHOSEN:
        n_cell = 800 if n >= 800 else 400
        for k in K_CELLS:
            jobs = [(n, k, i, i < N4_SEARCH) for i in range(N4)]
            rows = list(pool.imap(chosen_job, jobs, chunksize=8))
            ks = [r["k"] for r in rows]
            dist = {str(v): ks.count(v) for v in sorted(set(ks))}
            tested = [(r, cells[f"{n_cell},{r['k']}"]["q99"]) for r in rows if f"{n_cell},{r['k']}" in cells]
            tree_rej = sum(r["tree"] > q for r, q in tested)
            searched = [(r, q) for r, q in tested if np.isfinite(r["searched"])]
            cell = {
                "reference_cell_n": n_cell,
                "k_distribution": dist,
                "tested": len(tested),
                "not_tested_k_outside_cells": N4 - len(tested),
                "tree_reject": ci(tree_rej, len(tested)),
                "searched_reject": ci(sum(r["searched"] > q for r, q in searched), len(searched)),
                "tree_ratio_max": float(max(r["tree"] / q for r, q in tested)),
            }
            res[f"{n},{k}"] = cell
            log(f"chosen n={n} k={k}: {json.dumps(cell)}")
    return res


def main():
    results = json.loads(OUT.read_text()) if OUT.exists() else {}
    used = [builder.grid, builder.directions, builder._along_one, builder.resort, builder.swap,
            builder.search, builder.best_flat_cut_rho, builder.block_job, module.whiten, module.to_rho,
            module.split_rho, invariant_directions]
    hashes = {f.__name__: hashlib.sha256(inspect.getsource(f).encode()).hexdigest()[:16] for f in used}
    if "source_hashes" in results and results["source_hashes"] != hashes:
        raise SystemExit(f"imported functions changed since the first phase: {hashes}")
    results["source_hashes"] = hashes
    results["builder_constants"] = {"SEED": builder.SEED, "BLOCK": builder.BLOCK}
    log(f"source hashes {hashes}")
    with mp.get_context("fork").Pool(WORKERS) as pool:
        for name, run in (("null", phase_null), ("fresh", phase_fresh), ("chosen", phase_chosen)):
            if name in results:
                log(f"phase {name} already done")
                continue
            t = time.time()
            results[name] = run(pool) if name == "null" else run(pool, results["null"])
            results.setdefault("wall_seconds", {})[name] = time.time() - t
            OUT.write_text(json.dumps(results, indent=1))
            log(f"phase {name} done in {time.time() - t:.0f} s")


if __name__ == "__main__":
    main()
