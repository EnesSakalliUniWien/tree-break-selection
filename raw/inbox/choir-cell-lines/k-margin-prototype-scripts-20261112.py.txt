# ===== protocol.md =====
# # Protocol: prototype of k with a margin at the edge, also for more features than cells (frozen 2026-11-12, before any run)
#
# ## Why
#
# k is the number of invariant directions of a node: `invariant_directions(points)` in
# `tree_break_selection/hierarchy_analysis/statistics/sibling_divergence/split_count_rule_out.py` counts the
# eigenvalues of the node's covariance above `median eigenvalue / MP median(p/n) x (1 + sqrt(p/n))^2` and returns
# none when n <= p + 1. Measured on 2026-11-12 (wiki page `marchenko-pastur-multiplicity-literature`):
#
# - the edge is a limit, not a quantile: one independent Gaussian sample gets k >= 1 in 16.0% to 23.2% of draws;
# - with 30 cells in 40 features the rule returns no direction although a direction exists (Baik and Silverstein
#   2006, Theorem 1.2, has the same threshold for more features than cells);
# - on the benchmark the opt-in `sibling_best_flat_cut_reference` loses real groups where a subtree has no
#   invariant directions (58 of 151 calls, continuous suite mean ARI 0.88 to 0.695).
#
# ## The prototype rule (frozen; file `k_rule.py`, analysis folder only, no production change)
#
# Input: `points` (n cells x p features), level `alpha` (default 0.01), `max_directions` (default None).
#
# 1. Centre the cells. Let lambda_1 >= ... >= lambda_r be the nonzero eigenvalues of the covariance (divisor
#    n - 1), r = min(p, n - 1). For p > n - 1 they come from the n x n Gram matrix of the centred cells.
# 2. Step j = 1, 2, ...: statistic T_j = lambda_j / median(lambda_j, ..., lambda_r).
# 3. Null of step j: T_1 of one spherical Gaussian population with n cells and p - j + 1 features. Its
#    (1 - alpha) quantile q(n, p - j + 1, alpha) is simulated: B = 2,000 draws, seed derived from
#    (n, p - j + 1) so the value is reproducible, cached per (n, p - j + 1). The statistic does not depend on
#    the noise variance, so no noise variance is estimated. The simulation may draw the eigenvalues from a
#    Wishart matrix of dimension min(p', n - 1) with max(p', n - 1) degrees of freedom instead of drawing cells;
#    if it does, the builder checks this against drawing cells.
# 4. Stop at the first j with T_j <= q(n, p - j + 1, alpha), or when j - 1 = `max_directions`, or when fewer than
#    3 eigenvalues remain. k = j - 1. Return the k leading eigenvectors as rows, orthonormal, in the p features,
#    the same contract as `invariant_directions` (a (0, p) array when k = 0).
#
# Interface, used by both parts: `directions_with_margin(points, alpha=0.01, max_directions=None) -> np.ndarray`
# and `null_quantile(n, p, alpha=0.01) -> float`, importable from `k_rule.py` in this folder.
#
# Stated limits of the rule: the null is one spherical Gaussian population, so a single population with unequal
# variances has directions by definition; the choice (n, p - j + 1) for step j is the prototype's own choice and
# is measured, not derived; the directions are still chosen from the cells that are tested afterwards.
#
# ## Part A: the rule and synthetic checks (`a_checks.py`, output `a_checks.txt`, `a_results.json`)
#
# Gaussian data, identity noise unless stated, seed 20261112, the current rule `invariant_directions` beside the
# prototype rule in every row.
#
# - A0 self-checks (asserts): `null_quantile` reproducible; Wishart route equals drawing cells within Monte
#   Carlo error at (64, 30), (30, 40) and (40, 2000); the returned rows are orthonormal eigenvectors; k is
#   unchanged by a shift and by multiplying all cells by a constant.
# - A1 level: one Gaussian population, 2,000 draws each at (n, p) = (64, 30), (128, 30), (256, 30), (800, 30),
#   (200, 80), (30, 40), (40, 2000): share with k >= 1.
#   Prediction: between 0.004 and 0.018 at every size (about the 99% binomial range around 0.01, widened for
#   the Monte Carlo error of the quantile).
# - A2 power: (a) 64 and 256 cells, 30 features, population `rho` 0.15, 0.306, 0.6, 1.0, 1.44; (b) two groups of
#   15 cells in 40 features, `rho` 2.3, 5, 50; (c) two groups of 20 cells in 2,000 features, `rho` 10, 50, 200;
#   1,000 draws each: share with k >= 1.
#   Prediction: below the current rule near sqrt(p/n) in (a), at least 0.99 at `rho` 1.44 in (a), at 50 in (b)
#   and at 200 in (c).
# - A3 count: four balanced groups at equal pairwise distance 6 (three true directions), 400 cells, 30 features;
#   and two groups, 64 and 256 cells, `rho` 1.44 (one true direction); 1,000 draws each: distribution of k.
#   Prediction: k = 3 in at least 0.97; in the two-group case k >= 2 in at most 0.03.
# - A4 one population with unequal variances (variances 4, 2, 1, ..., 1), 256 cells, 30 features, 1,000 draws:

# ===== k_rule.py =====
"""Prototype k with a margin at the edge (protocol.md, section "The prototype rule").

k is the number of steps j at which T_j = lambda_j / median(lambda_j, ..., lambda_r) of the cells'
covariance lies above the (1 - alpha) quantile of T_1 of one spherical Gaussian population with n cells
and p - j + 1 features. Works for p > n - 1 through the n x n Gram matrix of the centred cells.
"""

from __future__ import annotations

from functools import lru_cache

import numpy as np

NULL_DRAWS = 2000


def _statistic(values: np.ndarray) -> float:
    return float(values[0] / np.median(values))


@lru_cache(maxsize=None)
def _null_draws(n: int, p: int) -> np.ndarray:
    """B draws of T_1 under one spherical Gaussian population with n cells and p features.

    The nonzero eigenvalues are those of a Wishart matrix of dimension d = min(p, n - 1) with
    m = max(p, n - 1) degrees of freedom (scale is irrelevant), drawn by the Bartlett decomposition.
    """
    if n < 2 or p < 1:
        raise ValueError(f"null_quantile needs n >= 2 and p >= 1, got n={n}, p={p}.")
    d, m = min(p, n - 1), max(p, n - 1)
    rng = np.random.default_rng((n, p))
    lower = np.tril(rng.normal(size=(NULL_DRAWS, d, d)), k=-1)
    diagonal = np.sqrt(rng.chisquare(m - np.arange(d), size=(NULL_DRAWS, d)))
    lower[:, np.arange(d), np.arange(d)] = diagonal
    values = np.linalg.eigvalsh(lower @ lower.transpose(0, 2, 1))
    return np.sort(values[:, -1] / np.median(values, axis=1))


def null_quantile(n: int, p: int, alpha: float = 0.01) -> float:
    """(1 - alpha) quantile of T_1 for one spherical Gaussian population of n cells in p features."""
    return float(np.quantile(_null_draws(int(n), int(p)), 1 - alpha))


def directions_with_margin(
    points: np.ndarray, alpha: float = 0.01, max_directions: int | None = None
) -> np.ndarray:
    """Return the k leading covariance eigenvectors (rows, orthonormal, p features); (0, p) when k = 0."""
    points = np.asarray(points, dtype=np.float64)
    n, p = points.shape
    if n < 2:
        return np.zeros((0, p))
    centred = points - points.mean(axis=0)
    r = min(p, n - 1)
    gram = p > n - 1  # nonzero eigenvalues from the n x n Gram matrix of the centred cells
    matrix = centred @ centred.T if gram else centred.T @ centred
    values, vectors = np.linalg.eigh(matrix / (n - 1))
    values, vectors = values[::-1][:r], vectors[:, ::-1]
    k = 0
    while (max_directions is None or k < max_directions) and r - k >= 3:
        if _statistic(values[k:]) <= null_quantile(n, p - k, alpha):
            break
        k += 1
    vectors = vectors[:, :k]
    if gram and k:
        vectors = centred.T @ vectors / np.sqrt((n - 1) * values[:k])
    return vectors.T.reshape(k, p)


__all__ = ["directions_with_margin", "null_quantile"]

def two_groups(sizes, p, rho):
    """Copied from marchenko_pastur_multiplicity_20261112/checks.py: the first feature separates the groups
    so that pi(1-pi)d^2 = rho."""
    n = sum(sizes)
    share = sizes[0] / n
    d = np.sqrt(rho / (share * (1 - share)))
    points = rng.normal(size=(n, p))
    points[: sizes[0], 0] += d
    return points


def four_groups(n, p=30):
    """As C4 of checks.py: centroids at the vertices of a regular simplex with pairwise distance 6."""
    points = rng.normal(size=(n, p))
    for g in range(4):
        points[g * n // 4 : (g + 1) * n // 4, g] += 6 / np.sqrt(2)
    return points


def unequal_variances(n=256, p=30):
    scale = np.ones(p)
    scale[:2] = np.sqrt([4.0, 2.0])
    return rng.normal(size=(n, p)) * scale


def both_rules(make, draws):
    current, prototype = [], []
    for _ in range(draws):
        points = make()
        current.append(len(invariant_directions(points)))
        prototype.append(len(directions_with_margin(points)))
    return np.array(current), np.array(prototype)


def row(key, label, current, prototype):
    total = len(current)
    entry = {"total": total}
    for name, ks in (("current", current), ("prototype", prototype)):
        values, counts = np.unique(ks, return_counts=True)
        entry[name] = {
            "k_ge_1": int((ks >= 1).sum()),
            "k_ge_2": int((ks >= 2).sum()),
            "k_eq_3": int((ks == 3).sum()),
            "k_distribution": {int(v): int(c) for v, c in zip(values, counts, strict=True)},
        }
    results[key] = entry
    c, q = entry["current"], entry["prototype"]
    say(
        f"{label}: current rule k >= 1 in {c['k_ge_1']} of {total}, k >= 2 in {c['k_ge_2']}, "
        f"k distribution {c['k_distribution']} | prototype rule k >= 1 in {q['k_ge_1']} of {total}, "
        f"k >= 2 in {q['k_ge_2']}, k distribution {q['k_distribution']}"
    )
    return entry


def cells_route(n, p, draws):
    """T_1 of one spherical Gaussian population by drawing cells (A0 check of the Wishart route)."""
    out = []
    for _ in range(draws):
        x = rng.normal(size=(n, p))
        x -= x.mean(0)
        matrix = x @ x.T if p > n - 1 else x.T @ x
        out.append(_statistic(np.linalg.eigvalsh(matrix)[::-1][: min(p, n - 1)]))
    return np.array(out)

def statistic_by_cells(n, p):
    """T_1 computed from drawn cells with plain numpy, no code shared with k_rule."""
    cells = rng.normal(size=(n, p))
    cells = cells - cells.mean(axis=0)
    values = np.linalg.svd(cells, compute_uv=False) ** 2
    values = values[: min(p, n - 1)]
    return values[0] / np.median(values)

def load_rule(rule):
    """Return the k rule: points -> orthonormal row directions, shape (0, p) for none."""
    if rule == "current":
        return mod.invariant_directions
    if not (HERE / "k_rule.py").exists():
        raise SystemExit(f"--rule prototype needs {HERE / 'k_rule.py'} (Part A), which does not exist yet.")
    sys.path.insert(0, str(HERE))
    from k_rule import directions_with_margin

    return lambda points: directions_with_margin(points, alpha=0.01, max_directions=None)


def write_section(rule, name, text):
    """Keep one summary file per rule; each script rewrites only its own section."""
    path = HERE / f"b_summary_{rule}.txt"
    parts = {}
    if path.exists():
        for block in path.read_text().split("#### ")[1:]:
            title, _, body = block.partition("\n")
            parts[title] = body
    parts[name] = text.rstrip("\n") + "\n\n"
    path.write_text("".join(f"#### {title}\n{parts[title]}" for title in sorted(parts)))


calls = []
original = mod.best_flat_cut_reference


def recording(points, in_left):
    r = original(points, in_left)
    calls.append(dict(n=int(len(points)), left=int(in_left.sum()), reason=r.reason, k=int(r.invariant_directions),
                      rho=None if r.rho != r.rho else float(r.rho), p=float(r.p_value)))
    return r


def run(case, method, **overrides):
    calls.clear()

    res = benchmark_cluster_algorithm(test_cases=[case], methods=[method], method_params={method: [params]}, verbose=False,
                                      plot_umap=False, include_cover_pages=False, include_validation_page=False,
                                      allow_method_errors=True)
    return res.iloc[0], sorted(calls, key=lambda c: -c["n"])

    reasons = Counter(c["reason"] for r in call_rows for c in r["calls"])
    ks = Counter(c["k"] for r in call_rows for c in r["calls"])

                rows_under[node] = [row_of[tree.nodes[node]["label"]]] if not children else sum((rows_under[c] for c in children), [])
            assert len(rows_under[tree.root()]) == len(matrix)
            for node, rows in rows_under.items():
                if len(rows) >= MIN_NODE_CELLS:
                    k = len(directions(matrix[rows]))
                    nodes.append(dict(seed=seed, cell=f"{operator}/{linkage}", node=str(node), n=len(rows), k=k,
                                      is_root=node == tree.root()))
            print(seed, operator, linkage, "found", int(res["found_clusters"].iloc[0]), flush=True)
    json.dump(nodes, open(HERE / f"b_subtrees_{rule}.json", "w"), indent=1)

    lines = [f"rule: {rule}; {time.perf_counter() - start:.0f} s; one Gaussian population, 496 cells, 30 features, "
             f"seeds 401 to 405, nodes with at least {MIN_NODE_CELLS} cells",
             "cell | nodes | share with k >= 1 | distribution of k"]
    for operator, linkage in CELLS:
        ks = [r["k"] for r in nodes if r["cell"] == f"{operator}/{linkage}"]
        positive = sum(k >= 1 for k in ks)
        lines.append(f"{operator}/{linkage} | {len(ks)} | {positive}/{len(ks)} = {positive / len(ks):.3f} | "
                     f"{dict(sorted(Counter(ks).items()))}")
    text = "\n".join(lines)
    print(text)
    write_section(rule, "B3 (b_subtrees.py)", text)


if __name__ == "__main__":
    main()
