# ===== brief.md =====
# # Brief: independent check of variant A of the draft definition of k (written 2026-11-12, before the check)
#
# ## What is checked
#
# Variant A, a draft outside production (`results/analyses/k_split_direction_runs_20261112/draft_rule.py`):
#
# 1. For a node and the tree's split into left and right, the node's cells are divided into a basis half and a
#    test half, alternating within each side in the order of the cells' rows in the data.
# 2. From the basis half only, one direction w = S^-1 (mean of the left basis cells - mean of the right basis
#    cells), S the pooled within covariance of the basis half; the difference of the means alone when the basis
#    half has no more than p + 2 cells. k = 1.
# 3. On the test half only: `rho` of the tree's split of the test cells along w against the Gaussian reference of
#    the best flat cut at (number of test cells, 1) (`reference_p_value` in
#    `tree_break_selection/hierarchy_analysis/statistics/sibling_divergence/best_flat_cut_reference.py`).
# 4. p = 1 with fewer than 15 test cells or a side with fewer than 2 cells.
#
# It replaces the reference call inside the opt-in `sibling_best_flat_cut_reference` at run time.
#
# ## What has been claimed so far (to be tested, not assumed)
#
# - Level: with one Gaussian population and the method's own trees, p <= 0.01 at 109 of 31,482 tested nodes, and
#   more than 1 cluster in 12 of 1,960 fits (`results/analyses/k_split_direction_level_20261112`).
# - Benchmark: continuous suite mean ARI 0.8302 against 0.6950 for the current rule; null cases at 1 cluster
#   (`results/analyses/k_split_direction_runs_20261112`).
# - CHOIR cells, Markov/Ward tree: 218 clusters, ARI 0.8311 against 230 and 0.8219 for the current rule
#   (`draft_A_*` against `results/analyses/spr_refit_20261111/k15_base_*`).
# - The level is measured, not derived: the tree's split, chosen from all cells, enters the direction.
#
# ## Questions the check must answer (each with a measurement)
#
# - Q1 code against definition: does `draft_rule.py` do exactly what the four points above say? List every
#   difference, including edge cases (sides of 2 or 3 cells, `rho` infinite, the order in which cells arrive).
# - Q2 dependence on the order of the rows: the halves depend on the row order of the data. With the same cells
#   in another order (a seeded random order instead of the data order), how much do p-values, accepted splits,
#   found clusters and ARI change? On the 14 benchmark cases (5 orders) and on the CHOIR cells (3 orders).
# - Q3 one population that is not Gaussian, with the method's own trees: at least skewed features, heavy tails,
#   a uniform population, and a population spread along a closed curve plus noise (variation like a cell cycle).
#   How often does variant A split it, and how often does the current rule? 256 and 496 cells in 30 features,
#   at least 20 seeds, the 4 cells of operator and linkage.
# - Q4 real data: of the splits variant A accepts on the CHOIR cells, how many are at nodes with at least 90% of
#   their cells from one cell line, and how many at nodes with several lines? The same for the current rule, for
#   the 27 splits only variant A accepts and the 10 only the current rule accepts.
# - Q5 the p-values under one Gaussian population: from the recorded level data, the share of tested nodes with
#   p <= 0.1, 0.05 and 0.01 by number of test cells, against the nominal shares.
# - Q6 anything else that could be wrong with variant A or with the evidence for it. Look for it actively.
#
# ## Rules
#
# - Only files in `results/analyses/variant_a_check_20261112/` are written. No production file, test, wiki page,
#   raw capture or file of another analysis folder is changed; nothing is committed, installed or downloaded.
# - Run pattern: `cd /Users/berksakalli/Projects/kl-te-cluster && OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 uv run
#   --no-sync --offline python <script>`; scripts pass `uv run --no-sync --offline ruff check`. Long runs go to
#   the background, at most 6 processes at a time.
# - Every finding is one of: defect (variant A or its evidence is wrong), limitation (correct but restricted),
#   or no problem found; each with the numbers that support it and the script that produced them. A finding
#   without a measurement is marked as not measured.
# - The report (`report.md`) ends with what was not checked.

# ===== q2_plugin.py =====
"""Q2: the plug-in of draft_rule.install("A") with each side's cells ordered by a seeded random key of the row index."""
import sys
from pathlib import Path

import numpy as np

HERE = Path(__file__).resolve().parent
sys.path.insert(0, str(HERE.parent / "k_split_direction_runs_20261112"))

import draft_rule  # noqa: E402

mod = draft_rule.mod


def install(order_seed):
    """order_seed None: data order (the plug-in as it is); an int: rows sorted by a key drawn with that seed."""
    draft_rule.install("A")
    if order_seed is None:
        return
    key = np.random.default_rng(order_seed).random(1_000_000)  # shortcut: at most 1,000,000 rows, enough for 48,879
    original = draft_rule._original_leaf_rows
    mod._leaf_rows = lambda tree, node, row_of_label: sorted(original(tree, node, row_of_label), key=key.__getitem__)


if __name__ == "__main__":  # self-check: the key order is a permutation of the rows and differs from data order
    install(1)
    rows = list(range(50))
    ordered = sorted(rows, key=np.random.default_rng(1).random(1_000_000).__getitem__)
    assert sorted(ordered) == rows and ordered != rows
    print("ok")

# ===== q3_nongaussian.py =====
"""Q3: one non-Gaussian population through the method's own pipeline, variant A and the current rule.

usage: q3_nongaussian.py SHAPE CELLS   SHAPE in skewed, heavy, uniform, circle; CELLS in 256, 496 (30 features, seeds 1 to 20)
Shapes (z = the generated one-population matrix minus its column means, about standard normal):
  skewed  exponential(1) features, expon.ppf(norm.cdf(z)) (skewness 2)
  heavy   t features with 3 degrees of freedom, t.ppf(norm.cdf(z), 3)
  uniform uniform features, norm.cdf(z)
  circle  angle 2 pi norm.cdf(z[:, 0]); features 1, 2 = RADIUS (cos, sin); features 3 to 30 = z[:, 2:]
Each fit is run twice on the same data: variant A installed, then the current rule (plug-in removed).
Per-fit recording as in k_split_direction_level_20261112/measure.py. Output: q3_<SHAPE>_<CELLS>.json
"""
import json
import sys
import time
from pathlib import Path

import networkx as nx
import numpy as np
from scipy import stats

HERE = Path(__file__).resolve().parent
sys.path.insert(0, str(HERE.parents[2]))
sys.path.insert(0, str(HERE.parent / "k_split_direction_runs_20261112"))

import draft_rule  # noqa: E402

import benchmarks.shared.generators.gaussian_cases as gaussian_cases  # noqa: E402
import benchmarks.shared.runners.tbs_runner as tbs_runner  # noqa: E402
from benchmarks.shared.benchmark_runs.runtime import (
    apply_single_thread_runtime_defaults,  # noqa: E402
)
from benchmarks.shared.cases import get_test_cases_by_suite  # noqa: E402
from benchmarks.shared.generators import generate_case_data  # noqa: E402
from benchmarks.shared.pipeline import benchmark_cluster_algorithm  # noqa: E402
from benchmarks.shared.runners.method_registry import METHOD_SPECS  # noqa: E402

METHOD = "tbs_family_diffusion"
CELLS = [(operator, linkage) for operator in ("symmetric", "markov") for linkage in ("average", "ward")]
RADIUS = 3.0
MIN_NODE_CELLS = 30
mod = draft_rule.mod
original = mod.best_flat_cut_reference  # the current rule, kept before install
original_make_blobs = gaussian_cases.make_blobs
seen = {"hook": 0}
Original = tbs_runner.TreeDecomposition


class Recording(Original):
    def decompose_tree(self):
        out = super().decompose_tree()
        seen.update(tree=self.tree)
        return out


def transform(x, shape):
    z = x - x.mean(0)
    if shape == "skewed":
        return stats.expon.ppf(stats.norm.cdf(z))
    if shape == "heavy":
        return stats.t.ppf(stats.norm.cdf(z), 3)
    if shape == "uniform":
        return stats.norm.cdf(z)
    angle = 2 * np.pi * stats.norm.cdf(z[:, 0])
    return np.column_stack([RADIUS * np.cos(angle), RADIUS * np.sin(angle), z[:, 2:]])


def use_rule(rule):
    if rule == "A":
        draft_rule.install("A")
    else:
        mod.best_flat_cut_reference, mod._leaf_rows = original, draft_rule._original_leaf_rows


def fit(case, operator, linkage):
    seen.pop("tree", None)
    draft_rule.CALLS.clear()
    params = {**METHOD_SPECS[METHOD].param_grid[0], "diffusion_coordinate_operator": operator, "tree_linkage_method": linkage,
              "sibling_best_flat_cut_reference": True}
    try:
        res = benchmark_cluster_algorithm(test_cases=[case], methods=[METHOD], method_params={METHOD: [params]}, verbose=False,
                                          plot_umap=False, include_cover_pages=False, include_validation_page=False,
                                          allow_method_errors=False).iloc[0]
    except ValueError as error:
        return None, f"error: {error}"
    return int(res["found_clusters"]), str(res["status"])


def main():
    shape, cells = sys.argv[1], int(sys.argv[2])

    def hook(*args, **kwargs):
        x, y = original_make_blobs(*args, **kwargs)
        seen["hook"] += 1
        return transform(x, shape), y

    gaussian_cases.make_blobs = hook
    tbs_runner.TreeDecomposition = Recording
    draft = draft_rule._draft("A")
    apply_single_thread_runtime_defaults()
    start = time.perf_counter()
    (registered,) = [c for c in get_test_cases_by_suite("continuous") if c["name"] == "gauss_null_large_continuous"]
    fits, failures = [], []
    for seed in range(1, 21):
        case = {**registered, "n_samples": cells, "n_features": 30, "seed": seed}
        before = seen["hook"]
        data, _, _, _ = generate_case_data(case)
        matrix = data.to_numpy(dtype=np.float64)
        if seen["hook"] == before:
            failures.append(dict(check="make_blobs hook used", seed=seed))
        if shape == "circle" and not np.allclose(np.hypot(matrix[:, 0], matrix[:, 1]), RADIUS):
            failures.append(dict(check="first two features on the circle", seed=seed))
        row_of = {name: row for row, name in enumerate(data.index)}
        for operator, linkage in CELLS:
            use_rule("current")
            cur_found, cur_status = fit(case, operator, linkage)
            use_rule("A")
            a_found, a_status = fit(case, operator, linkage)
            record = dict(seed=seed, cell=f"{operator}/{linkage}", a_found=a_found, a_status=a_status, cur_found=cur_found,
                          cur_status=cur_status, calls=[dict(c) for c in draft_rule.CALLS], nodes=[])
            draft_rule.CALLS.clear()
            if "tree" not in seen:
                fits.append(record)
                failures.append(dict(check="tree captured", seed=seed, cell=record["cell"]))
                continue
            tree = seen["tree"]
            rows_under = {}
            for node in reversed(list(nx.topological_sort(tree))):
                children = list(tree.successors(node))
                rows_under[node] = [row_of[tree.nodes[node]["label"]]] if not children else sum((rows_under[c] for c in children), [])
            if sorted(rows_under[tree.root()]) != list(range(cells)):
                failures.append(dict(check="cells under the root are all cells", seed=seed, cell=record["cell"]))
            for node, rows in rows_under.items():
                children = list(tree.successors(node))
                if not children or len(rows) < MIN_NODE_CELLS:
                    continue
                left = sorted(rows_under[children[0]])
                right = sorted(r for c in children[1:] for r in rows_under[c])
                in_left = np.r_[np.ones(len(left), dtype=bool), np.zeros(len(right), dtype=bool)]
                points = matrix[left + right]
                try:
                    a = draft(points, in_left)
                    (call,) = draft_rule.CALLS
                except Exception as error:  # noqa: BLE001  # an error of variant A is a finding, recorded
                    call = dict(reason=f"error: {type(error).__name__}", p=None, rho=None)
                    a = None
                draft_rule.CALLS.clear()
                b = original(points, in_left)
                record["nodes"].append(dict(
                    cells=len(rows), left=len(left), a_reason=call["reason"], a_p=call["p"], a_test_cells=call.get("n_test"),
                    a_rho=call["rho"], cur_reason=b.reason, cur_k=int(b.invariant_directions), cur_p=float(b.p_value)))
                assert a is None or a.p_value == call["p"]
            fits.append(record)
        print(shape, cells, seed, f"{time.perf_counter() - start:.0f} s", flush=True)
    json.dump(dict(shape=shape, cells=cells, radius=RADIUS if shape == "circle" else None, seconds=time.perf_counter() - start,
                   failures=failures, fits=fits), open(HERE / f"q3_{shape}_{cells}.json", "w"))
    assert not failures, f"{len(failures)} failed self-checks"


if __name__ == "__main__":
    main()

"""Own checks of four findings of the independent check (not the checker's code)."""
import json
import sys
from pathlib import Path

import numpy as np
import pandas as pd

HERE = Path(__file__).resolve().parent
sys.path.insert(0, str(HERE.parents[2]))
sys.path.insert(0, str(HERE.parent / "k_split_direction_runs_20261112"))

import draft_rule  # noqa: E402

from tree_break_selection.hierarchy_analysis.statistics.sibling_divergence.best_flat_cut_reference import (
    reference_p_value,  # noqa: E402
)

rng = np.random.default_rng(31415)
draft = draft_rule._draft("A")

print("== 1. inputs that raise an error ==")
points = rng.normal(size=(120, 5))
points[:, 2] = 1.0  # a feature that is constant in the node
in_left = np.r_[np.ones(60, bool), np.zeros(60, bool)]
for label, data in (("constant feature", points), ("equal basis means", np.tile(rng.normal(size=(1, 5)), (120, 1)) + 0.0)):
    try:
        print(label, "->", draft(data, in_left))
    except Exception as error:  # noqa: BLE001
        print(label, "-> raises", type(error).__name__, str(error)[:60])

print("\n== 2. accepted splits on the CHOIR cells by composition of the node ==")
source = HERE.parent / "choir_cell_lines_tbs_lbfgsb_20261106"
lines = pd.read_csv(source / "cell_metadata.csv", index_col=0, dtype=str)["Cell_line"].to_numpy()
saved = np.load(HERE.parent / "spr_alternatives_best_flat_cut_20261111" / "tree_tbs_family_diffusion_markov_ward.npz")
parent, leaf_row = saved["parent"].astype(np.int64), saved["leaf_row"].astype(np.int64)
n = len(lines)
codes = pd.factorize(lines)[0]
counts = np.zeros((len(parent), codes.max() + 1), dtype=np.int32)
counts[np.arange(n), codes[leaf_row]] = 1
for node in range(len(parent)):
    if parent[node] >= 0:
        counts[parent[node]] += counts[node]
purity = counts.max(axis=1) / counts.sum(axis=1)
accepted = {}
for name, path in (("variant A", HERE.parent / "k_split_direction_runs_20261112" / "draft_A_splits.json"),
                   ("current rule", HERE.parent / "spr_refit_20261111" / "k15_base_splits.json")):
    accepted[name] = {int(s["node"][1:]) for s in json.loads(path.read_text())["splits"] if s["bh_different"]}
    one = sum(purity[i] >= 0.9 for i in accepted[name])
    print(f"{name}: accepted {len(accepted[name])}; node with at least 90% of its cells from one line: {one}; several lines: {len(accepted[name]) - one}")
for name, nodes in (("only variant A", accepted["variant A"] - accepted["current rule"]), ("only current rule", accepted["current rule"] - accepted["variant A"])):
    one = sum(purity[i] >= 0.9 for i in nodes)
    print(f"{name}: {len(nodes)}; one line {one}; several lines {len(nodes) - one}")

print("\n== 3. the table at k = 1 against the exact best cut of one direction, 20,000 Gaussian datasets per n ==")
for size in (15, 30, 75, 100, 150, 400):
    hits = 0
    for _ in range(20000):
        x = np.sort(rng.normal(size=size))
        prefix = np.cumsum(x)[:-1]
        left = np.arange(1, size)
        between = (prefix / left - (x.sum() - prefix) / (size - left)) ** 2 * left * (size - left) / size
        r2 = between.max() / ((x - x.mean()) ** 2).sum()
        hits += reference_p_value((size - 2) / size * r2 / (1 - r2), size, 1)[0] <= 0.01
    print(f"n = {size}: best cut has p <= 0.01 in {hits} of 20000 ({hits / 20000:.4f})")

print("\n== 4. the benchmark mean ARI of variant A and of the current rule, by set of cases ==")
a = pd.read_csv(HERE.parent / "k_split_direction_runs_20261112" / "benchmark_results_A.csv")
c = pd.read_csv(HERE.parent / "k_margin_prototype_20261112" / "b_results_current.csv")
for name, table in (("variant A", a), ("current rule", c)):
    t = table[table["method"] == "tbs_family_diffusion"]
    continuous = t[~t["case"].str.startswith("cancer_pc")]
    nine = continuous[continuous["case"] != "gauss_null_256n_30f_continuous"]
    print(f"{name}: 9 continuous cases of 11 November {nine['ari'].mean():.4f} (cases: {len(nine)}); all 10 continuous cases {continuous['ari'].mean():.4f}; "
          f"all 14 cases {t['ari'].mean():.4f}; left out of the 9: {sorted(set(continuous['case']) - set(nine['case']))}")
