# ===== protocol.md =====
# # Protocol: sprs applied to every refused split whose best flat cut passes, then the fit rerun (frozen 2026-11-11, before the run)
#
# Trial; no gate, default or production file is changed. Data and setup of `spr_alternatives_best_flat_cut_20261111`:
# 48,879 CHOIR cells, 30 PCs, `tbs_family_diffusion_markov_ward` with `sibling_best_flat_cut_reference=True`,
# sibling alpha 0.01, edge alpha 0.001, registry parameters (fixed-topology NNLS branch lengths). The saved tree is
# `spr_alternatives_best_flat_cut_20261111/tree_tbs_family_diffusion_markov_ward.npz` (`parent`: parent index per
# node, leaves 0 to n-1 are `L<i>`, internal nodes are `N<j>`; `leaf_row`: data row of each leaf).
#
# Baseline (fit of this tree): 138 clusters, ARI 0.2975, NMI 0.8512, 76 lines recovered at 90/90, 9 split only, 91
# merged only, 14 both, largest cluster 7,678, 1,838 tested splits.
#
# ## Part 1: harness (harness.py)
#
# Rerun the fit on a tree given as a parent array, without recomputing distances or the linkage, by handing the
# runner a `PosetTree` built from that topology. Proof before any changed tree is used: the unchanged saved tree
# through the harness reproduces the baseline (138 clusters, 1,838 tested splits, the same assignment as
# `best_flat_cut_reference_real_20261111/tbs_family_diffusion_markov_ward` for the reference arm). The merge heights
# given to the builder are topology-only; if the replay is not exact, the cause is reported and nothing is tuned.
#
# ## Part 2: sprs (apply_all_sprs.py)
#
# Top-down over the current tree. A node is a candidate when it has 15 cells or more, 1 to 10 invariant directions
# (`invariant_directions` of its own cells), its own split has a sibling reference p above 0.01
# (`best_flat_cut_reference`), and its best flat cut (the table's search) has reference p at or below 0.01. For a
# candidate, the smaller side of its best flat cut is made a node by sprs (join the tree nodes that make it up,
# then regraft the joined node on the edge above the candidate), so the node's two children are (that side | the
# rest). Then both children are evaluated in the same way on the cells they now hold. Nodes with no invariant
# directions or more than 10 are left as they are and their children are evaluated. Each move is one
# subtree-prune-regraft as in `tree_break_selection/tree/spr.py` (the pruned node's parent keeps its id).
#
# Self-check before the full run: on at least three nodes the array implementation gives the same leaf sets as
# `subtree_prune_regraft` on a `PosetTree` with set based identity (`to_splits` equal); N96475, N96842 and N96808
# reproduce the 2 sprs and the `rho` values 7.651, 10.305 and 13.693 of the earlier follow-up.
#
# Recorded per candidate: leaves, cell lines, k, `rho` and p of the tree split and of the best flat cut, number of
# sprs, single-leaf moves, leaf sets changed, line cut share before and after, and whether the node was a tested
# and refused split of the baseline fit.
#
# ## Part 3: refit and comparison
#
# The changed tree through the harness. Endpoints against the baseline: found clusters, ARI and NMI against the
# 190 cell lines, lines recovered at 90/90, split only, merged only, both, largest cluster, clusters at least 90%
# pure, clusters under 20 cells (definitions of `best_flat_cut_reference_real_20261111/summarize.py`); tested
# splits, kept (p <= 0.01) and accepted by BH; of the candidate nodes, how many splits the refit accepts.
#
# ## Expected before running
#
# - The sprs reach only nodes with 1 to 10 invariant directions. In the baseline every split with 1,000 cells or
#   more has 11 to 15 and is refused (190 splits). Those stay refused, so the largest cluster and the merged-only
#   lines should change little and the ARI should rise only modestly.
# - On the per-split reference, 221 of the 1,285 measured splits (32 cells or more) were refused with a passing
#   best flat cut; the top-down pass also evaluates nodes the fit never tested and nodes created by the sprs, so
#   the number of candidates is not predicted.
# - In the baseline 17 of 48 splits at p 0.0005 were not accepted by BH; a part of the new splits will be refused
#   by BH or by the edge gate. How many is not predicted.
# - Splits inside single cell lines can pass the best flat cut (earlier: 38 of 570 and 48 of 195 subtrees), so
#   the sprs can also split lines; the split-only count may rise.
#
# ## Limits known before running
#
# One dataset, one tree, one run; the candidates are chosen by the same data that is then tested, and the reference
# does not cover the choice of k or of the node; branch lengths are refit by the runner on the changed topology;
# splits with more than 10 invariant directions are not touched; no null calibration of the complete procedure.

# ===== deviations.md =====
# # Deviations and interpretations (Part 2, apply_all_sprs.py)
#
# No deviation from the candidate rule, the spr operation or the recursion. Choices the protocol leaves open:
#
# - Nodes with fewer than 32 cells are not searched (n <= p + 1 = 31 gives no invariant directions, so they can
#   never be candidates); the summary counts them as one group instead of splitting "k = 0" and "< 15 cells".
# - Order of the joining sprs: pieces largest first, ties by node id (the earlier `apply_sprs.py` sorted by size
#   only). Equal-size sides of the best flat cut: fewer tree nodes, then the side holding the smallest leaf index.
# - "Tested and refused in the baseline fit": the candidate's leaf set equals the leaf set of an input-tree node
#   whose baseline record has `bh_different` false (all 90 such candidates had reason `tested`).
# - "Several cell lines / one cell line": number of distinct `Cell_line` values among the candidate's cells.

# ===== harness.py =====

usage: harness.py TREE_NPZ OUT_PREFIX   (npz with `parent` and `leaf_row` as written by fit.py)

No distances and no linkage are computed: the runner's build_tree is replaced by one that returns the PosetTree of
the given topology. Merge heights are topology-only (row k of the linkage merges at height k + 1). Internal nodes are
emitted in the smallest-id-first topological order, so a tree whose children all have smaller ids than their parents
(the saved tree) keeps its ids; otherwise they are renumbered and reports name nodes by the id in the npz.
"""

def linkage_from_parent(parent, n_leaves):
    """Linkage rows in smallest-id-first topological order; returns (Z, npz id of the node made by each row)."""
    children = [[] for _ in parent]
    for node, up in enumerate(parent):
        if up >= 0:
            children[up].append(node)
    internal = range(n_leaves, len(parent))
    if (parent == -1).sum() != 1 or any(len(children[i]) != 2 for i in internal) or any(children[i] for i in range(n_leaves)):
        raise ValueError("parent array is not a rooted binary tree with leaves 0..n-1")
    waiting = {i: sum(c >= n_leaves for c in children[i]) for i in internal}
    ready = [i for i, w in waiting.items() if w == 0]
    heapq.heapify(ready)
    new_of, order = {i: i for i in range(n_leaves)}, []
    while ready:
        node = heapq.heappop(ready)
        new_of[node] = n_leaves + len(order)
        order.append(node)
        up = parent[node]
        if up >= 0:
            waiting[up] -= 1
            if waiting[up] == 0:
                heapq.heappush(ready, up)
    if len(order) != n_leaves - 1:
        raise ValueError("parent array has a cycle or disconnected nodes")
    Z = np.empty((n_leaves - 1, 4))
    for k, node in enumerate(order):
        a, b = sorted(new_of[c] for c in children[node])  # scipy writes the smaller child index first
        Z[k] = a, b, k + 1.0, 0.0
    sizes = np.ones(len(parent), dtype=np.int64)
    for node in order:
        sizes[node] = sizes[children[node]].sum()
    Z[:, 3] = sizes[order]
    return Z, np.array(order, dtype=np.int64)


# Definitions copied from best_flat_cut_reference_real_20261111/summarize.py (breakdown) and run.py (recovered_lines);
# summarize.py runs at import, so it is copied instead of imported.
def breakdown(a):
    t = pd.crosstab(a.Cell_line, a.cluster)
    main = t.idxmax(axis=1)
    split = t.max(axis=1) / t.sum(axis=1) < 0.9
    merged = (t.max(axis=0) / t.sum(axis=0))[main].to_numpy() < 0.9
    purity = t.max(axis=0) / t.sum(axis=0)
    return {"clusters_ge90_pure": int((purity >= 0.9).sum()), "clusters_lt20_cells": int((t.sum(axis=0) < 20).sum()),
            "largest_cluster": int(t.sum(axis=0).max()), "recovered": int((~split & ~merged).sum()),
            "split_only": int((split & ~merged).sum()), "merged_only": int((~split & merged).sum()),
            "both": int((split & merged).sum())}


def recovered_lines(truth, labels):
    table = pd.crosstab(truth, labels)
    recall = table.max(axis=1) / table.sum(axis=1)
    purity = table.max(axis=0) / table.sum(axis=0)
    return int(((recall >= 0.9) & (purity[table.idxmax(axis=1)].to_numpy() >= 0.9)).sum())

"""protocol.md Part 2: top-down sprs that make every candidate's best-flat-cut side one of its two children.

Arrays only (parent, children); a node's identity is its leaf set, the id is a label. Waves: every node of a

def load_tree(path=SPR / f"tree_{METHOD}.npz"):

def children_of(parent):
    children = np.full((len(parent), 2), -1, dtype=np.int64)
    fill = np.zeros(len(parent), dtype=np.int64)
    for node, up in enumerate(parent):
        if up >= 0:
            children[up, fill[up]] = node
            fill[up] += 1
    return children


def leaves_of(children, node):
    """Leaf indices under ``node``, first child's leaves first."""
    out, stack = [], [node]
    while stack:
        v = stack.pop()
        if children[v, 0] < 0:
            out.append(v)
        else:
            stack.extend((children[v, 1], children[v, 0]))
    return np.array(out, dtype=np.int64)


def test_node(job):
    """Candidate test of one node from its cells' rows and its current split (``in_left``)."""
    rows, in_left = job
    points = X["x"][rows]
    n = len(rows)
    directions = invariant_directions(points)
    k = len(directions)
    out = {"n": n, "k": k}
    if n < MIN_CELLS or not 1 <= k <= MAX_DIRECTIONS:
        return out
    tree = best_flat_cut_reference(points, in_left)
    out.update(rho_tree=tree.rho, p_tree=tree.p_value)
    if tree.p_value > ALPHA:
        rho_best, mask = best_flat_cut(points @ directions.T)
        out.update(rho_best=rho_best, p_best=float(reference_p_value(rho_best, n, k)[0]), best_mask=mask)
    return out


def spr(parent, children, prune, regraft):
    """``tree.spr.subtree_prune_regraft`` on arrays: the parent of ``prune`` keeps its id and moves above ``regraft``."""
    p = parent[prune]
    if p < 0 or parent[regraft] < 0:
        raise ValueError("cannot prune the root or regraft above it")
    sibling = children[p, 0] if children[p, 1] == prune else children[p, 1]
    if regraft in (prune, p, sibling):
        raise ValueError("degenerate spr")
    g = parent[p]
    children[g, children[g] == p] = sibling
    parent[sibling] = g
    t = parent[regraft]
    children[t, children[t] == regraft] = p
    parent[p] = t
    children[p] = (prune, regraft)
    parent[regraft] = p


def pieces_inside(children, node, side):
    """Maximal nodes under ``node`` whose leaves all lie in ``side`` (a set of leaf indices), with their sizes."""
    post, stack = [], [node]
    while stack:
        v = stack.pop()
        post.append(v)
        if children[v, 0] >= 0:
            stack.extend(children[v])
    size, inside = {}, {}
    for v in reversed(post):
        if children[v, 0] < 0:
            size[v], inside[v] = 1, int(v in side)
        else:
            a, b = children[v]
            size[v], inside[v] = size[a] + size[b], inside[a] + inside[b]
    out, stack = [], [node]
    while stack:
        v = stack.pop()
        if inside[v] == size[v]:
            out.append(v)
        elif inside[v]:
            stack.extend(children[v])
    return sorted(((size[v], v) for v in out), key=lambda sv: (-sv[0], sv[1]))


def make_child(parent, children, node, side):
    """Sprs that give the node holding ``node``'s leaf set the children ``side`` and the rest.

    Returns the new holder, the holder of ``side`` and the moves (pruned, regraft, pruned size).
    """
    pieces = pieces_inside(children, node, side)
    holder, joined, moves = node, pieces[0][1], []
    for size, piece in pieces[1:]:
        p = parent[piece]
        if p == holder:  # the sibling of the pruned piece then holds the node's leaf set
            holder = children[p, 0] if children[p, 1] == piece else children[p, 1]
        moves.append((int(piece), int(joined), int(size)))
        spr(parent, children, piece, joined)
        joined = p
    if parent[joined] != holder:
        p = parent[joined]
        moves.append((int(joined), int(holder), len(side)))
        spr(parent, children, joined, holder)
        holder = p
    return holder, joined, moves


def clade_sets(children, node):
    """Leaf sets of the internal nodes under ``node`` (inclusive)."""
    post, stack = [], [node]
    while stack:
        v = stack.pop()
        post.append(v)
        if children[v, 0] >= 0:
            stack.extend(children[v])
    sets, out = {}, set()
    for v in reversed(post):
        if children[v, 0] < 0:
            sets[v] = frozenset((v,))
        else:
            sets[v] = sets[children[v, 0]] | sets[children[v, 1]]
            out.add(sets[v])
    return out


def line_cut_share(lines, mask):
    left = np.bincount(lines[mask], minlength=lines.max() + 1)
    right = np.bincount(lines[~mask], minlength=lines.max() + 1)
    return float(np.minimum(left, right).sum() / len(lines))


def original_node(parent0, pre0, sub0, leaves):
    """Id of the input tree's node with exactly these leaves, or None."""
    positions = pre0[leaves]
    v, hi = int(leaves[np.argmin(positions)]), int(positions.max())
    while not pre0[v] <= hi < pre0[v] + sub0[v]:
        v = int(parent0[v])
    return v if (sub0[v] + 1) // 2 == len(leaves) else None


def choose_side(children, node, leaves, mask):
    """Smaller side of the cut; equal sizes: fewer tree nodes, then the side holding the smallest leaf index."""
    sides = [leaves[mask], leaves[~mask]]
    if len(sides[0]) != len(sides[1]):
        return min(sides, key=len)
    return min(sides, key=lambda s: (len(pieces_inside(children, node, set(s.tolist()))), s.min()))


def is_rooted_binary(parent, n_leaves):
    m = len(parent)
    roots = np.flatnonzero(parent < 0)
    if len(roots) != 1 or m != 2 * n_leaves - 1:
        return False, "root count or node count"
    counts = np.bincount(parent[parent >= 0], minlength=m)
    if (counts[:n_leaves] != 0).any() or (counts[n_leaves:] != 2).any():
        return False, "child counts"
    seen = leaves_of(children_of(parent), int(roots[0]))
    if sorted(seen.tolist()) != list(range(n_leaves)):
        return False, "leaf set"
    if len(index_tree(parent)[0]) != m:
        return False, "unreachable nodes"
    return True, "one root, 2 children per internal node, leaves 0..n-1 have none, all nodes reachable"

def poset(children, top, n_leaves, cells_of_leaf):
    """PosetTree of the subtree at ``top`` below an extra root with one 'outside' leaf (room to regraft above ``top``)."""
    tree = PosetTree()
    tree.add_node("ROOT", is_leaf=False, label="ROOT")
    tree.add_node("OUT", is_leaf=True, label="outside")
    name = lambda v: f"L{v}" if v < n_leaves else f"N{v}"  # noqa: E731
    stack, edges = [top], []
    while stack:
        v = stack.pop()
        tree.add_node(name(v), is_leaf=bool(v < n_leaves), label=cells_of_leaf[v] if v < n_leaves else name(v))
        if v >= n_leaves:
            edges += [(name(v), name(c)) for c in children[v]]
            stack.extend(children[v])
    for edge in edges:
        tree.add_edge(*edge)
    tree.add_edge("ROOT", name(top))
    tree.add_edge("ROOT", "OUT")
    tree.graph["root"] = "ROOT"
    return tree


def check_one(node, parent0, leaf_row, cells, x):
    n_leaves = len(leaf_row)
    parent, children = parent0.copy(), children_of(parent0)
    leaves = leaves_of(children, node)
    points = x[leaf_row[leaves]]
    _, mask = best_flat_cut(points @ invariant_directions(points).T)
    side = choose_side(children, node, leaves, mask)
    side_set = set(side.tolist())
    cells_of_leaf = {int(v): cells[leaf_row[v]] for v in leaves}

    # PosetTree path with set based identity, the same piece order (largest first, ties by node id)
    tree = poset(children, node, n_leaves, cells_of_leaf)
    encoding = {cells_of_leaf[int(v)]: i for i, v in enumerate(leaves)} | {"outside": len(leaves)}
    tree.initialize_split_indices(encoding)
    position = {int(v): i for i, v in enumerate(leaves)}
    part = lambda s: Partition(tuple(sorted(position[v] for v in s)), encoding)  # noqa: E731
    target, node_set = part(side_set), part(set(leaves.tolist()))
    pieces = sorted(tree.to_splits(with_leaves=True).maximals_under(target),
                    key=lambda p: (-len(p), int(tree.find_node_by_split(p)[1:])))
    joined, sprs_poset = pieces[0], 0
    for piece in pieces[1:]:
        subtree_prune_regraft(tree, tree.find_node_by_split(piece), tree.find_node_by_split(joined))
        joined = Partition(tuple(sorted(set(joined.indices) | set(piece.indices))), encoding)
        sprs_poset += 1
    target_node, holder = tree.find_node_by_split(target), tree.find_node_by_split(node_set)
    if next(iter(tree.predecessors(target_node))) != holder:
        subtree_prune_regraft(tree, target_node, holder)
        sprs_poset += 1

    # array path
    new_holder, side_node, moves = make_child(parent, children, node, side_set)
    mine = poset(children, new_holder, n_leaves, cells_of_leaf)
    mine.initialize_split_indices(encoding)
    kids = [set(leaves_of(children, c).tolist()) for c in children[new_holder]]
    s_mask = np.isin(leaves, side)
    rho = best_flat_cut_reference(points, s_mask).rho
    print(f"N{node}: {len(leaves)} leaves, side {len(side)}; array sprs {len(moves)} {moves}; PosetTree sprs {sprs_poset}; "
          f"holder N{new_holder} (PosetTree {tree.find_node_by_split(node_set)}), rho after {rho:.3f}")
    check(tree.to_splits() == mine.to_splits(), f"N{node}: to_splits of array result == PosetTree subtree_prune_regraft result")
    check(sorted(map(len, kids)) == sorted([len(side), len(leaves) - len(side)]) and side_set in kids
          and set(leaves.tolist()) - side_set in kids, f"N{node}: holder's children are exactly S and P minus S")
    check(len(moves) == 2 == sprs_poset, f"N{node}: 2 sprs (array {len(moves)}, PosetTree {sprs_poset})")
    check(round(rho, 3) == EXPECTED[node], f"N{node}: rho of the new split {rho:.3f} == {EXPECTED[node]}")

def describe(parent):
    """Children, bottom-up leaf-set hashes (two xor words and the size) and leaf lists on request."""
    m = len(parent)
    children = [[] for _ in range(m)]
    roots = []
    for node, up in enumerate(parent):
        (roots if up < 0 else children[up]).append(node)
    assert len(roots) == 1, roots
    assert all(len(children[i]) == 0 for i in range(n)) and all(len(children[i]) == 2 for i in range(n, m))
    order, stack = [], [roots[0]]
    while stack:
        node = stack.pop()
        order.append(node)
        stack.extend(children[node])
    assert len(order) == m, "not all nodes reachable"
    word = np.zeros((m, 2), dtype=np.int64)
    size = np.zeros(m, dtype=np.int64)
    word[:n], size[:n] = keys, 1
    for node in order[::-1]:
        if node >= n:
            a, b = children[node]
            word[node], size[node] = word[a] ^ word[b], size[a] + size[b]
    identity = {(int(size[i]), int(word[i, 0]), int(word[i, 1])): i for i in range(m)}
    return children, identity, size


def leaves(children, node):
    out, stack = [], [node]
    while stack:
        u = stack.pop()
        if u < n:
            out.append(u)
        else:
            stack.extend(children[u])
    return np.array(out)
