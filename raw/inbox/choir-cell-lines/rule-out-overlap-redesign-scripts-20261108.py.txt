# ===== protocol.md =====
# Protocol: replacing the zero-overlap rule with an overlap fraction (frozen 2026-11-08)

## Question (user-confirmed)

Redesign the zero-overlap rule of the split-count rule-out so that it does not tighten as the number of cells
grows (`rule_out_gradient_20261108`: separable share follows Phi(delta/2)^n).

## New rule (everything else unchanged)

Old: the split is separable by a flat cut in the subtree's invariant directions (no cell on the wrong side).
New: the Fisher discriminant of the split in the invariant directions (pooled within-sides covariance, priors =
the split's proportions pi and 1 - pi) misplaces a fraction of cells no larger than the overlap of the weakest
separation the count of all splits can accept:

- count bound: pi (1 - pi) delta^2 > 2 ln 2, so delta_min(pi) = sqrt(2 ln 2 / (pi (1 - pi)));
- allowed fraction tau(pi) = Bayes error of two unit-variance Gaussians with proportions pi, 1 - pi at
  separation delta_min(pi): pi Phi(-delta_min/2 - c) + (1 - pi) Phi(-delta_min/2 + c), c = ln((1 - pi)/pi) / delta_min.

Balanced: delta_min = 2.355, tau = 0.119. The invariant directions (noise band), the n <= p + 1 edge, the 5%
equidistant-cell rule and the count of all splits are unchanged.

## Checks

Self-check (assert): two Gaussians at delta = 4, 2,000 cells: misplaced fraction within 0.01 of Phi(-2) = 0.023;
tau(0.5) within 0.001 of 0.119.

E1 grid (`rule_out_gradient_20261108` grid, same seeds, 8,640 runs): kept rate by (p, n, delta) under the new
rule; prediction: no decline with n at fixed delta; transition near delta = 2.36 for n > p + 1.
E2 935 simulated datasets, both trees, end to end (harness of `split_count_exclusion_20261108`), arms rule_out
(old) and rule_out_overlap (new), with the frozen rule of that protocol: Markov/Ward no-group passes <= 2% for
>= 40 and 10-39 cells at sd 0.25 and 0.42; default-tree ARI within 0.02 of today's (today taken from the
2026-11-08 exclusion run).
E3 real CHOIR data, both methods, end to end: clusters, ARI, lines recovered (90/90), old vs new.
E4 the 9 continuous benchmark cases: clusters and ARI, old vs new.

The new rule replaces the old one in production only if E2 passes the frozen rule; otherwise it is reported and
production stays as it is.

## Amendment after E1 (before E2-E4; see deviations.md)

E1 showed the overlap rule removes the decline at delta = 6 but the unchanged 5% equidistant-cell rule (full
whitened p-dimensional metric) then binds at delta = 3-4 and also tightens with n and p. Amended rule, same
principle: margins are measured on the Fisher-discriminant coordinate of the split within the invariant
directions (1D, scaled to unit pooled within-sides SD), m = (|x - mu_other| - |x - mu_own|) / |mu_own - mu_other|
on that coordinate, tie |m| < 0.1 as before; allowed share = the expected share for two unit Gaussians with
proportions pi, 1 - pi at delta_min(pi) (numerical integration; balanced 0.047). E1 is repeated with both rules
(E1b), and E2-E4 run three arms: rule_out (old), rule_out_overlap (new overlap, old ties, as frozen) and
rule_out_overlap_ties (new overlap, new ties, amendment). The production replacement is the arm that passes
E2's frozen rule; if both pass, the amendment arm.

# ===== deviations.md =====
# Deviations from protocol.md

- After E1: the equidistant-cell rule was found to tighten with n and p; the amendment section adds a
  redesigned tie rule and a third arm before E2-E4 ran.
- After E2: all three arms pass the frozen rule, but the new rules raise false partitions and lower
  Markov/Ward real-group ARI, which the frozen rule does not check. The replacement clause (replace production
  with the amendment arm) was not applied; the decision is left to the user. E3 and E4 were planned after a
  replacement and were not run. `overlap_by_size.txt` (overlap of tree-chosen splits by size) was added after E2.

# ===== overlap_rule.py =====
"""New rule: Fisher-discriminant misplaced fraction in invariant directions against the count-bound overlap."""
import numpy as np
from scipy.stats import norm


def allowed_overlap(pi):
    """Bayes error at the weakest separation the count of all splits can accept, delta^2 pi(1-pi) = 2 ln 2."""
    pi = min(max(pi, 1e-9), 1 - 1e-9)
    delta = np.sqrt(2 * np.log(2) / (pi * (1 - pi)))
    c = np.log((1 - pi) / pi) / delta
    return float(pi * norm.cdf(-delta / 2 - c) + (1 - pi) * norm.cdf(-delta / 2 + c))


def misplaced_fraction(points, in_left):
    """Share of cells the Fisher discriminant (pooled covariance, observed priors) puts on the other side."""
    left, right = points[in_left], points[~in_left]
    pi = len(left) / len(points)
    centered = np.vstack([left - left.mean(0), right - right.mean(0)])
    within = centered.T @ centered / max(len(points) - 2, 1)
    w = np.linalg.pinv(np.atleast_2d(within)) @ (left.mean(0) - right.mean(0))
    midpoint = (left.mean(0) + right.mean(0)) / 2
    score = (points - midpoint) @ w + np.log(pi / (1 - pi))
    return float(np.mean((score > 0) != in_left))


if __name__ == "__main__":
    rng = np.random.default_rng(0)
    x = np.r_[rng.standard_normal(1000) + 2, rng.standard_normal(1000) - 2][:, None]
    side = np.r_[np.ones(1000, bool), np.zeros(1000, bool)]
    assert abs(misplaced_fraction(x, side) - norm.cdf(-2)) < 0.01, misplaced_fraction(x, side)
    assert abs(allowed_overlap(0.5) - 0.119) < 0.001, allowed_overlap(0.5)
    print("self-check passed", round(misplaced_fraction(x, side), 4), round(allowed_overlap(0.5), 4),
          {p: round(allowed_overlap(p), 4) for p in (0.1, 0.25, 0.5)})


def discriminant_coordinate(points, in_left):
    """Fisher-discriminant coordinate of every cell, scaled to unit pooled within-sides SD."""
    left, right = points[in_left], points[~in_left]
    centered = np.vstack([left - left.mean(0), right - right.mean(0)])
    within = centered.T @ centered / max(len(points) - 2, 1)
    w = np.linalg.pinv(np.atleast_2d(within)) @ (left.mean(0) - right.mean(0))
    z = points @ w
    sd = np.sqrt(np.mean(np.r_[z[in_left] - z[in_left].mean(), z[~in_left] - z[~in_left].mean()] ** 2))
    return z / sd


def tie_share_1d(z, in_left, margin=0.1):
    mu_l, mu_r = z[in_left].mean(), z[~in_left].mean()
    to_l, to_r = np.abs(z - mu_l), np.abs(z - mu_r)
    m = np.where(in_left, to_r - to_l, to_l - to_r) / abs(mu_l - mu_r)
    return float(np.mean(np.abs(m) < margin))


def allowed_tie_share(pi, margin=0.1):
    """Expected tie share for unit Gaussians with proportions pi, 1 - pi at the weakest acceptable separation."""
    pi = min(max(pi, 1e-9), 1 - 1e-9)
    delta = np.sqrt(2 * np.log(2) / (pi * (1 - pi)))
    # |m| < margin  <=>  |x| < margin * delta / 2 on a line with means at +- delta / 2 (midpoint at 0)
    half = margin * delta / 2
    left = norm.cdf(half - delta / 2) - norm.cdf(-half - delta / 2)  # mass of the side centred at +delta/2 near 0
    return float(pi * left + (1 - pi) * left)

import numpy as np  # noqa: E402

from tree_break_selection.hierarchy_analysis.statistics.sibling_divergence.split_count_rule_out import (  # noqa: E402
    MAX_EQUIDISTANT_SHARE,
    equidistant_share,
    invariant_directions,
)

PS, NS = (10, 30, 100), (20, 40, 60, 80, 120, 160, 240, 320, 640)
DELTAS, REPS = (0.0, 1.0, 1.5, 2.0, 2.5, 3.0, 4.0, 6.0), 40


def task(job):
    p, n, d_index = job
    out = []
    with threadpool_limits(limits=1):
        for rep in range(REPS):
            rng = np.random.default_rng(np.random.SeedSequence([20261108, 77, p, n, d_index, rep]))
            in_left = np.r_[np.ones(n // 2, bool), np.zeros(n - n // 2, bool)]
            x = rng.standard_normal((n, p))
            x[:, 0] += np.where(in_left, DELTAS[d_index] / 2, -DELTAS[d_index] / 2)
            directions = invariant_directions(x)
            misplaced = misplaced_fraction(x @ directions.T, in_left) if len(directions) else np.nan
            if len(directions) == 0:
                reason = "no_invariant_directions"
            elif misplaced > allowed_overlap(in_left.mean()):
                reason = "overlap"
            else:
                reason = "kept" if equidistant_share(x, in_left) <= MAX_EQUIDISTANT_SHARE else "equidistant_cells"
            out.append({"p": p, "n": n, "delta": DELTAS[d_index], "rep": rep, "reason": reason, "misplaced": misplaced,
                        "kept": reason == "kept"})
    return out


if __name__ == "__main__":

        for rows in pool.imap_unordered(task, list(itertools.product(PS, NS, range(len(DELTAS))))):
            f.write("".join(json.dumps(r) + "\n" for r in rows))

def log_count(n, k, sep):
    """log of the number of possible splits of n cells; flat cuts in k invariant directions when separable."""
    if n < 2:
        return 0.0
    return counting.log_hyperplane_splits(n, k) if sep else counting.log_all_splits(n)


def adjusted(stat, df, log_m):
    return float(np.exp(min(0.0, log_m + chi2.logsf(stat, df))))


def swapped(records, *, model, **kwargs):
    ids, summaries, labels, decisions, inadmissible = ORIGINAL(records, model=model, **kwargs)
    arm, cache = STATE["arm"], STATE["cache"]
    tree = sys._getframe(1).f_locals["tree"]
    by_parent = {r.parent: r for r in records}
    if "rows" not in cache:
        cache["rows"] = precompute_descendants(tree, {label: i for i, label in enumerate(STATE["data"].index)})
        cache["matrix"] = STATE["data"].to_numpy(dtype=np.float64)
    rows, matrix = cache["rows"], cache["matrix"]
    out = ([], [], [], [], list(inadmissible))
    for pid, summary, label, decision in zip(ids, summaries, labels, decisions, strict=True):
        record = by_parent[pid]
        if decision is None:
            for column, value in zip(out[:4], (pid, summary, label, decision), strict=True):
                column.append(value)
            continue
        key = ("split", str(pid))
        if key not in cache:
            left, right = sorted(rows[record.left]), sorted(rows[record.right])
            points = matrix[left + right]
            own_a = np.r_[np.ones(len(left), bool), np.zeros(len(right), bool)]
            n = len(points)
            count("n_matches_record", n == int(record.n_parent))
            k, basis = counting.invariant_directions(points)
            sep = bool(k >= 1 and counting.separable(points @ basis.T, own_a))
            m, _ = distances.margins(distances.whiten(points, own_a), own_a)
            ties = int(np.sum(np.abs(m) < TIE_MARGIN))
            pi = float(own_a.mean())
            misplaced = misplaced_fraction(points @ basis.T, own_a) if k >= 1 else 1.0
            tie_1d = tie_share_1d(discriminant_coordinate(points @ basis.T, own_a), own_a) if k >= 1 else 1.0
            low_overlap = bool(k >= 1 and misplaced <= allowed_overlap(pi))
            few_ties_1d = bool(k >= 1 and tie_1d <= allowed_tie_share(pi))
            cache[key] = (n, int(min(len(left), len(right))), k, sep, ties, low_overlap, few_ties_1d, misplaced, tie_1d)
        n, n_small, k, sep, ties, low_overlap, few_ties_1d, misplaced, tie_1d = cache[key]
        stat, df = float(record.stat), float(record.degrees_of_freedom)
        few_ties = ties / n <= MAX_TIE_SHARE
        real = {"rule_out": sep and few_ties, "rule_out_overlap": low_overlap and few_ties,
                "rule_out_overlap_ties": low_overlap and few_ties_1d}[arm]
        c = 1.0
        p = adjusted(stat, df, counting.log_all_splits(n)) if real else 1.0
        STATE["splits"].append({"node": str(pid), "n_parent": n, "n_small": n_small, "stat": stat, "df": df, "k": k,
                                "separable": sep, "tie_share": ties / n, "low_overlap": low_overlap, "few_ties_1d": few_ties_1d,
                                "misplaced": misplaced, "tie_1d": tie_1d, "real": real, "p": p,
                                "c_today": float(decision.c_hat)})
        out[0].append(pid)
        out[1].append((stat / c, df, p))
        out[2].append(f"{label}:{arm}")
        out[3].append(replace(decision, c_hat=float(c), p_value=p))
    return out

    STATE["checks"] = {}
    with threadpool_limits(limits=1):
        prepared = prepare(counts)
        STATE["data"] = prepared[0]
        for tree_name, index in TREES.items():
            dist = pdist(prepared[index])
            STATE["cache"] = {}
            for arm in ARMS:
                STATE.update(arm=arm, splits=[])
                start = perf_counter()
                result = fit(prepared[0], dist, tree_name)
                key = {"model": model, "replicate": replicate, "tree": tree_name, "arm": arm}
                bh = result.extra["annotations"]["Sibling_BH_Different"].astype(bool)
                splits.extend({**key, **row, "bh_different": bool(bh[row["node"]])} for row in STATE["splits"])
                datasets.append({**key, "status": result.status.value, "found_clusters": result.found_clusters,
                                 "ari": float(adjusted_rand_score(np.asarray(truth), result.labels)),
                                 "sec": perf_counter() - start})
    return datasets, splits, {"model": model, "replicate": replicate, **STATE["checks"]}


def jobs():
    signal = [(m, r) for m in SIGNALS for r in range(VALIDATION_MODELS[m]["replicates"])]
    return signal + [(m, r) for m in NULLS for r in range(300)]


def main(workers):
    paths = {name: HERE / f"{name}.jsonl" for name in ("datasets", "splits", "checks")}
    done = set()
    if paths["checks"].exists():
        done = {(r["model"], r["replicate"]) for r in map(json.loads, paths["checks"].read_text().splitlines())}
    todo = [j for j in jobs() if j not in done]
    files = {name: path.open("a", buffering=1) for name, path in paths.items()}
    with Pool(workers) as pool:
        for i, (datasets, splits, checks) in enumerate(pool.imap_unordered(task, todo), 1):
            files["splits"].write("".join(json.dumps(r) + "\n" for r in splits))
            files["datasets"].write("".join(json.dumps(r) + "\n" for r in datasets))
            files["checks"].write(json.dumps(checks) + "\n")
            if i % 25 == 0:
                print(f"{i}/{len(todo)}", flush=True)


if __name__ == "__main__":
    if sys.argv[1] == "check":
        for job in (("low", 0), ("signal_balanced", 0)):
            t = perf_counter()
            datasets, splits, checks = task(job)
            print(job, f"{perf_counter() - t:.1f}s", checks)
            for d in datasets:
                print(d["tree"], d["arm"], d["found_clusters"], round(d["ari"], 3), round(d["sec"], 1))
            for s in splits:
                if s["arm"] == "rule_out_overlap_ties" and s["n_parent"] >= 100:

                           if k in ("tree", "n_parent", "k", "separable", "low_overlap", "few_ties_1d", "misplaced", "tie_1d", "real", "p")})
    else:
        main(int(sys.argv[1]))
