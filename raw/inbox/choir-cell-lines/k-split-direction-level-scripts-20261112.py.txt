# ===== protocol.md =====
# # Protocol: the level of variant A of the draft definition of k on one-population data with the method's own trees (frozen 2026-11-12, before any run)
#
# ## Why
#
# Variant A of the draft (wiki page `k-split-direction-draft`): k = 1; the node's cells are divided into a basis
# half and a test half; the direction comes from the tree's split on the basis half; `rho` of the tree's split of
# the test half along it is compared with the reference at (test cells, 1). Its level is measured, not derived,
# because the tree's split, which was chosen from all cells, enters the direction. Measured so far: at most 13 of
# 1,000 simulated datasets with Ward linkage on raw features, and 80 of 80 runs of a one-population grid at 1
# cluster. This protocol measures it on more one-population data with the trees the method builds itself.
#
# ## Code to reuse (read before writing anything)
#
# - `results/analyses/k_split_direction_runs_20261112/draft_rule.py`: `install("A")` replaces the reference call
#   inside the opt-in's module at run time and passes each side's cells in data order; `CALLS` records every call
#   (cells, left size, reason, `rho`, p, test cells); `_draft("A")` returns the function for one node.
# - `results/analyses/k_split_direction_runs_20261112/run_benchmark.py`: how a one-population case is run through
#   `benchmark_cluster_algorithm` with the operator and linkage overrides and the opt-in on.
# - `results/analyses/k_margin_prototype_20261112/b_subtrees.py`: how the fitted tree is captured at run time and
#   how the cells under every node are collected.
#
# ## Data (frozen)
#
# One Gaussian population, generated through the registered case `gauss_null_large_continuous` with other sizes
# and seeds (`blobs_continuous`, 1 cluster, `cluster_std` 1.0).
#
# - Identity covariance: (cells, features) = (60, 30), (100, 30), (200, 30), (256, 30), (496, 30), (1000, 30),
#   (200, 80), (60, 200).
# - Unequal variances with correlated features: (256, 30), (496, 30), (1000, 30). The generated matrix X is
#   replaced by X diag(sqrt(v)) Q', with v the 30 eigenvalues of the CHOIR root (53.09, 35.75, 24.75, 20.4,
#   18.24, 16.16, 15.65, 13.51, 12.01, 11.79, 11.6, 10.13, 10.01, 9.21, 8.46, 8.17, 7.91, 7.58, 6.91, 6.66, 6.47,
#   6.31, 6.02, 5.93, 5.78, 5.68, 5.62, 5.46, 5.34, 5.12) and Q one fixed random orthogonal matrix
#   (`scipy.stats.ortho_group.rvs(30, random_state=0)`). Hook: at run time `make_blobs` inside
#   `benchmarks.shared.generators.gaussian_cases` is wrapped so that it returns the transformed matrix while the
#   flag for this covariance is on. No production file is changed.
# - Seeds 1 to 50 for settings with at most 496 cells, 1 to 20 for the two settings with 1,000 cells.
# - Method `tbs_family_diffusion` with `diffusion_coordinate_operator` symmetric or markov and
#   `tree_linkage_method` average or ward (4 cells), `sibling_best_flat_cut_reference=True`, variant A installed.
#   1,960 fits in total.
#
# ## Measurements (`measure.py`, one output file per setting; `summarize.py`, output `summary.txt`)
#
# - M1 complete method: found clusters of every fit. Reported per setting and cell: fits with more than 1
#   cluster, of the number of fits.
# - M2 called nodes: the calls recorded in `CALLS` during every fit. Reported per setting and cell and in total:
#   tested calls, tested calls with p <= 0.01, smallest p, and the same by node size (fewer than 60 cells, 60 to
#   199, 200 and more).
# - M3 every node: for every internal node with at least 30 cells of every fitted tree, variant A applied
#   directly to the node's cells and the tree's split of that node (each side's cells in data order), and the
#   current rule on the same node (the unreplaced `best_flat_cut_reference`, kept in a variable before
#   `install`). Reported per setting and cell and in total: nodes, nodes tested, nodes with p <= 0.01, for both
#   rules; and for variant A by node size as in M2.
# - Self-checks (asserts): every fit has status ok; the cells under the captured root are all cells of the case;
#   for the unequal-variance settings the largest eigenvalue of the data's covariance is above 20 and for the
#   identity settings below 5; the halves of variant A at a node are what `draft_rule` computes (the direct call
#   uses `draft_rule._draft("A")`, no reimplementation).
#
# ## Predictions, stated before any run
#
# - V1 more than 1 cluster in at most 19 of the 1,960 fits (1%).
# - V2 called nodes: p <= 0.01 in at most 2% of the tested calls in total.
# - V3 every node with at least 30 cells: variant A has p <= 0.01 in at most 2% of the tested nodes in total.
# - V4 among the 4 cells, markov/ward has the largest share of nodes with p <= 0.01 under variant A.
# Each is reported as held or not held, with the counts.
#
# ## Rules
#
# - Only files in `results/analyses/k_split_direction_level_20261112/` are written. No production file, test,
#   wiki page or raw capture is changed; nothing is committed, installed or downloaded.
# - Run pattern: `cd /Users/berksakalli/Projects/kl-te-cluster && OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 uv run
#   --no-sync --offline python <script>`; `apply_single_thread_runtime_defaults()` as in the reused scripts.
#   `measure.py` takes the index of one setting, so settings can run as separate processes, at most 6 at a time.
#   Scripts pass `uv run --no-sync --offline ruff check`.
# - This protocol is frozen. Anything done differently goes into `deviations.md` with the reason; a failed assert
#   or prediction is reported, not removed.
# - Results are counts with their totals. The report ends with what was not checked. No explanation is given
#   without a measurement that supports it.


# ===== deviations.md =====
# # Deviations and open choices (protocol frozen 2026-11-12)
#
# ## Failed self-checks (kept, not removed)
# - Setting 7, (60, 200) identity: the assert "largest eigenvalue of the data covariance below 5" failed for all 50 seeds (values 7.28 to 8.48, see
#   `setting_07.json`, key `failures`). `measure.py 7` therefore ends with an AssertionError after writing the file. The data are the registered
#   case with other sizes; with 60 cells and 200 features the sample covariance has a largest eigenvalue above 5. The assert was not changed; M1 to M3
#   of this setting are in `summary.txt` and count in the totals.
# - Setting 10, (1000, 30) unequal variances, seed 1, symmetric/ward: the fit raised ValueError (fixed-topology NNLS branch-length optimization,
#   status 'solver_not_converged'; `allow_method_errors=False`). It is recorded as a fit with status "error: ..." (assert "every fit has status ok"
#   failed once, see `setting_10.json`), has no calls and no nodes, counts in the 1,960 fits and in M1 as not more than 1 cluster. `measure.py 10`
#   ends with an AssertionError after writing the file. All other 1,959 fits have status ok.
#
# ## Choices the protocol left open
# - A fit that raises ValueError is caught in `measure.py` (added after the first run of setting 10 stopped at seed 1 without a file); the other
#   settings were started with the version without the catch and had no error. Setting 10 was rerun with the catch.
# - Left side of a node = its first child in `tree.successors` order; right side = all rows below the other children (binary tree: the second
#   child). The pipeline's own left/right order was not read from its code.
# - M3 matrix = `generate_case_data(case)` data (with the unequal-variance hook on for settings 8 to 10), rows indexed by the labels of the tree leaves.
# - M3 nodes: internal nodes (with children) with at least 30 cells; variant A tested = reason "tested"; "p <= 0.01" is counted over tested nodes
#   only. Node size bins use the node's cells (M2: the call's n).
# - V2, V3: "at most 2%" is checked as count <= 0.02 x tested; V4 compares counts/tested nodes per cell over all settings.
# - Extra self-checks added (recorded in `failures` if violated, none violated): every recorded M2 call (n, left size) is a node of the captured
#   tree; the direct call's record has the node's n and left size and `n_test` = ceil(left/2) + ceil(right/2); the direct return equals the record.
# - Largest-eigenvalue check uses `np.cov` of the generated matrix per seed (once per seed, not per cell).
# - `make_blobs` hook is `gaussian_cases.make_blobs` replaced at run time; Q = `ortho_group.rvs(30, random_state=0)`, X replaced by X diag(sqrt(v)) Q'
#   (written `x @ (diag(sqrt(v)) @ Q.T)`).


# ===== measure.py =====
"""protocol.md M1 to M3 for one setting. usage: measure.py SETTING_INDEX (0 to 10)"""
import json
import sys
import time
from pathlib import Path

import networkx as nx
import numpy as np
from scipy.stats import ortho_group

HERE = Path(__file__).resolve().parent
sys.path.insert(0, str(HERE.parents[2]))
sys.path.insert(0, str(HERE.parent / "k_split_direction_runs_20261112"))

import draft_rule  # noqa: E402

import benchmarks.shared.generators.gaussian_cases as gaussian_cases  # noqa: E402
import benchmarks.shared.runners.tbs_runner as tbs_runner  # noqa: E402
from benchmarks.shared.benchmark_runs.runtime import (
    apply_single_thread_runtime_defaults,  # noqa: E402
)
from benchmarks.shared.cases import get_test_cases_by_suite  # noqa: E402
from benchmarks.shared.generators import generate_case_data  # noqa: E402
from benchmarks.shared.pipeline import benchmark_cluster_algorithm  # noqa: E402
from benchmarks.shared.runners.method_registry import METHOD_SPECS  # noqa: E402

METHOD = "tbs_family_diffusion"
CELLS = [(operator, linkage) for operator in ("symmetric", "markov") for linkage in ("average", "ward")]
SETTINGS = [(c, f, False) for c, f in ((60, 30), (100, 30), (200, 30), (256, 30), (496, 30), (1000, 30), (200, 80), (60, 200))] + [
    (c, 30, True) for c in (256, 496, 1000)
]
EIGENVALUES = np.array([53.09, 35.75, 24.75, 20.4, 18.24, 16.16, 15.65, 13.51, 12.01, 11.79, 11.6, 10.13, 10.01, 9.21, 8.46, 8.17,
                        7.91, 7.58, 6.91, 6.66, 6.47, 6.31, 6.02, 5.93, 5.78, 5.68, 5.62, 5.46, 5.34, 5.12])
MIN_NODE_CELLS = 30
UNEQUAL = False  # flag read by the make_blobs hook
TRANSFORM = np.diag(np.sqrt(EIGENVALUES)) @ ortho_group.rvs(30, random_state=0).T
original = draft_rule.mod.best_flat_cut_reference  # the current rule, kept before install
original_make_blobs = gaussian_cases.make_blobs
seen = {}
Original = tbs_runner.TreeDecomposition


class Recording(Original):
    def decompose_tree(self):
        out = super().decompose_tree()
        seen.update(tree=self.tree)
        return out


def make_blobs_hook(*args, **kwargs):
    x, y = original_make_blobs(*args, **kwargs)
    return (x @ TRANSFORM if UNEQUAL else x), y


def main():
    global UNEQUAL
    index = int(sys.argv[1])
    cells, features, UNEQUAL = SETTINGS[index]
    gaussian_cases.make_blobs = make_blobs_hook
    tbs_runner.TreeDecomposition = Recording
    draft_rule.install("A")
    draft = draft_rule._draft("A")
    apply_single_thread_runtime_defaults()
    start = time.perf_counter()
    (registered,) = [c for c in get_test_cases_by_suite("continuous") if c["name"] == "gauss_null_large_continuous"]
    fits, failures = [], []  # a failed self-check is kept in the file and fails the run at the end
    for seed in range(1, 21 if cells == 1000 else 51):
        case = {**registered, "n_samples": cells, "n_features": features, "seed": seed}
        data, _, _, _ = generate_case_data(case)
        matrix = data.to_numpy(dtype=np.float64)
        row_of = {name: row for row, name in enumerate(data.index)}
        top = float(np.linalg.eigvalsh(np.cov(matrix.T)).max())
        if not (top > 20 if UNEQUAL else top < 5):
            failures.append(dict(check="largest eigenvalue of the data covariance", seed=seed, value=top, unequal=UNEQUAL))
        for operator, linkage in CELLS:
            seen.clear()
            draft_rule.CALLS.clear()
            params = {**METHOD_SPECS[METHOD].param_grid[0], "diffusion_coordinate_operator": operator, "tree_linkage_method": linkage,
                      "sibling_best_flat_cut_reference": True}
            try:
                res = benchmark_cluster_algorithm(test_cases=[case], methods=[METHOD], method_params={METHOD: [params]}, verbose=False,
                                                  plot_umap=False, include_cover_pages=False, include_validation_page=False,
                                                  allow_method_errors=False).iloc[0]
            except ValueError as error:  # kept as a failed fit (status assert), the setting goes on
                fits.append(dict(cells=cells, features=features, unequal=UNEQUAL, seed=seed, cell=f"{operator}/{linkage}", found=None,
                                 status=f"error: {error}", calls=[], nodes=[]))
                failures.append(dict(check="status ok", status=fits[-1]["status"], seed=seed, cell=fits[-1]["cell"]))
                continue
            m2 = [dict(c) for c in draft_rule.CALLS]  # the calls of the fit, before the direct M3 calls
            draft_rule.CALLS.clear()
            fit = dict(cells=cells, features=features, unequal=UNEQUAL, seed=seed, cell=f"{operator}/{linkage}",
                       found=int(res["found_clusters"]), status=str(res["status"]), calls=m2, nodes=[])
            where = dict(seed=seed, cell=fit["cell"])
            if fit["status"] != "ok":
                failures.append(dict(check="status ok", status=fit["status"], **where))
            tree = seen["tree"]
            rows_under = {}
            for node in reversed(list(nx.topological_sort(tree))):
                children = list(tree.successors(node))
                rows_under[node] = [row_of[tree.nodes[node]["label"]]] if not children else sum((rows_under[c] for c in children), [])
            if sorted(rows_under[tree.root()]) != list(range(cells)):
                failures.append(dict(check="cells under the root are all cells", **where))
            pairs = set()
            for node, rows in rows_under.items():
                children = list(tree.successors(node))
                if not children:
                    continue
                left = sorted(rows_under[children[0]])
                right = sorted(r for c in children[1:] for r in rows_under[c])
                pairs.add((len(rows), len(left)))
                if len(rows) < MIN_NODE_CELLS:
                    continue
                order = left + right
                in_left = np.r_[np.ones(len(left), dtype=bool), np.zeros(len(right), dtype=bool)]
                points = matrix[order]
                a = draft(points, in_left)
                (record,) = draft_rule.CALLS
                draft_rule.CALLS.clear()
                if (record["n"], record["left"]) != (len(rows), len(left)) or (
                    record["reason"] == "tested" and record["n_test"] != (len(left) + 1) // 2 + (len(right) + 1) // 2
                ):
                    failures.append(dict(check="halves of variant A are those of draft_rule", node=str(node), **where))
                assert a.reason == record["reason"] and a.p_value == record["p"]
                b = original(points, in_left)
                fit["nodes"].append(dict(
                    cells=len(rows), left=len(left), a_reason=record["reason"], a_rho=record["rho"], a_p=record["p"],
                    a_test_cells=record.get("n_test"), cur_reason=b.reason, cur_k=int(b.invariant_directions),
                    cur_rho=float(b.rho) if np.isfinite(b.rho) else None, cur_p=float(b.p_value)))
            if not {(c["n"], c["left"]) for c in m2} <= pairs:
                failures.append(dict(check="every recorded call is a node of the captured tree", **where))
            fits.append(fit)
        print(index, seed, f"{time.perf_counter() - start:.0f} s", flush=True)
    json.dump(dict(setting=index, cells=cells, features=features, unequal=UNEQUAL, seconds=time.perf_counter() - start,
                   failures=failures, fits=fits), open(HERE / f"setting_{index:02d}.json", "w"))
    assert not failures, f"{len(failures)} failed self-checks, see setting_{index:02d}.json"


if __name__ == "__main__":
    main()


# ===== summarize.py =====
"""protocol.md: tables of M1 to M3 and predictions V1 to V4 from setting_*.json into summary.txt"""
import json
from pathlib import Path

HERE = Path(__file__).resolve().parent
CELLS = ["symmetric/average", "symmetric/ward", "markov/average", "markov/ward"]
BINS = [("<60", lambda n: n < 60), ("60-199", lambda n: 60 <= n < 200), (">=200", lambda n: n >= 200)]
files = sorted(HERE.glob("setting_*.json"))
settings = [json.load(open(f)) for f in files]
assert len(settings) == 11, f"{len(settings)} of 11 setting files"
fits = [f for s in settings for f in s["fits"]]
label = lambda f: f"{f['cells']}x{f['features']}{' unequal' if f['unequal'] else ''}"  # noqa: E731
groups = [(f"{s['cells']}x{s['features']}{' unequal' if s['unequal'] else ''} {c}", [f for f in s["fits"] if f["cell"] == c])
          for s in settings for c in CELLS] + [(f"TOTAL {c}", [f for f in fits if f["cell"] == c]) for c in CELLS] + [("TOTAL all", fits)]
lines = [f"one Gaussian population; {len(fits)} fits; failed self-checks: {sum(len(s['failures']) for s in settings)}"]


def tally(ps):
    return f"{sum(p <= 0.01 for p in ps)}/{len(ps)}", (f"{min(ps):.4g}" if ps else "-")


def by_size(items, size, p):
    return " | ".join(f"{name} {sum(q <= 0.01 for q in qs)}/{len(qs)}" for name, test in BINS
                      for qs in [[p(i) for i in items if i["reason"] == "tested" and test(size(i))]])


lines += ["", "M1 found clusters: fits with more than 1 cluster / fits", "group | >1 cluster"]
lines += [f"{g} | {sum((f['found'] or 0) > 1 for f in fs)}/{len(fs)}" for g, fs in groups]
lines += ["", "M2 called nodes: tested calls with p <= 0.01 / tested calls | smallest p | by node size (<60, 60-199, >=200)"]
for g, fs in groups:
    calls = [c for f in fs for c in f["calls"] if c["reason"] == "tested"]
    count, smallest = tally([c["p"] for c in calls])
    lines.append(f"{g} | {count} | {smallest} | {by_size(calls, lambda c: c['n'], lambda c: c['p'])}")
lines += ["", "M3 every node with >= 30 cells: nodes | variant A tested | variant A p <= 0.01 | current rule tested | current rule p <= 0.01 | "
          "smallest p variant A | variant A p <= 0.01 by node size (<60, 60-199, >=200)"]
for g, fs in groups:
    nodes = [n for f in fs for n in f["nodes"]]
    a = [n for n in nodes if n["a_reason"] == "tested"]
    c = [n for n in nodes if n["cur_reason"] == "tested"]
    lines.append(f"{g} | {len(nodes)} | {len(a)} | {sum(n['a_p'] <= 0.01 for n in a)} | {len(c)} | {sum(n['cur_p'] <= 0.01 for n in c)} | "
                 f"{min([n['a_p'] for n in a], default='-')} | {by_size([dict(n, reason=n['a_reason']) for n in nodes], lambda n: n['cells'], lambda n: n['a_p'])}")
v1 = sum((f["found"] or 0) > 1 for f in fits)
m2 = [c for f in fits for c in f["calls"] if c["reason"] == "tested"]
v2 = sum(c["p"] <= 0.01 for c in m2)
m3 = [n for f in fits for n in f["nodes"] if n["a_reason"] == "tested"]
v3 = sum(n["a_p"] <= 0.01 for n in m3)
share = {c: [sum(n["a_p"] <= 0.01 for f in fits if f["cell"] == c for n in f["nodes"] if n["a_reason"] == "tested"),
             sum(f["cell"] == c for f in fits for n in f["nodes"] if n["a_reason"] == "tested")] for c in CELLS}
v4 = max(share, key=lambda c: share[c][0] / share[c][1])
held = lambda ok: "held" if ok else "not held"  # noqa: E731
lines += ["", "Predictions",
          f"V1 more than 1 cluster in at most 19 of {len(fits)} fits: {v1} of {len(fits)}: {held(v1 <= 19)}",
          f"V2 called nodes p <= 0.01 in at most 2% of tested calls: {v2} of {len(m2)} ({v2 / max(len(m2), 1):.4f}): {held(v2 <= 0.02 * len(m2))}",
          f"V3 nodes with >= 30 cells, variant A p <= 0.01 in at most 2% of tested nodes: {v3} of {len(m3)} ({v3 / max(len(m3), 1):.4f}): "
          f"{held(v3 <= 0.02 * len(m3))}",
          "V4 markov/ward has the largest share of nodes with p <= 0.01 under variant A: "
          + ", ".join(f"{c} {a}/{b} = {a / b:.4f}" for c, (a, b) in share.items()) + f"; largest {v4}: {held(v4 == 'markov/ward')}"]
(HERE / "summary.txt").write_text("\n".join(lines) + "\n")
print("\n".join(lines))

"""Independent spot check of the level measurement (own run of one setting, and consistency inside the recorded files)."""
import json
import sys
from collections import Counter
from pathlib import Path

HERE = Path(__file__).resolve().parent
sys.path.insert(0, str(HERE.parents[2]))
sys.path.insert(0, str(HERE.parent / "k_split_direction_runs_20261112"))

import draft_rule  # noqa: E402

from benchmarks.shared.benchmark_runs.runtime import (
    apply_single_thread_runtime_defaults,  # noqa: E402
)
from benchmarks.shared.cases import get_test_cases_by_suite  # noqa: E402
from benchmarks.shared.pipeline import benchmark_cluster_algorithm  # noqa: E402
from benchmarks.shared.runners.method_registry import METHOD_SPECS  # noqa: E402

files = [json.loads(path.read_text()) for path in sorted(HERE.glob("setting_*.json"))]
print("top-level keys of a setting file:", list(files[0].keys()) if isinstance(files[0], dict) else type(files[0]))
fits = [fit for f in files for fit in (f["fits"] if isinstance(f, dict) else f)]
print("fits", len(fits), "| keys of a fit:", list(fits[0].keys()))
print("found clusters of the fits with more than 1:", sorted(fit["found"] for fit in fits if (fit["found"] or 0) > 1))
print("status:", Counter("ok" if fit["status"] == "ok" else "error" for fit in fits))

# 1) inside the files: a called node and the direct call at the node with the same cells and left size give the same p-value
same = differ = unmatched = 0
for fit in fits:
    direct = {}
    for node in fit["nodes"]:
        direct.setdefault((node["cells"], min(node["left"], node["cells"] - node["left"])), []).append(node)
    for call in fit["calls"]:
        if call["reason"] != "tested" or call["n"] < 30:
            continue
        candidates = direct.get((call["n"], min(call["left"], call["n"] - call["left"])), [])
        if not candidates:
            unmatched += 1
        elif any(abs(c["a_p"] - call["p"]) < 1e-12 for c in candidates):
            same += 1
        else:
            differ += 1
print(f"called nodes against the direct call on the same node: equal p in {same}, different p in {differ}, no node found {unmatched}")

# 2) own run of one setting: (256, 30) identity, seeds 1 to 10, the 4 cells
draft_rule.install("A")
apply_single_thread_runtime_defaults()
(registered,) = [c for c in get_test_cases_by_suite("continuous") if c["name"] == "gauss_null_large_continuous"]
recorded = {(fit["seed"], fit["cell"]): fit for fit in fits if (fit["cells"], fit["features"], fit["unequal"]) == (256, 30, False)}
equal = total = 0
for seed in range(1, 11):
    for operator in ("symmetric", "markov"):
        for linkage in ("average", "ward"):
            draft_rule.CALLS.clear()
            params = {**METHOD_SPECS["tbs_family_diffusion"].param_grid[0], "diffusion_coordinate_operator": operator,
                      "tree_linkage_method": linkage, "sibling_best_flat_cut_reference": True}
            case = {**registered, "n_samples": 256, "n_features": 30, "seed": seed}
            res = benchmark_cluster_algorithm(test_cases=[case], methods=["tbs_family_diffusion"], method_params={"tbs_family_diffusion": [params]},
                                              verbose=False, plot_umap=False, include_cover_pages=False, include_validation_page=False,
                                              allow_method_errors=False)
            mine = (int(res["found_clusters"].iloc[0]), sorted(round(c["p"], 12) for c in draft_rule.CALLS if c["reason"] == "tested"))
            theirs = recorded[(seed, f"{operator}/{linkage}")]
            total += 1
            equal += mine == (theirs["found"], sorted(round(c["p"], 12) for c in theirs["calls"] if c["reason"] == "tested"))
print(f"own run of (256, 30) identity, seeds 1 to 10: found clusters and the p-values of the tested calls equal the recorded ones in {equal} of {total} fits")
