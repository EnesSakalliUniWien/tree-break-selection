# ===== protocol.md =====
# # Protocol: how the sprs relate to the subspaces and the equidistances (frozen 2026-11-11, before the run)
#
# Descriptive; no gate or default is changed. Data, tree and splits of `spr_alternatives_best_flat_cut_20261111`:
# 48,879 CHOIR cells, the saved Markov/Ward tree (replay 138 clusters), the 1,285 tested splits with 32 cells or
# more and 1 to 10 invariant directions. Nodes are leaf sets (`Partition`).
#
# ## Trace (algebra, checked numerically in the self-check)
#
# Node P with children A (a cells) and B (b cells), a clade C (c cells) below A, centroids mu, in any Euclidean
# space S. Pruning C and regrafting it on B's side changes the within-children sum of squares by the transfer cost
#
#     dW_S(C) = c b / (b + c) |mu_C - mu_B|^2  -  c a / (a - c) |mu_C - mu_A|^2 .
#
# 1. In P's whitened invariant directions the between/total ratio of the split changes by exactly -dW / n. So an
#    spr raises `rho` if and only if dW < 0: the clade is, weighted by size, nearer the other side.
# 2. dW = 0 means the clade is equidistant: the spr leaves `rho` unchanged, so `rho` cannot rank the two
#    alternatives. For one cell and large sides the sign of dW is the sign of the cell margin of 8 November
#    (m = (distance to the other centroid - distance to its own) / distance between the centroids).
# 3. The same clade has a margin in every space. The tree was built in the tree's space (Markov diffusion
#    coordinates, Ward). An spr alternative in a space S is a clade with dW_S <= 0. So the sprs seen against the
#    best flat cut are the clades whose side differs between the tree's space and the invariant directions, or
#    that are equidistant in the tree's space.
# 4. Equidistance in the construction: Ward joined A's children A1 and A2 because their merge cost was lowest. If
#    the cost of joining A2 with B is nearly the same, the tree with (A2, B) joined is the spr of A2 onto B, and
#    it changes P's split to (A1 | A2 plus B).
#
# ## Spaces
#
# tree (30 Markov diffusion coordinates, Euclidean, the tree's own criterion), pcs (30 PCs, Euclidean),
# invariant (PCs on P's invariant directions, whitened by P's covariance: the space of `rho`), fuzzy (PCs with
# the invariant directions projected out).
#
# Clade margin m_S(C) = (|mu_C - mu_other| - |mu_C - mu_own|) / |mu_A - mu_B|; for one cell this is the cell
# margin of 8 November. Tied: |m| < 0.1 (the stated convention of 8 November, not a test). Wrong side: m < 0.
#
# ## Measured per split
#
# 1. Per space: share of cells tied, on the wrong side; share of cells whose side differs between the tree's
#    space and the invariant directions.
# 2. Clades whose spr raises `rho` (dW_invariant < 0) against all other clades: share tied in the tree's space,
#    share on the wrong side in the tree's space, share tied in the fuzzy space. Separately for single cells and
#    for clades of 10 cells or more.
# 3. Cells moved by the greedy sprs and cells that differ between the tree split and the best flat cut (targeted
#    sprs), against the cells that stay: share tied and share on the wrong side in the tree's space and in pcs.
# 4. Grandchild sprs (move A1, A2, B1 or B2 to the other side): Ward tie ratio in the tree's space = cost of
#    joining the grandchild with the other child / cost of the merge the tree made; near-tied if below 1.1
#    (convention). Against: does this spr raise `rho`, and does the split pass the reference after it.
# 5. Sprs derived from equidistance and subspace, without the best flat cut and without a greedy search: move
#    every maximal clade that is tied in the tree's space and has dW_invariant < 0 ("tied sprs"). Control: move
#    every maximal clade with dW_invariant < 0 that is not tied in the tree's space ("untied sprs"). One pass, all
#    clades at once. Recorded: number of clades, cells moved, `rho`, reference p, line cut share.
#
# Summaries by the verdict classes of the earlier run (tree and best pass 57, only the best flat cut passes 221
# of which greedy sprs rescued 122, neither 1,007).
#
# ## Self-check before the run (selfcheck.py)
#
# (a) -dW / n equals the change of the between/total ratio for every clade of a simulated tree, to rounding
# error; (b) two groups 12 SD apart give 0 tied and 0 wrong-side cells; (c) moving all tied sprs gives the `rho`
# that `split_rho` returns for the resulting split.
#
# ## Expected before running
#
# - 8 November, splits inside one population: 7-11% of cells tied in the tree's space, the side differs between
#   the tree's space and the test space for 7-12% of cells. Most of the 1,285 splits lie inside one cell line
#   (765), so similar values are expected here. For large CHOIR splits the tree's space had 0.6% tied cells.
# - Clades whose spr raises `rho` should be tied or on the wrong side in the tree's space more often than other
#   clades. How much is not predicted. If they are not, the sprs come from the change of space alone.
# - The fuzzy space should carry no side information (about a quarter of the cells tied on 8 November).
# - Near-tied merges should give `rho`-raising grandchild sprs more often than other merges; not predicted how
#   strongly.
# - Tied sprs against untied sprs: not predicted.
#
# ## Limits known before running
#
# One dataset and one tree; dependent splits; the tie cuts 0.1 and 1.1 are conventions; centroid distances only,
# so equidistance to a curved group is not seen; the tree's space is taken as the saved diffusion coordinates;
# per-split p-values without the BH step; nothing is applied to the fit.

# ===== margin_lib.py =====
"""Clade margins and transfer costs in one space, for every clade below a split (protocol.md)."""
import numpy as np

TIE = 0.1


def layout(is_leaf, sub):
    """Cells before each clade, clade sizes, index of the second child, and the 'below the first child' flag."""
    lo = np.cumsum(is_leaf) - is_leaf
    sizes = (sub + 1) // 2
    second = 1 + sub[1]
    below_first = np.zeros(len(sub), dtype=bool)
    below_first[1:second] = True
    return lo, sizes, second, below_first


def clade_margins(z, lo, sizes, second, below_first):
    """Return margin m and transfer cost dW of every clade in the space ``z`` (nan for P and its children)."""
    prefix = np.vstack([np.zeros(z.shape[1]), np.cumsum(z, axis=0)])
    mu = (prefix[lo + sizes] - prefix[lo]) / sizes[:, None]
    mu_first, mu_second = mu[1], mu[second]
    own = np.where(below_first, sizes[1], sizes[second]).astype(float)
    other = len(z) - own
    d_own = np.linalg.norm(mu - np.where(below_first[:, None], mu_first, mu_second), axis=1)
    d_other = np.linalg.norm(mu - np.where(below_first[:, None], mu_second, mu_first), axis=1)
    m = (d_other - d_own) / np.linalg.norm(mu_first - mu_second)
    with np.errstate(divide="ignore", invalid="ignore"):
        dw = sizes * other / (other + sizes) * d_other**2 - sizes * own / (own - sizes) * d_own**2
    for values in (m, dw):
        values[[0, 1, second]] = np.nan
    return m, dw


def maximal(selected, sub):
    """Keep the selected clades that have no selected clade above them."""
    cover = np.zeros(len(sub) + 1, dtype=np.int64)
    chosen = np.flatnonzero(selected)
    np.add.at(cover, chosen + 1, 1)
    np.add.at(cover, chosen + sub[chosen], -1)
    return chosen[np.cumsum(cover)[chosen] == 0]


def cells_of(clades, lo, sizes, n):
    mask = np.zeros(n, dtype=bool)
    for clade in clades:
        mask[lo[clade] : lo[clade] + sizes[clade]] = True
    return mask


def ward_cost(z, cells_u, cells_v):
    u, v = z[cells_u], z[cells_v]
    return len(u) * len(v) / (len(u) + len(v)) * float(((u.mean(0) - v.mean(0)) ** 2).sum())

def root_split(x, tree_coordinates):
    n = len(x)
    z = linkage(tree_coordinates, "ward")
    parent = np.full(2 * n - 1, -1, dtype=np.int64)
    for k, (a, b) in enumerate(z[:, :2].astype(int)):
        parent[a] = parent[b] = n + k
    order, pre, sub = index_tree(parent)
    nodes, local_parent, is_leaf, local_sub = subtree(parent, order, pre, sub, 2 * n - 2, n)
    return nodes[is_leaf], is_leaf, local_sub

"""protocol.md: margins of cells and clades in four spaces against the sprs, for the 1,285 measured splits."""
import json
import sys
from multiprocessing import Pool
from pathlib import Path

import numpy as np
import pandas as pd

HERE = Path(__file__).resolve().parent
SPR = HERE.parent / "spr_alternatives_best_flat_cut_20261111"
sys.path.insert(0, str(HERE.parents[2]))
sys.path.insert(0, str(HERE))
sys.path.insert(0, str(SPR))
sys.path.insert(0, str(HERE.parent / "split_vs_best_flat_cut_20261111"))

from margin_lib import TIE, cells_of, clade_margins, layout, maximal, ward_cost  # noqa: E402
from measure_lib import best_flat_cut, r2_of  # noqa: E402
from spr_lib import greedy_sprs, index_tree, subtree  # noqa: E402

from tree_break_selection.hierarchy_analysis.statistics.sibling_divergence.best_flat_cut_reference import (  # noqa: E402
    reference_p_value,
    to_rho,
    whiten,
)
from tree_break_selection.hierarchy_analysis.statistics.sibling_divergence.split_count_rule_out import invariant_directions  # noqa: E402

METHOD = "tbs_family_diffusion_markov_ward"
NEAR_TIE = 1.1
STATE = {}


def init():
    source = HERE.parent / "choir_cell_lines_tbs_lbfgsb_20261106"
    STATE["x"] = np.load(source / "pca.npy")
    STATE["tree_space"] = np.load(source / METHOD / "coordinates.npy")
    STATE["line"] = pd.factorize(pd.read_csv(source / "cell_metadata.csv", index_col=0, dtype=str).Cell_line)[0]
    z = np.load(SPR / f"tree_{METHOD}.npz")
    STATE["parent"], STATE["leaf_row"] = z["parent"], z["leaf_row"]
    STATE["index"] = index_tree(z["parent"])


def line_cut_share(lines, mask):
    left = np.bincount(lines[mask], minlength=lines.max() + 1)
    right = np.bincount(lines[~mask], minlength=lines.max() + 1)
    return float(np.minimum(left, right).sum() / len(lines))


def counts(flag, group):
    """[cells or clades in the group, of them flagged]."""
    return [int(group.sum()), int((flag & group).sum())]


def job(node):
    order, pre, sub_all = STATE["index"]
    nodes, local_parent, is_leaf, sub = subtree(STATE["parent"], order, pre, sub_all, node, len(STATE["leaf_row"]))
    rows = STATE["leaf_row"][nodes[is_leaf]]
    points = STATE["x"][rows]
    n = len(rows)
    directions = invariant_directions(points)
    k = len(directions)
    coordinates = points @ directions.T
    y = whiten(coordinates)
    lines = STATE["line"][rows]
    lo, sizes, second, below_first = layout(is_leaf, sub)
    spaces = {"tree": STATE["tree_space"][rows], "pcs": points, "invariant": y, "fuzzy": points - coordinates @ directions}
    m, dw = {}, {}
    for name, z in spaces.items():
        m[name], dw[name] = clade_margins(z, lo, sizes, second, below_first)

    def p_of(r2):
        return float(reference_p_value(to_rho(r2, n), n, k)[0])

    tree_mask = np.arange(n) < sizes[1]
    r2_tree = r2_of(y, tree_mask)
    out = {"node": f"N{node}", "n": n, "k": k, "lines_in_subtree": int(len(np.unique(lines))), "rho_tree": to_rho(r2_tree, n), "p_tree": p_of(r2_tree)}

    # 1. cells per space
    cell = {name: values[is_leaf] for name, values in m.items()}
    everyone = np.ones(n, dtype=bool)
    out["cells"] = {name: {"tied": counts(np.abs(v) < TIE, everyone)[1], "wrong": counts(v < 0, everyone)[1]} for name, v in cell.items()}
    out["side_differs_tree_invariant"] = int(((cell["tree"] < 0) != (cell["invariant"] < 0)).sum())

    # 2. clades whose spr raises rho against the others
    valid = ~np.isnan(dw["invariant"])
    raises = valid & (dw["invariant"] < 0)
    out["clades"] = {}
    for label, group in (("single", valid & (sizes == 1)), ("big", valid & (sizes >= 10))):
        out["clades"][label] = {
            side: {"n": int(g.sum()), "tied_tree": int((np.abs(m["tree"]) < TIE)[g].sum()), "wrong_tree": int((m["tree"] < 0)[g].sum()),
                   "tied_fuzzy": int((np.abs(m["fuzzy"]) < TIE)[g].sum())}
            for side, g in (("raises", group & raises), ("other", group & ~raises))
        }

    # 3. cells moved by the greedy sprs and by the targeted sprs
    final = tree_mask
    for _, _, left in greedy_sprs(y, local_parent, is_leaf, sub):
        final = left
    rho_best, best = best_flat_cut(coordinates)
    differs = tree_mask != best
    targeted = differs if differs.sum() <= n / 2 else ~differs
    out.update(rho_spr=to_rho(r2_of(y, final), n), p_spr=p_of(r2_of(y, final)), rho_best=rho_best, p_best=float(reference_p_value(rho_best, n, k)[0]))
    out["moved"] = {}
    for label, moved in (("greedy", final != tree_mask), ("targeted", targeted)):
        out["moved"][label] = {
            name: {"moved_tied": counts(np.abs(cell[name]) < TIE, moved), "moved_wrong": counts(cell[name] < 0, moved),
                   "stay_tied": counts(np.abs(cell[name]) < TIE, ~moved), "stay_wrong": counts(cell[name] < 0, ~moved)}
            for name in ("tree", "pcs")
        }

    # 4. grandchild sprs and Ward near-ties in the tree's space
    out["grandchildren"] = []
    for child, other in ((1, second), (second, 1)):
        if sub[child] == 1:
            continue
        kids = (child + 1, child + 1 + sub[child + 1])
        for g, h in (kids, kids[::-1]):
            cells_g, cells_h, cells_other = (cells_of([i], lo, sizes, n) for i in (g, h, other))
            made = ward_cost(spaces["tree"], cells_g, cells_h)
            ratio = ward_cost(spaces["tree"], cells_g, cells_other) / made if made > 0 else None
            r2 = r2_of(y, tree_mask ^ cells_g)
            out["grandchildren"].append({"size": int(sizes[g]), "ratio": ratio, "raises": bool(dw["invariant"][g] < 0),
                                         "m_tree": float(m["tree"][g]), "rho": to_rho(r2, n), "p": p_of(r2)})

    # 5. sprs derived from equidistance in the tree's space and the side in the invariant directions
    tied_tree = np.abs(m["tree"]) < TIE
    out["derived"] = {}
    for label, selected in (("tied", raises & tied_tree), ("untied", raises & ~tied_tree)):
        clades = maximal(selected, sub)
        mask = tree_mask ^ cells_of(clades, lo, sizes, n)
        row = {"moves": int(len(clades)), "cells": int(sizes[clades].sum())}
        if 0 < mask.sum() < n:
            r2 = r2_of(y, mask)
            row.update(rho=to_rho(r2, n), p=p_of(r2), cut=line_cut_share(lines, mask))
        out["derived"][label] = row
    out["cut_tree"] = line_cut_share(lines, tree_mask)
    return out

def pct(part, whole):
    return f"{100 * part / whole:.1f}%" if whole else "-"

for name, g in groups:
    n = sum(r["n"] for r in g)
    parts = [f"{space} {pct(sum(r['cells'][space]['tied'] for r in g), n)} / {pct(sum(r['cells'][space]['wrong'] for r in g), n)}" for space in ("tree", "pcs", "invariant", "fuzzy")]

            line.append(f"{space}: moved {pooled('moved_tied')} / {pooled('moved_wrong')}, stay {pooled('stay_tied')} / {pooled('stay_wrong')}")

              f"median line cut share {med(x.get('cut') for x in d):.3f}")
